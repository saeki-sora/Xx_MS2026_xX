01 · お願いしたいこと

やってほしいことは、この4つ

いまは仮のレベルデザインが入っていて、そのまま遊べます。これを土台に、気持ちよく遊べる形へ作り直してください。迷ったら左の「やりたいこと」から探せます。

1 · WAVE

敵の出し方を決める

ウェーブごとに「何秒後に・どの湧き位置から・どの敵を・何体・何秒かけて」出すかを決めます。

2 · GOAL

目標撃破数を決める

「この数を倒したら次のウェーブへ」という数です。WAVE 5 の目標を倒したらクリアになります。

3 · MAP

障害物・敵の強さを整える

障害物の配置の変更・追加と、敵の体力・速さの調整も、今回お願いする範囲です。

4 · PLAY

遊んで直す

Unity で Play して確かめ、数字を直します。ツールにテスト用のボタン（ウェーブを飛ばすなど）があります。

やらなくていいこと・触らないでほしい所詳しく
  • プログラム（.cs ファイル）は触りません。全部ツールの画面で数字を入れるだけです。
  • Game のシーン（Assets/Scenes/Game.unity）は触りません。カメラや HUD など、全ステージ共通の物が入っています。作業はステージのシーンだけを開いて行ってください。
  • 画面の表示のタイミング（発表の長さ、赤い線の出方など）は全ステージ共通です。変えたいときは相談してください。
  • 背景の見た目は今回の範囲外です（ステージ2の床や壁は仮の四角です）。
  • ステージ2の橋（Bridge）は、WAVE 3 で崩れる仕掛けとつながっています。消したり名前を変えたりしないでください。
ユーザー（ディレクター）が決めていること詳しく
  • ステージ1と2は難易度順ではありません。2つの間に難しさの差はいりません。どちらから遊んでも同じくらいの手応えにしてください（試合ごとにルーレットでステージが決まります）。
  • このゲームは「制限時間内に、どのウェーブまで行けるか」を遊ぶゲームです。WAVE 5 は今のところの仮の上限です。
  • 時間切れは今はゲームオーバーです（リザルトには「どのウェーブまで行けたか」が出ます）。後で変わる可能性が大きいので、そこに頼りすぎない作りにしておくと安全です。
  • ウェーブの合間は「歯みがきタイム」で、その間は敵が来ません。

02 · 作業の始め方

最初に main を最新にして、自分のブランチを作る

ほかの人の作業とぶつからないように、毎回この順番で始めてください。Unity は閉じた状態でやると安全です。

main に切り替える

git switch main

フェッチする（新しい変更があるか調べる）

git fetch origin

新しい変更があればプルする

git pull origin main

「Already up to date.」と出たら、新しい変更はありません。そのまま次へ。

main から自分のブランチを作る

git switch -c 名前＿ステージレベルデザイン

名前の付け方は、今までのブランチ（例: 佐伯＿敵ウェーブ修正）に合わせて「名前＿作業内容」で。

Unity を開いて作業 → こまめにコミット

区切りのいいところでコミットしておくと、失敗しても戻れます。終わったら push して、ディレクター（プログラマー）に知らせてください。main への取り込み（マージ）はこちらでやります。

git add -A
git commit -m "ステージ1 WAVE 1〜3 の湧き方を調整"
git push -u origin 名前＿ステージレベルデザイン
GitHub Desktop などの画面で操作する場合詳しく
  1. 上の「Current branch」で main を選ぶ。
  2. Fetch origin を押す。
  3. ボタンが Pull origin に変わったら押す（変わらなければ新しい変更なし）。
  4. 「Current branch」→ New branch で、名前を入れて作る（元は main）。
  5. 作業したら左下でコミット → Publish branch（2回目からは Push origin）。

ほかのアプリでも流れは同じです: main に切り替え → フェッチ → あればプル → main から新しいブランチ。

途中で main が新しくなったら・困ったとき詳しく
  • 作業中に main が進んでも、基本はそのまま続けて大丈夫です。取り込むときにこちらで合わせます。
  • 「コミットしていない変更があるので切り替えられない」と出たら、先にコミットしてから切り替えてください。
  • 同じステージのシーンを、ほかの人も同時にいじっていると、ぶつかることがあります。作業を始める前に一声かけてもらえると安全です。
  • わからなくなったら、何もせずに相談してください（無理に直そうとすると、変更が消えることがあります）。

03 · 1試合の流れ

ウェーブ → 合間 → ウェーブ…をくり返す

決めてもらうのは、赤い枠の「戦う」部分の中身です。それ以外の時間は自動で進みます。

最初だけ ・ 4秒握り方のヒント「握るとビーム！」
4秒発表WAVE n／目標撃破数、敵の通り道の赤い線、新しい敵の紹介
発表の最後3・2・1・GO!ここから時計が動く
目標を倒すまで戦うあなたが決めた湧き方で敵が出る
約2〜5秒WAVE CLEAR!残りの敵は画面の外へ逃げる
約11.5秒歯みがきタイム連打でコア回復。敵は来ない

↻ これを WAVE 1 → 5 までくり返し、WAVE 5 の目標を倒したらクリア（WAVE 5 の後に合間はありません）

発表で画面に出るもの詳しく
  • WAVE n ／ 目標撃破数 m！ の大きな帯。
  • 敵の通り道（赤い線）：そのウェーブで使う湧き位置からコアまでの道が、矢印つきで出ます。湧き位置には「！」の印。画面の外の湧き位置は、画面のふちに矢印で出ます。
  • NEW ENEMY カード：そのウェーブで試合中はじめて出てくる敵だけ、右側に紹介カードが出ます。新しい敵を何ウェーブ目で出すかは、そのまま「チュートリアルの順番」になります。
  • 「発表の一言」（例: ボス出現！）という欄もありますが、今は画面に出さない設定です（ユーザー決定）。書いても見えません。
歯みがきタイム（合間）でやること詳しく

ウェーブの合間に、全員で握力センサーを「にぎにぎ」連打して歯をみがくミニゲームです。

  • 説明 1.5秒 → みがく 8秒 → 結果 2秒（合計 約11.5秒）。
  • 1人 18回で 100%（人数分合わせて数えます）。全員がそろって握ると「シンクロ」でボーナス。
  • みがいた分だけコアの HP が回復。満タンを超えた分は「コーティング」（次の1ウェーブだけ、先にダメージを受けてくれる盾）になります。
  • レベルデザイン的には「前のウェーブで削られても、ここで立て直せる」区切りです。合間を「休むだけ（秒数指定）」に変えることもできます。
ステージ2だけの仕掛け：WAVE 3 で橋が崩れる詳しく

お風呂場（ステージ2）では、コアは最初、浴槽の上にかかった橋の上にあります。WAVE 3 の発表で橋が崩れ、コアが下の床に落ちます。WAVE 3 からは守る場所が変わるので、敵が来る方向の組み立ても変えると効果的です（いまの仮案も WAVE 3 から下の出口を主にしています）。

何ウェーブ目で崩れるかの設定はステージのシーンの中（StageCoreDrop の「崩れるウェーブ」）にあります。変えたいときは相談してください。

04 · 敵の種類

いま使える敵は3種類

湧きの行ごとに、この中から1種類を選びます。体力・速さなども調整してOKです（下の数字は今の値）。敵の設定は2つのステージで共通なので、変えると両方に効きます。

数字の見方と細かい性質詳しく
  • 速さは1秒に進む距離（m）。湧き位置からコアまではどちらのステージも 25〜30m ほど（障害物をよける分もう少し長い）なので、スピキなら 10秒前後でコアに着きます。
  • 爆弾スピキ：爆発の半径 1.6m、まわりの敵に 30 ダメージ（スピキは一撃）。コアに着いたときの爆発はコアに 2 ダメージ。
  • ボススピキ：当たり判定が大きく（半径 0.75m）、ビームが当たりやすい。
  • 3種類とも紹介文があるので、試合ではじめて出るウェーブで NEW ENEMY カードが出ます。
  • 数字の変え方は、左の「敵の強さ・速さを変えるには？」へ。新しい種類も作れます（新しい敵の種類を作るには？）。

表の「1秒に」の意味と、仮案の考え方詳しく
  • 1秒に＝1秒あたりに出てくるおよその数。ツールの「全体」ページのグラフ（青）と同じ計算です。プレイヤーにとっての「忙しさ」の目安になります。
  • どのウェーブも「1周（10〜15秒）を出し終えたら、2秒待って最初からくり返す」設定です。目標に届くまで敵が出続けるので、ウェーブが終わらなくなることはありません。
  • 全部すぐ倒せたとしても、目標の数が出そろうまで WAVE 1 で約15秒、WAVE 5 で約30〜35秒かかります。5ウェーブ合わせて最短 約2分。実際は倒すのに時間がかかるので、5分の制限時間に対して「上手なチームならぎりぎり最後まで行ける」くらいを狙った仮の値です。まだ実際に4人で遊んで調整はしていません。
  • ステージ1は「8方向のどこから来るか」で、ステージ2は「上か下か・橋が落ちた後の守り方」で変化をつけています。
行の中身をすべて見る（ステージ1）全データ

07 · 決めること

ウェーブ1つで決める項目

太字の3つが本番です。残りはだいたい今のままで大丈夫です。

目標撃破数targetKills
この数を倒したら次へ。WAVE 5 ならクリア。ウェーブの長さを決めるいちばん大きなつまみです。
湧きの行spawnEntries
「何秒後に・どこから・どの敵を・何体・何秒かけて」を1行にしたもの。何行でも足せます。出る順番は発生時刻で自動に決まるので、行の並び順は自由です。
目標までくり返すrepeatUntilCleared
基本は ON。行を最後まで出し終えたら、決めた秒数待って最初から出し直します。OFF にすると1回きりで、出る数が目標より少ないと終わらなくなります（ツールが赤い ✖ で教えてくれます）。
くり返すまで（秒）repeatGapSeconds
1周の終わりから次の周までの「息つぎ」。いまは 2秒。
このウェーブの後intervalEvent / restSeconds
合間のイベント（いまは全部「歯みがきタイム」）。空にすると、指定した秒数休むだけになります。WAVE 5 の後は使われません。

空なら「WAVE n」。ふつうは空のままで。

08 · ツールでの入れ方

要塞デザイナーの「敵ウェーブ」タブで入れる

データはステージごとに1ファイル。ツールで変えた数字はすぐ効きますが、ファイルに書き込まれるのは Ctrl+S（File › Save）を押したときです。こまめに Ctrl+S を押してください。

ステージのシーンを開く

Project ウィンドウで Assets/Scenes/Stages/ の Stage1 か Stage2_Bath をダブルクリック。

要塞デザイナーを開いて「敵ウェーブ」タブへ

Tools›要塞›要塞デザイナーを開く→敵ウェーブ

「全体」ページで流れを確認

試合の流れ（WAVE と合間の並び）、目標の合計、難しさの上がり方のグラフ（赤＝目標撃破数、青＝1秒に出る数）、気になる所が出ます。

「WAVE n」ページで目標と行を入れる

「きまり」で目標撃破数を、「湧きの行」の表で行を足して中身を入れます。行をクリックすると、その行だけが開いて編集できます。上のタイムライン（棒グラフ）で、いつ何が出るかが見えます。

Play して試す → 直す

次の「試し方」へ。ウェーブ・敵の数字は Play 中に直しても、Play を止めたあと残ります（湧き位置・障害物を Play 中に動かした分は戻ります）。最後に Ctrl+S。

09 · やりたいこと別ガイド

「〇〇したい」から探す

左の「やりたいこと」のボタンから、ここの各項目へ直接飛べます。まず1行の答えを見て、足りなければ「手順」を開いてください。ツールはすべて Tools›要塞›要塞デザイナーを開く で開く要塞デザイナーです。

敵

敵の数の調整はどこ？

敵ウェーブ›WAVE n›湧きの行›数

行を開いて「数」を変えます。ウェーブ全体をまとめて増減するなら「全部の数を ×倍率」。

手順詳しく
  1. 変えたいウェーブのページ（WAVE 1〜5）を開く。
  2. 「湧きの行」の表で行をクリック → 開いた中の 数 を変える。
  3. まとめて変えるなら、表の上の「数の倍率」に数字（例: 1.2）を入れて 全部の数を ×1.2。
  4. 「かける秒数」で出している行は、数を増やしても出し終わる時間は同じで、密度が上がります。
  5. ページ上の「見積もり」（1周の数・1秒に出る数）が変わるので、目安にしてください。

敵が出るタイミングを変えるには？

敵ウェーブ›WAVE n›湧きの行›発生時刻・かける秒数

「発生時刻」＝GO! から何秒後に1体目を出すか。「かける秒数」＝全部を出し終えるまでの秒数。

手順詳しく
  • 行の並び順は関係ありません。出る順番は発生時刻で決まります（見やすくしたいときは「時刻順に並べる」）。
  • 途中に場面を差し込みたいときは、行を選んで「ずらす秒数」を入れ ○秒以降の行をずらす。
  • 上のタイムライン（棒グラフ）で、いつ・どこから・何が出るかが一目で見えます。棒をクリックすると、その行が選ばれます。
  • 1周を出し終えた後、次の周までの「息つぎ」は、きまりの くり返すまで（秒）。

敵が出てくる場所を変えるには？

敵ウェーブ›湧き位置

行の「湧き位置」を別の場所に変えるか、「湧き位置」ページで場所そのものを動かす・増やします。

手順詳しく
  • 使う場所を変える: 行を開いて「湧き位置」を選び直す。
  • 場所そのものを動かす: 「湧き位置」ページで ドラッグ編集 を ON → Scene ビューでつかんで動かす。
  • 増やす: 「＋ 追加」で Scene ビューの真ん中に作られるので、動かして名前（ID）を付ける。
  • 四方から一斉に: 行を選んで 全ての湧き位置に足す。
  • 湧き位置はシーンの中の物なので、動かしたら Ctrl+S でステージのシーンを保存。

目標撃破数を変えるには？

敵ウェーブ›WAVE n›きまり›目標撃破数

ウェーブの長さをいちばん大きく変えるつまみです。「全体」ページで5ウェーブの合計と上がり方が見られます。

敵の強さ・速さを変えるには？

群衆›敵の種類

種類ごとに「体力」「移動速度」「コアに与えるダメージ」などを変えます。2ステージ共通です。

主な項目詳しく
項目意味
体力倒すのに必要なダメージ。スピキ 10、ボス 150
移動速度1秒に進む距離（m）。スピキ 3
コアに与えるダメージコアに着いたときに削る量
速度のばらつき1体ずつの速さの差。大きいほど群れがばらける

Play 中に変えても、そのまま残ります（その場で手応えを確かめながら調整できます）。

新しい敵の種類を作るには？

群衆›敵の種類›＋ 新しい敵の種類を作成

作った種類は、ウェーブの行の「敵の種類」で選べるようになります。

注意詳しく
  • 見た目は、絵を入れなければ自動の仮の絵で動きます。本番の絵はあとで差し替えられます。
  • 試合ではじめて出たときの NEW ENEMY カードには、「表示名」と「紹介文」が出ます。どちらも同じ「敵の種類」の欄で書けます（紹介文が空だとカードは出ません。30文字まで）。
  • 増やしたら一声かけてください（絵や演出をこちらで用意します）。

障害物

障害物を新規で設置するには？

経路・障害物›障害物・地帯›＋ ボタン

「＋ 破壊可能ブロック」「＋ 壊れない壁」「＋ 通行コスト地帯」のどれかを押すと、Scene ビューの真ん中に置かれます。

3種類の違いと、好きな場所に置くやり方詳しく
種類どうなる
破壊可能ブロックレーザーで壊せる。壊れると敵が通れるようになり、時間で元に戻る
壊れない壁ずっと通れない
通行コスト地帯通れるが遅くなる。敵はなるべく避けて通る（水たまりなど）

クリックした場所にすぐ置く（壊せる物のみ）: 「破壊可能物」タブの「配置」で ▶ Sceneをクリック/ドラッグして配置 → Scene ビューをクリックで置く、ドラッグで好きな大きさで置く、Esc で終わり。最初に「プリセット」の サンプルを作る（木箱・岩・ガラス） を1回押しておくと、「配置する種類」で木箱・岩・ガラスを選べるようになります（押さなければ、ふつうのブロック）。

必ずステージのシーンだけを開いた状態で置いてください。置いた物はステージのシーンの Obstacles の中に入ります。置いたら Ctrl+S で保存。

既存障害物の移動方法は？

経路・障害物›障害物・地帯›選択

一覧の「選択」を押すか Scene ビューでクリックして選び、移動ツール（W キー）でドラッグ。数字で動かすなら一覧の位置を直接書きかえます。

手順詳しく
  1. 一覧で動かしたい障害物の 選択 を押す（Scene ビューにその物が映る）。
  2. Scene ビューで W（移動ツール）→ 矢印をドラッグ。
  3. きっちり合わせたいときは、一覧の位置の数字を直接入れる。
  4. 動かすと敵の通り道は自動で計算し直されます。コアまで行けるかを確認。
  5. Ctrl+S でステージのシーンを保存。間違えたら Ctrl+Z。

障害物の大きさを変えるには？

破壊可能物›Sceneでの表示›リサイズハンドル

壊せる物は、選んで角や辺をドラッグ。壁・地帯は「経路・障害物」の一覧で大きさの数字を書きかえます。

障害物を消すには？

経路・障害物›障害物・地帯›削除

一覧の「削除」を押します（Ctrl+Z で戻せます）。ステージ2の 橋（Bridge）は消さないでください（WAVE 3 で崩れる仕掛け）。

壊せる障害物の硬さ・復活時間は？

破壊可能物›選んだ物の設定›耐久・再生

「耐久値」で硬さ、「再生までの時間(秒)」で壊れてから戻るまでの時間を変えます。

まとめて変える（プリセット）詳しく
  • 同じ種類の物をまとめて変えたいときは「プリセット」を使います。プリセット＝耐久・見た目・演出の設定一式（位置・大きさは入らない）。
  • 1つを調整 → 選択中を新しいプリセットとして保存 → ほかの物を選んで 選択中に適用。
  • 一覧の 同じ種類を選択 で、同じプリセットの物を全部選べます。

スキル玉（スマッシュボール）を置く・動かすには？

スマッシュボール›一覧›スマッシュボール化

スキル玉は「壊せる障害物にスキル玉の機能を足した物」です。破壊可能物を置いてから、一覧で スマッシュボール化。動かし方は障害物と同じです。

浮かせる・止める詳しく
  • 既定では画面の中をふわふわ漂います。「浮遊」を OFF にすると置いた場所から動きません。
  • Play 中は「P1が割る」などのボタンで、割れたときの動き（スキルが使えるようになる）を試せます。

敵がコアまで行けるか確かめるには？

経路・障害物›Sceneでの可視化›湧き位置→コアの予想ルート

Scene ビューに、湧き位置ごとの道が線で出ます。緑＝行ける、赤＝行けない。赤があったら障害物か湧き位置を動かしてください。

ほかの確かめ方詳しく
  • 「敵ウェーブ › WAVE n」の Scene ビューに、このウェーブの敵のルートを表示: ゲームの発表で出る赤い線と同じ道。オレンジの線はコアまで行けない道。
  • 「進行方向の矢印」「距離ヒートマップ」を ON にすると、敵がどう回り込むかが見えます。

試す・その他

特定のウェーブだけ試すには？

敵ウェーブ›WAVE n›▶ WAVE n の発表から

Play 中にそのウェーブのページを開いてボタンを押すと、そこから始め直せます。詳しくは「試し方」。

ステージ2で WAVE 3 以降を試すと橋が崩れます。そのあと WAVE 1・2 に戻しても橋は元に戻らないので、WAVE 1・2 を試すときは Play し直してください。

制限時間を変えるには？

敵ウェーブ›全体›制限時間(秒・0でなし)

今は 300秒（戦っている間だけ減る）。2ステージで同じにしておくのがおすすめです。

保存・提出はどうする？

ツールで変えた数字（ウェーブ・敵の種類）も、湧き位置・障害物も、Ctrl+S（File › Save）を押したときにファイルへ書き込まれます。押さずにコミットすると、変更が入りません。終わったら「提出前チェック」を見て、コミット → push → 一声かけてください。

10 · 試し方

ステージのシーンを開いたまま Play

ステージのシーンだけ開いて Play すると、ゲームに必要な物（Game のシーン）が自動で読み込まれ、そのステージで WAVE 1 から始まります。

KEYBOARD

キーボードで握る

キー意味
Q W O PP1〜P4 が握る（押している間ビーム）
1〜4P1〜P4 のスキルを使える状態にする（テスト用）

キーボードの握りは強さが一定なので、本物のセンサーより弱く感じることがあります。最後は必ず本物で確かめてください。

TOOL

ツールのテスト用ボタン（Play 中）

ボタン意味
▶ WAVE n の発表から開いているページのウェーブから始め直す
目標を倒したことにする今のウェーブをすぐクリア

「WAVE 4 だけ何度も試す」が数秒でできます。

Play しなくても確かめられること詳しく
  • Scene ビューの赤い線：WAVE n ページの「Scene ビューに、このウェーブの敵のルートを表示」を ON にすると、ゲームの発表で出る赤い線と同じ道が見えます。オレンジの線はコアまで行けない道（障害物でふさがれている）です。
  • 見積もり：WAVE n ページに「1周 ○体 / ○秒・1秒に約○体・目標が出そろうまで約○秒」が出ます。全部すぐ倒せたとしたときの最短なので、実際はもっと長くなります。
  • 気になる所：「全体」ページに、終わらないウェーブ・種類が空の行・シーンに無い湧き位置などが一覧で出ます。
4人で遊ぶときの見え方詳しく

本番は4台のPCで、1人ずつ自分の砲台のまわりを映した画面を見ます。1台で試すと全体を見下ろす画面になりがちなので、「この湧き位置の敵は、誰の画面にいつ入ってくるか」を意識すると、本番の手応えに近づきます。どこから来るかは発表の赤い線と、画面のふちの矢印で全員に伝わります。

11 · 設計のコツ

迷ったときの目安

PACE

1ウェーブ 30〜40秒が理想

ふつうに遊んで、1ウェーブがだいたい 30〜40秒で終わるくらいを狙ってください。長さは目標撃破数でいちばん大きく変わります。実際にかかった秒数は Play 中にツールの残り時間で測れます。

TEACH

新しい敵は1ウェーブに1種類

はじめて出る敵には紹介カードが出ます。同じウェーブで2種類が初登場すると、紹介が渋滞します。

DIRECTION

方向で難しさを作る

数を増やす前に、出てくる方向を増やす・ずらすだけで、ぐっと忙しくなります。4人の画面が違うので「誰かの方向に偏る」と、助け合いが生まれます。

BREATH

波に「息つぎ」を作る

ずっと同じ量より、押し寄せる → 少し引く、のくり返しが気持ちいい。発生時刻をずらしたり、くり返しの待ちで作れます。

やりがちな失敗注意
  • 倒しきれない量を出す → コアに着いた敵は撃破数に入らないので、コアが削れるのに目標が進まず、いちばんつらい展開になります。「1秒に出る数」が急に跳ね上がっていないか、グラフで確かめてください。
  • 「くり返し」を OFF にして数が足りない → ウェーブが終わりません（ツールが ✖ を出します）。
  • ボスを同時に出しすぎる → 4人のビームが分散して、どれも倒せなくなります。
  • 湧き位置を障害物の向こうに置く → コアまで行けず、敵がたまります（Scene ビューでオレンジの線になります）。
  • 片方のステージだけ難しくなる → 2ステージは同じくらいの手応えにする決まりです。片方を直したら、もう片方と比べてください。
