    BLUESKILL

    青キャラのスキル — うがい薬を投げて、落ちた場所に水の渦

    スマッシュボールを割ると うがい薬を持ち、
    次の攻撃でそれを投げて 敵を足止めする水の渦 を出す。

    赤スキルと同じ「ゲージ技」です。ボールを割ると、砲台の上に青いうがい薬のボトルがふわっと浮かび、足元に小さな渦、まわりを水の粒がぐるぐる回ります。次に握ると振りかぶって向いている方向へポーンと投げ、落ちた場所で「パシャーン」と破裂。そこに大きな水の渦が数秒間広がり、中の敵はその場で足止めされ、ぐるぐる巻き込まれ、ダメージを受けやすくなります。

    誰が使う
    プランナー（強さ・広さ・時間の調整）／デザイナー（色・演出の調整）／プログラマー（キャラとの紐づけ）
    入れ方
    Tools›青スキル›開いているシーンにスキルを入れる → シーンを保存
    調整する場所
    Tools›青スキル›スキルの設定ファイルを開く（Assets/BlueSkill/Data/BlueVortexSkill.asset）
    今の状況
    テスト用シーン blueskill_test で作成中。スキル欄・配る係・キャラとの対応表は赤スキルと共通（対応表はまだ空）
    01 — What it does

    持って、投げて、
    渦で止める。

    スキルは「溜まる → 持つ → 投げる → 渦」の順に進みます。投げる距離・渦の広さ・足止めの強さ・見た目は、設定ファイル 1 つで変えられます。

    ① 溜まる

    自分のレーザーでスマッシュボールを割る。

    ② 持つ

    砲台の上に青いうがい薬が「ポンッ」と浮かぶ。後ろに青い光、足元に小さな渦、水の粒がまわりを回って吸い込まれ、泡と波紋が出る。落ちる場所に点線の輪と放物線の点線が出る。

    ③ 振りかぶる

    次に握った瞬間、ボトルを後ろへ引いて震わせる（0.35 秒）。砲台の回転がゆっくりになる。

    ④ 投げる

    回りながら放物線を描いて飛ぶ（0.55 秒）。水がこぼれ、床に影。

    ⑤ 破裂・渦

    光・衝撃の輪・水しぶき・ボトルのかけら・画面の揺れ。半径 3.2m の渦が 5 秒。初期値は 3 本持っているので、攻撃のたびに 1 本ずつ、3 回まで投げられる（「まとめて一気に」なら半径 2.4m の渦が一度に 3 か所）。

    ⑥ 消える

    最後の 1 秒はふちが点滅。中心へ吸い込まれるように縮み、しぶきを上げて消える。

    砲台放物線で飛ぶ7m 先に渦（半径 3.2m）
    🔵

    次の攻撃がスキル

    使える状態で次にレーザーを撃ち始めた瞬間に投げる（普段のレーザーは出ない）。

    例：ボールを割ったときに撃っていたレーザーは、離すまで最後まで撃てる。次に Q を押した瞬間に投げる。溜まるたびに 1 回だけ。

    🧊

    足止め

    渦の中の敵はその場から進めなくなる（強さは 0〜1 で調整）。渦から出ると元の速さに戻る。

    例：コアへの通り道に投げると、敵の列がそこで止まって渋滞する。

    🌀

    巻き込み・引き寄せ

    中の敵を渦に沿ってぐるぐる回し、少しずつ中心へ寄せる（真ん中の 1 点には固めない）。

    💧

    デバフ

    中の敵は受けるダメージが 1.5 倍。さらに 0.5 秒ごとに少しダメージ（白く光る）。倒した数は投げた人に入る。

    例：渦に投げてから仲間がレーザーで撃つと、いつもより早く倒れる。

    🫧

    3 本持って 1 本ずつ投げる

    ボールを 1 回割るとボトルを 3 本持ち、攻撃のたびに 1 本ずつ投げる（初期値）。持っている本数が 3 → 2 → 1 と減っていく。

    例：1 本目で通り道をふさぎ、向きが変わったら 2 本目で別の場所へ。投げ方 で「まとめて一気に投げる」「1本だけ（元の動き）」にも切り替えられる。

    🎯

    落ちる場所を調整できる

    距離・左右のずれ・壁の手前で落とすか。持っている間は落ちる場所に目印が出る。設定ファイルを選ぶと Scene ビューにも全砲台の落ちる場所が出る。

    🧩

    どのシーンでも・どのキャラにも

    プレハブを置くだけで全砲台に配られる。赤スキルと同じ対応表でキャラに紐づけられる。

    02 — First 5 minutes

    メニュー 1 回で、
    すぐ試せる。

    1

    シーンに入れる

    試したいシーン（例：Assets/Scenes/blueskill_test.unity）を開き、Tools›青スキル›開いているシーンにスキルを入れる。[BlueSkill] Skill Installer が置かれるので Ctrl+S で保存。

    赤スキルなど別の色と一緒に使うときは 「赤スキルと青スキルを一緒に使いたい」。もう赤スキルの [RedSkill] Skill Installer があるシーンでは、新しく置かずに「全員に配るスキルを青スキルに変えますか？」と聞かれます。青スキルに変える を押すと、その係が青スキルを配るようになります（係は 1 シーンに 1 つ）。

    2

    ▶ Play して溜める

    本番どおりなら Q（P1 の握り）でスマッシュボールを割ります。すぐ試すなら、キーボードの 1〜4 で P1〜P4 を「使える」にできます（エディタだけ）。砲台の上に青いボトルが浮かび、足元に小さな渦が出れば OK。

    3

    握って投げる

    Q を押すとボトルを投げ、点線の輪のところに渦が出ます。撃っている最中に溜まった場合は、一度離してからもう一度押します。

    4

    値を変える

    Tools›青スキル›スキルの設定ファイルを開く。Play 中に変えてもすぐ反映され、Play を止めても残ります。Inspector の下の 今すぐ撃つ ボタンで、握らずに何度でも投げられます。

    P2〜P4 は W O P で握れます。全員まとめて溜めるなら Tools›青スキル›全員を使える状態にする（Play中）。

    03 — Recipes

    「〜したい」から
    探す。

    もっと遠く／近くに投げたい落ちる場所

    落ちる場所（渦を広げる場所） › 落ちる距離（m）（初期値 7）。発射口から測る を OFF にすると砲台の中心から測ります。設定ファイルを選んだまま Scene ビューを見ると、全ての砲台の「今投げたら落ちる場所」と渦の大きさが青い円で出ます。

    投げ方を変えたい（1本ずつ・まとめて一気に・元の 1 本）投げ方（1本・まとめて・1本ずつ）

    設定ファイルの 投げ方（1本・まとめて・1本ずつ） › 投げ方 で選びます。ボトルの数（3）は持つ本数です。

    • 1本ずつ順番に投げる（初期値）：ボールを 1 回割るとボトルを 3 本持ち、攻撃のたびに 1 本ずつ投げる。投げたら一度握るのを離し、もう一度握ると次の 1 本。渦は 1 つずつ（いつもの大きさ）。全部投げ終わるまでは、ボールを割っても本数は増えません。
    • まとめて一気に投げる：3 本を扇形に持ち、次の攻撃で全部投げて 3 か所に渦（下の値で形を調整）。
    • 1本だけ（元の動き）：最初に作ったときと同じ動きに戻ります。ほかの値はそのまま残るので、いつでも切り替えられます。

    まとめて一気に投げるとき の値：

    • 広がる角度（度）（32）：となり同士の向きの差。大きいほど横に広がる。
    • 外側の距離の倍率（0.85）：1 より小さいと弓なり、大きいと V 字。
    • 投げる間隔（秒）（0.06）：真ん中から外へ順に手を離れる。0 で全部同時。
    • 1つの渦の大きさの倍率（0.75）：まとめて投げたときの渦 1 つの大きさ（渦の半径 に掛ける）。
    • 2つ目以降の揺れの強さ（0.35）：画面の揺れが重なりすぎないように弱める。

    渦が重なった所の敵は、渦のダメージを重なった数だけ受けます。

    向きの真正面ではなく、少し横に落としたい落ちる場所

    左右のずれ（m）。＋で向いている方向の右、－で左。

    壁の向こうに落ちないようにしたい落ちる場所

    壁の手前で落ちる を ON。途中に壁・障害物があると、その 壁から離す距離（m）（0.5）手前に落ちます。OFF（初期値）だと壁を飛び越えます。

    落ちる場所の目印を消したい・色を変えたい落ちる場所

    落ちる場所の目印を出す（ON）・目印の色・点線の点の数（14。0 で放物線の点線なし）。

    足止めを弱く（ゆっくり進める）したい敵への効果（デバフ）

    足止めの強さ（1=止まる）。1 で完全に止まり、0.5 で半分の速さ、0 で足止めなし。ふちのやわらかさ（割合）（0.2）を上げると、ふちの方は弱く、中ほど強くかかります。

    ぐるぐる回す・引き寄せる強さを変えたい敵への効果（デバフ）

    渦に巻き込む速さ（m/秒）（1.4。0 で回さない）・中心へ引き寄せる速さ（m/秒）（0.7）・引き寄せない内側（割合）（0.3）。時計回り で回る向き（見た目の渦も同じ向き）。敵の歩く速さの 1.6 倍より速くはなりません。

    渦の中の敵をもっと倒しやすく／倒しにくくしたい敵への効果（デバフ）

    受けるダメージの倍率（1.5。レーザーや爆発のダメージに上乗せ）、渦のダメージ（1回）（1.5）と 渦のダメージの間隔（秒）（0.5）。普通の敵の体力は 10、ボスは 150 です。ダメージのたびに光らせる を OFF にすると白く光りません。

    渦を大きく／長くしたい渦の広さ・時間

    渦の半径（m）（3.2）・渦が続く時間（秒）（5）。広がる・消える速さは 広がる時間（秒）（0.45）・消える時間（秒）（0.6）。消える直前の点滅は 消える前の点滅（秒）（1。0 で点滅なし）。消えたあとも少しだけ足止めを残すなら 消えたあとの足止めの残り（秒）（0.4）。

    投げるまで／落ちるまでを速く・ゆっくりにしたいタイミング（投げる）

    振りかぶる時間（秒）（0.35。0 ですぐ投げる）・飛んでいる時間（秒）（0.55）・放物線の高さ（m）（2.4）・飛んでいる間の回転（回）（1.75）。振りかぶり中の砲台の回転は 振りかぶり中の砲台の回る速さ（0.3。0 で止まる）。

    渦の色・模様を変えたい渦の見た目
    1. 渦の色（中心→ふち）：左が中心の暗い目、右がふち。アルファ（濃さ）を右端で 0 にしておくと、ふちがやわらかく消えます。
    2. 光る部分は 渦の筋の色・ふちの輪の色・中心の輪の色（どれも明るさ込みの HDR 色）。
    3. 模様は うず巻きの本数（4）・ねじれの強さ（4.5）・回る速さ（回/秒）（0.55）・筋のくっきり具合・水の揺らぎ・中心の目の大きさ。
    4. 床が明るくて渦が見えにくいときは 濃さ（床を塗る強さ）（0.85）を上げます。逆回りの渦を重ねる を OFF にすると 1 枚になります。
    渦の演出をもっと派手に／控えめにしたい渦の見た目

    吸い込まれるしぶき（個/秒）（55）・浮かぶ泡（個/秒）（26）・ふちのきらめき（個/秒）（40）・波紋の間隔（秒）（0.55）・つかまった敵の泡（個/秒）（30）・粒の明るさ（2.2）。どれも 0 で出なくなります。画面の揺れは カメラの揺れ › 渦が出ている間の揺れの強さ（0 で揺れない）。

    破裂の瞬間をもっと派手に／控えめにしたい投げる・破裂の演出

    破裂の光の大きさ（倍）・水の王冠のトゲの数・衝撃の輪の数・飛び散るしぶき（個）（150）・しぶきの速さ（m/秒）・ボトルのかけら（個）・わき上がる泡（個）。揺れは カメラの揺れ › 破裂の揺れの強さ。

    うがい薬のボトルの絵を差し替えたい・持ち方を変えたいうがい薬のボトル

    ボトルの絵（空なら仮の絵） に、口（キャップ）が上を向いた絵（スプライト）を入れるだけで差し替わります。空のときはコードで描いた仮の青いボトル（白いラベルに水のしずく）が出ます。大きさは ボトルの長さ（m）・ボトルの幅（m）、持つ位置は 持つ位置（前へ m）・持つ位置（右へ m）・持つ高さ（m）・持つときの傾き（度）。

    溜め（使える状態）の演出を変えたい溜め（使える状態）の演出

    ボトルの後ろの光の色・足元の小さな渦の半径（m）（1.7。0 で出さない）・まわりを回る水の粒（個/秒）・浮かぶ泡（個/秒）・足元の波紋の間隔（秒）・使えるようになった瞬間の輪（m）。振りかぶり中はこれらが 振りかぶり中の強まり（倍）（3）倍まで強くなります。

    効果音を付けたい効果音・追加エフェクト

    効果音・追加エフェクト（D-Drive） の各欄（使えるようになった瞬間・振りかぶり始め・投げた瞬間・飛んでいる間（ループ）・破裂した瞬間・渦が出ている間（ループ）・渦のダメージのたび・渦が消えた瞬間）に D-Drive の SE / VFX を選びます。ゲームの他の演出欄と同じ使い方です（要塞デザイナーのガイドの「演出」）。

    別のシーンでも使いたいメニュー

    そのシーンを開いて Tools›青スキル›開いているシーンにスキルを入れる → 保存。または Assets/BlueSkill/Prefabs/BlueSkill_Installer.prefab をシーンにドラッグ。シーンの全ての砲台に自動で配られます。スキルを配る係がもうあるシーン（赤スキル入りなど）では、新しく置かずにその係の配るスキルを変えます（係が 2 つあると取り合いになるため）。

    キャラに紐づけたい（青キャラだけがこのスキル）対応表
    1. Tools›スキル›スキルの割り当て（プレイヤー・キャラ） の ② キャラごと（キャラ選択を通ってきたときに使う） に、キャラの一覧（色の四角＋ファイル名と id）が並びます。青キャラの行で うがい薬の渦 を選ぶだけで、赤スキルと共通の対応表 Assets/RedSkill/Data/CharacterSkillTable.asset に書き込まれます（共通のファイルなので、触る前にチームに声をかけてください）。
    2. キャラ選択を通ってきたときは、この表が「プレイヤーごと」「全員に配る」より優先されます。
    3. 試すときは Play 中に ③ Play 中に試す › P1 のキャラ などでキャラを選び このキャラで配り直す。キャラ選択の画面を通らなくても、表どおりに配られるか確かめられます。
    赤スキルと青スキルを一緒に使いたい（P1 は赤、P2 は青…）スキルの割り当て
    1. Tools›スキル›スキルの割り当て（プレイヤー・キャラ） を開く。
    2. ① プレイヤーごと（今のテスト用） で P1（Q で握る） に赤（極太レーザー）、P2（W で握る） に青（うがい薬の渦）を選ぶ。空の席は 全員に配るスキル になります。
    3. シーンを保存（Ctrl+S）。

    プロジェクトの中のスキルを自動で探すので、黄・緑のスキルができたら何もしなくても一覧に出ます。見つかったスキルを P1 から順に配る で一度に並べることもできます。Play 中に変えるとすぐ配り直されます（Play を止めると元に戻ります）。

    P2 だけ青スキル（または別の調整）にしたいスキルを配る係

    スキルを配る係の プレイヤーごとのスキル（P1〜P4） の 2 番目に BlueVortexSkill を入れます。別の調整にしたいときは設定ファイルを複製（Ctrl+D）して値を変えたものを入れます。

    !
    今の仕様の注意。振りかぶり中・投げている間も、握っている間は砲台の熱が溜まります（赤スキルと同じ）。「受けるダメージの倍率」は群衆の敵だけにかかります（Actor の敵には足止め・巻き込み・渦のダメージだけ）。ネット対戦では、落ちる場所が PC ごとにほんの少しずれることがあります（敵の動きはホストの渦に合わせて全員同じに見えます）。

    05 — Numbers

    06 — Troubleshooting

    困ったときは
    ここ。

    ボールを割ったのにボトルが出ない・投げない
    1. シーンに [BlueSkill] Skill Installer（または青スキルを配る係）があるか確認。
    2. ボールを割ったときに握っていたままではありませんか？ そのレーザーは離すまで出続けます。次に握った（Q を押した）瞬間に投げます。
    3. オーバーヒート中は撃てないので、冷めるまで待つ。
    渦がどぎついピンク一色（マゼンタ）・四角く見える
    シェーダーが読み込めていません。Console に [BlueSkill] シェーダー … が見つかりません が出ていないか確認し、設定ファイルの シェーダー（通常は触らない） の 3 つが入っているか見てください。
    渦が見えない・敵の上に乗って敵が見えない
    渦の描く順番（renderQueue） を確認してください。2980（初期値）なら床の上・敵の下に描かれます。床の模様にめり込むときは 床から浮かせる（m） を少し上げます。
    敵が止まらない
    足止めの強さ（1=止まる） が 1 か確認。ネット対戦のクライアント側では、ホストの計算結果が届くまでほんの少し遅れて止まります。Scene ビューの つかまっている敵 N が 0 なら、渦の位置に敵がいないか、群衆（SwarmSystem）のないシーンです。
    ネット対戦でも動く？
    はい。各 PC が自分でボトルと渦を出し（通信は増えません）、敵を止める・ダメージを与えるのはホストだけです。止まった敵の位置はいつもどおり全員に届きます。
    07 — Words

    分からない言葉は
    ここで引く。

    デバフ
    敵を弱くする効果。ここでは足止め・巻き込み・受けるダメージ増加・渦のダメージ。
    渦（デバフエリア）
    ボトルが落ちた場所に出る円い範囲。中の敵に効果がかかる（Blue Vortex Area）。
    スキル欄
    砲台ごとに 1 つある「スキルを持つ場所」。赤スキルと共通（Player Skill Slot）。
    スキルを配る係
    シーンに 1 つ置く部品。全ての砲台にスキルを配る（Player Skill Installer）。
    設定ファイル
    スキルの値をまとめたファイル（ScriptableObject）。Play 中に変えても残る。
    群衆の敵
    何千体も同時に動く普通の敵（SwarmSystem）。Actor の敵は 1 体ずつの GameObject の敵（今のプロジェクトにはまだいない）。
    D-Drive
    このゲームの効果音・エフェクトをまとめて管理する仕組み。演出欄はすべてこれで選ぶ。
    08 — For programmers

    赤スキルと同じ
    スキル欄に乗る。

    名前空間 MS2026.Skills.Blue、asmdef MS2026.BlueSkill.Runtime（赤スキルの MS2026.RedSkill.Runtime を参照）。既存のコードは変更していません（公開 API だけ使用）。

    PlayerSkillSlot
    using MS2026.Skills;
using MS2026.Skills.Blue;

var slot = PlayerSkillSlot.Find(playerIndex);   // 砲台のスキル欄（配る係が付ける）
slot.SetSkill(blueVortexSkillAsset);            // 青スキルにする（使える状態は引き継ぐ）
slot.GrantCharge();                             // 溜める
    配る順番キャラ選択の結果＋対応表 → プレイヤーごと → 全員共通（赤スキルと共通）。
    落ちる場所BlueVortexSkill.PredictLanding(turret)。
    BlueVortexArea
    // 渦が出たとき（UI・キャラのボイスなど）
BlueVortexSkillRunner.AnyVortexSpawned += (runner, area) => { /* runner.Turret.playerIndex, area.Center */ };

// スキル以外のきっかけで渦を出す
var area = BlueVortexArea.Spawn(blueVortexSkillAsset, floorPoint, playerIndex);
area.Dismiss();                                  // すぐ消し始める
int trapped = BlueVortexField.AffectedCount;     // つかまっている群衆の敵の数
    効果のかけ方群衆の配列を SwarmSystem.StorageReadable の瞬間に Burst のジョブで書き換え（足止め = speedScale、巻き込み = 速度）。ホストだけ。
