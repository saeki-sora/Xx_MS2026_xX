    REDSKILL

    赤キャラのスキル — 砲台の向きへ、広がっていく極太レーザー

    スマッシュボールを割ると スキルが溜まり、
    次にレーザーを撃った瞬間が 極太レーザー になる。

    格闘ゲームの「ゲージ技」と同じ考え方です。ボールを割ってゲージが満タンになると、発射口に光が灯り、赤い稲妻がビリビリ走ります。そのまま次に握ると、普段の細いレーザーの代わりに、先へ行くほど広がる太いレーザーが数秒間出ます。壁に当たるとそこで止まり、火花と光が飛び散ります。

    誰が使う
    プランナー（強さ・長さの調整）／デザイナー（色・演出の調整）／プログラマー（キャラとの紐づけ）
    入れ方
    Tools›赤スキル›開いているシーンにスキルを入れる → シーンを保存
    調整する場所
    Tools›赤スキル›スキルの設定ファイルを開く（Assets/RedSkill/Data/RedLaserSkill.asset）
    今の状況
    テスト用シーン redskill_testscene で作成中。対応表には赤キャラ（Chara_Alpha）→ 赤スキル、緑キャラ（Chara_Gamma）→ 緑スキル が入っている（2026-10-20）。スキルを配る係のプレハブでは P3 が緑スキル
    01 — What it does

    溜めて、撃って、
    壁で弾ける。

    スキルは「溜まる → 使える → 撃つ」の順に進みます。どの段階の見た目・長さ・強さも、設定ファイル 1 つで変えられます。

    ① 溜まる

    自分のレーザーでスマッシュボールを割る。

    ② 使える

    砲台の上に強力そうな歯磨き粉が「ポンッ」と出てブルブル震え、口に光が灯り、赤い稲妻がビリビリ走って、光の粒が吸い込まれる。次の攻撃（次に Q を押す）は普段のレーザーではなくスキルになる。

    ③ ため

    次に握った瞬間、歯磨き粉が押しつぶされて震えが強くなり、口に光が一気に集まる（0.3 秒）。

    ④ 発射

    衝撃の輪と画面の揺れ。広がる極太レーザーを 3 秒。

    ⑤ 消える

    細くなって消え、普段のレーザーに戻る。

    根元 1.2m先 5.5m壁で止まる
    🔴

    次の攻撃がスキル

    使える状態で次にレーザーを撃ち始めた瞬間に発動。

    例：ボールを割ったときに撃っていたレーザーは、離すまでそのまま出る。次に Q を押した瞬間がスキル（普段のレーザーは出ない）。スキルは溜まるたびに 1 回だけ。

    📐

    広がる極太レーザー

    根元は細く、先へ行くほど太い。撃ち始めは「ドンッ」と膨らんでから落ち着く。

    例：根元 1.2m → 14m 先で 5.5m。

    🧱

    壁で止まって弾ける

    壁・障害物の手前で止まり、当たった場所に光・壁に沿って広がる光・火花・衝撃の輪・小さな揺れ。

    💥

    敵も物も壊せる

    群衆の敵・破壊できる物（箱・スマッシュボール・Actorの敵）にダメージ。倒した数は撃った人に入る。

    🎨

    しま模様のグラデーション

    赤・薄いピンク・濃い赤の斜めのしまが、なめらかなグラデーションでつながって先へ流れる。ふちは赤く光ってにじむ。色はグラデーションの欄で自由に変えられる。

    🧩

    どのシーンでも・どのキャラにも

    プレハブを置くだけで全砲台に配られる。キャラとスキルの対応表を埋めればキャラ選択と連動。

    02 — First 5 minutes

    メニュー 1 回で、
    すぐ試せる。

    1

    シーンに入れる

    試したいシーン（例：Assets/Scenes/redskill_testscene.unity）を開き、Tools›赤スキル›開いているシーンにスキルを入れる。[RedSkill] Skill Installer が置かれるので Ctrl+S で保存。

    2

    ▶ Play して溜める

    本番どおりに溜めるなら、Q（P1 の握り）でレーザーを撃ってスマッシュボールを割ります。すぐ試したいときは、キーボードの 1〜4 で P1〜P4 を「使える」にできます（エディタだけ）。砲台の上に赤い歯磨き粉が出て、ブルブル震えていれば OK。

    3

    握って撃つ

    Q を押すと極太レーザー。撃っている最中に溜まった場合は、一度離してからもう一度押します。

    4

    値を変える

    Tools›赤スキル›スキルの設定ファイルを開く。Play 中に変えてもすぐ反映され、Play を止めても残ります。Inspector の下の 今すぐ撃つ ボタンで、握らずに何度でも試せます。

    P2〜P4 は W O P で握れます。

    03 — Recipes

    「〜したい」から
    探す。

    もっと長く撃ちたい／短くしたいタイミング

    タイミング › 撃ち続ける時間（秒）（初期値 3）。撃つ前の 撃つ前のため（秒）（0.3）を 0 にすると握った瞬間に出ます。

    もっと太く・もっと広がるようにしたい形・大きさ

    形・大きさ › 根元の太さ（m）（1.2）と 先の太さ（m）（5.5）。広がりきる距離（m）（14）を小さくすると、すぐ横に広がります。当たり判定も見た目と一緒に変わります。

    敵が倒れにくい／倒れすぎるダメージ・当たり判定

    群衆の敵へのダメージ（毎秒）（100。普段のレーザーは最大 20、敵の体力は 10、ボスは 150）と 破壊できる物へのダメージ（毎秒）（60）。

    スキル中は砲台を止めたい／普段どおり回したいタイミング

    スキル中の回転速度の倍率（0.3）。0 で止まり、1 で普段どおり。

    レーザーの一部だけが壁に当たったときの止まり方ダメージ・当たり判定

    極太レーザーは横に何本かの「筋」に分かれていて、壁や障害物に当たった部分だけがそこで止まり、当たっていない部分はそのまま先へ伸びます（障害物のかどの位置は細かく探して、きれいに切れるようにしています）。止まった部分の壁ぎわは明るく光り、火花・稲妻・衝撃の輪はその部分から出ます。

    • 筋の数は 横に分ける筋の数（止まる判定）（20）。増やすと細い障害物でも止まりやすくなります（判定は少し重くなる）。
    • 壁ぎわの光は レーザーの色・模様 › 壁ぎわの光（1.2、0 でなし）。
    • 破壊できる物でも止まる を OFF にすると、箱などは止まらずに壊しながら貫通します。Actor の敵（1体ずつの敵）ではいつも止まりません。
    握るのをやめたらすぐ終わるようにしたいタイミング

    離したらすぐ終わる を ON。初期値は OFF（最後まで撃つ）。

    レーザーの色・しま模様を変えたいレーザーの色・模様
    1. しま模様の色（1周ぶん）：左から右へが、しま 1 周ぶんの色です（右端の次は左端につながる）。初期値は赤 → 薄いピンク → 濃い赤 → 薄いピンク。色のキーを 2 つずつ近くに置くと「色の帯」になり、帯と帯の間がなめらかなグラデーションになります。キーの間を広げるほど、ぼんやりしたグラデーションになります。
    2. しまのグラデーションの広さ（0.65）：大きいほど色と色の間が広いグラデーションになります（0 でくっきりした帯、1 でほぼ全部グラデーション）。
    3. しまの形は しま1周の長さ（m）（3.2）・しまの傾き（度）（40。0 で輪切り）・しまが流れる速さ（m/秒）（7。0 で止まる）。しま模様の濃さ を 0 にするとしまが消えます。
    4. 断面の色（中心→ふち）：しまの色に掛け合わされます。初期値は中心が白く、外へ行くほど少しずつ赤くなり、ふちは濃い赤く光ってにじみます。長さ方向の色（根元→先端） も初期値は根元が白っぽく、先へ行くほど赤くなります。
    5. 全体の明るさは 明るさ（1.15）。塗りの強さ（明るい背景用）（0.85）を下げると、しまが薄くなって光っぽくなります。真ん中の白い筋は 真ん中のツヤ。
    スジ模様・ふちのギザギザを減らしたいレーザーの色・模様

    スジの濃さ と ふちのギザギザ を 0 に近づけます。ちらつき も 0 にするとおとなしい光になります。

    溜めの歯磨き粉の絵を差し替えたい・動きを変えたい溜めの歯磨き粉

    設定ファイルの 溜めの歯磨き粉 にまとまっています。スキルを使える間、砲台の上に乗り、スキルのレーザーはこの歯磨き粉の口から出ます。

    • 絵：歯磨き粉の絵（口が上向き） に、口が上を向いた絵（スプライト）を入れるだけで差し替わります。空なら仮の絵（タイトル画面の冒頭の歯磨き粉をお手本にした、縦長で赤いトゥーン調のチューブ。稲妻マーク付き）を使います。大きさは 長さ（m）（3.4）・横幅（m）（1）で合わせます。
    • 置く場所：前へのずらし（m）・横へのずらし（m）。砲台の絵より上に描くには 描く順番（140）を砲台の絵（2）より大きく、レーザー（150）より小さく。
    • 雷：雷の間隔（最短・秒）（0.35）〜雷の間隔（最長・秒）（0.9）ごとに、まわりから太い雷が歯磨き粉に落ちます（ため中は3倍の速さ）。雷の長さ（m）・雷の太さ（倍）。
    • 今にも出そうな動き：震えの大きさ（m）（0.04）・震えの速さ（回/秒）（40。画面の更新より速いと毎フレーム左右に震える）・踏ん張りの強さ（0.06。押しつぶされて力んでいる感じ）・力みの波（回/秒）（1.3。「ぐっ」と強く力む）・震えの角度（度）・ふくらみの大きさ・口からにじむ粒（毎秒）・チューブを走る稲妻（毎秒）・後ろの光の大きさ（倍）。
    • しぼり方（タイトル画面の冒頭の歯磨き粉と同じ）：ため（撃つ前）で真ん中を握り始めてくびれ、ほかがふくらみます。撃っている間はくびれが徐々に徐々に深くなり（撃ち終わりで一番深い）、中身が出てだんだんやせていき、チューブ全体も左右から細くなっていきます（長さは変わりません）。撃つ間に横から縮む割合（0.4。撃ち終わりで4割細くなる。おしりの帯とキャップは少しだけ）。くびれの深さ（0.55）・くびれる高さ（0.45）・くびれの幅（0.09）・ふくらむ大きさ（0.35）・やせる大きさ（0.2）・ためで握る強さ（0.15）。絵を差し替えたら、おしりの帯とキャップがふくらまないよう ふくらむ範囲（下〜上） を合わせます。
    • 撃つとき：撃った反動（m）（後ろへ下がる）。
    • 歯磨き粉を出す を OFF にすると、前と同じく砲台の発射口から撃ちます。
    溜めの光を変えたい溜め（使える状態）の演出

    溜めの光の色・発射口の光の大きさ（m）・吸い込まれる粒の数（毎秒）・吸い込まれる粒の色。使えるようになった瞬間の輪は 使えるようになった瞬間の輪（m）（0 で出さない）。

    ビリビリ（稲妻）を増やしたい・減らしたいビリビリ（稲妻）

    設定ファイルの ビリビリ（稲妻） にまとまっています。溜め中は 溜め中の稲妻の数（毎秒）（22）と 溜め中の稲妻の範囲（m）（2.4）、撃っている間は レーザーにまとわりつく稲妻（毎秒）（30）・ふちから飛び出す稲妻（毎秒）（24）、壁は 当たった場所の稲妻（毎秒）（26）。どれも 0 で出なくなります。色・明るさ・太さ・ギザギザは上の 稲妻の色・稲妻の明るさ・稲妻の太さ（m）・ギザギザの大きさ。

    レーザーをもっと派手に／控えめにしたい派手さ（追加の演出）

    設定ファイルの 派手さ（追加の演出） にまとまっています。どれも 0（または OFF）で出なくなります。

    いちばん上の 演出をレーザーと同じ太さに収める（初期値 ON）で、外側の光・進む輪・壁に沿って広がる光・トゲ状の光・光の粒・ふちの稲妻・走る光の線が、レーザーと同じ太さの中に収まります（横にはみ出さない）。OFF にすると、それぞれの「太さ（倍）」の設定どおり外へ広がります。

    • 光の波：レーザーの中を根元から先へ走る明るい帯。光の波の明るさ（0.9）・光の波の間隔（m）（5）・光の波の速さ（m/秒）（45）・光の波の太さ。
    • 外側の光：レーザーのまわりの大きなにじみ（壁で止まった所では一緒に止まる）。外側の光を出す・外側の光をレーザーの上に重ねる（ON: レーザー全体が光に包まれる／OFF: 後ろに描いて横にはみ出した所だけ見える）・外側の光の太さ（倍）（2）・外側の光の色・外側の光の明るさ（1.5）。
    • レーザーを進む輪：発射口から先へ飛んでいく光の輪。輪を出す間隔（秒）（0.16）・輪の速さ（m/秒）（40）・輪の厚み（m）・輪の色。
    • 発射口の二重の光：後ろで逆向きに回る大きな光。二重の光の大きさ（倍）（1.9）・二重の光のトゲの本数。
    • 撃っている間の画面の揺れ（ゴゴゴ…）は カメラの揺れ › 撃っている間の揺れ（揺れ幅 0.22・回転の揺れ幅 0.7 度）と 撃っている間の揺れの強さ（1、0 で揺れない）。撃った本人の画面だけ揺らしたいときは 撃った本人の画面だけ揺らす を ON。
    発射口の演出

    レーザーに沿って走る光の線（毎秒）（70）と 走る光の線の速さ（m/秒）（45。速いほど長い線）。0 で出なくなります。

    壁に当たったときの演出を派手に／控えめにしたい壁に当たった場所の演出

    火花の数（毎秒）・壁に沿って広がる光の長さ（倍）・衝撃の輪の間隔（秒）（0 で輪なし）。揺れは カメラの揺れ › 当たっている間の揺れの強さ（0 で揺れない）。

    効果音を付けたい効果音・追加エフェクト

    効果音・追加エフェクト（D-Drive） の各欄（使えるようになった瞬間・ため開始・撃ち始め・撃っている間（ループ）・壁に当たり始め・撃ち終わり）に D-Drive の SE / VFX を選びます。ゲームの他の演出欄と同じ使い方です（要塞デザイナーのガイドの「演出」）。

    別のシーンでも使いたいメニュー

    そのシーンを開いて Tools›赤スキル›開いているシーンにスキルを入れる → 保存。または Assets/RedSkill/Prefabs/RedSkill_Installer.prefab をシーンにドラッグ。シーンの全ての砲台に自動で配られます。

    キャラに紐づけたい（赤キャラだけがこのスキル）対応表
    1. Assets/RedSkill/Data/CharacterSkillTable.asset を開き、対応表 に行を足す。
    2. キャラ に赤キャラのファイル（キャラ選択の CharacterDefinition）、スキル に RedLaserSkill。

    P2 だけ別のスキル（または別の調整）にしたいスキルを配る係

    設定ファイルを複製（Ctrl+D）して値を変え、スキルを配る係の プレイヤーごとのスキル（P1〜P4） の 2 番目に入れます。

    04 — Inspector

    見る場所は
    3 つ。

    スキルの設定ファイル（RedLaserSkill）

    強さ・形・色・演出を変えるとき

    • 上から スキルの情報・使えるようになる条件・通常のレーザーとの関係、その下に ▶ で開くまとまり（タイミング／形・大きさ／ダメージ・当たり判定／レーザーの色・模様／溜め（使える状態）の演出／発射口の演出／壁に当たった場所の演出／カメラの揺れ／効果音・追加エフェクト（D-Drive））。
    • 項目にマウスを乗せると説明が出ます。
    • Play 中は一番下に、このスキルを持つ砲台ごとの状態と 使えるようにする／今すぐ撃つ／止める。

    スキルを配る係（[RedSkill] Skill Installer）

    どの席にどのスキルを配るか決めるとき

    • 全員に配るスキル・プレイヤーごとのスキル（P1〜P4）・キャラ選択の結果を使う・キャラとスキルの対応表。
    • テスト用：最初から全員使える（テスト）、数字キー1〜4で溜める（テスト）（エディタだけ）。
    • プレハブでは プレイヤーごとのスキル（P1〜P4） の 3 番目（P3）が緑スキル（GreenMintSkill）。ほかの席は 全員に配るスキル（赤）。
    • Play 中は全砲台の状態とテストボタンが並びます。

    砲台のスキル欄（Player Skill Slot）

    Play 中に 1 台だけ確かめるとき

    • Play すると各砲台（Turret_P0 など）に自動で付きます。
    • 状態：スキルなし／まだ使えない／使える（次に撃つとスキル）／使える（今のレーザーを離したら次で発動）／スキルを撃っている。

    06 — Troubleshooting

    困ったときは
    ここ。

    ボールを割ったのにスキルが出ない
    1. 発射口に光が灯って粒が吸い込まれているか（出ていなければ溜まっていない）。シーンに [RedSkill] Skill Installer があるか確認。
    2. ボールを割ったときに握っていたままではありませんか？ そのレーザーは離すまで出続けます。次に握った（Q を押した）瞬間がスキルです。
    3. オーバーヒート中は撃てないので、冷めるまで待つ。
    レーザーがどぎついピンク一色（マゼンタ）・しまが出ない
    シェーダーが読み込めていません。Console に [RedSkill] シェーダー … が見つかりません が出ていないか確認し、設定ファイルの シェーダー（通常は触らない） の 3 つが入っているか見てください。
    数字キーで溜まらない
    エディタで Play 中だけ有効です。スキルを配る係の 数字キー1〜4で溜める（テスト） が ON か、Game ビューをクリックしてキー入力がゲームに届いているか確認してください。
    ネット対戦でも動く？
    はい。スマッシュボールが割れたことと砲台の状態は全員の PC に届くので、各 PC が自分でスキルを出します（通信は増えません）。ダメージを決めるのはホストだけです。PC ごとに出るタイミングがほんの少しずれることがあります。
    07 — Words

    分からない言葉は
    ここで引く。

    スキル欄
    砲台ごとに 1 つある「スキルを持つ場所」。溜まっているか・撃っているかを覚えている（Player Skill Slot）。
    スキルを配る係
    シーンに 1 つ置く部品。全ての砲台にスキル欄を付けて、スキルを配る（Player Skill Installer）。
    設定ファイル
    スキルの値をまとめたファイル（ScriptableObject）。Play 中に変えても残る。
    対応表
    「どのキャラがどのスキルを持つか」の表（Character Skill Table）。
    ため
    握ってからレーザーが出るまでの短い時間。発射口に光が集まる。
    D-Drive
    このゲームの効果音・エフェクトをまとめて管理する仕組み。演出欄はすべてこれで選ぶ。
    08 — For programmers

    スキルは
    差し替えるだけ。

    名前空間 MS2026.Skills（赤スキルは MS2026.Skills.Red）。asmdef MS2026.RedSkill.Runtime。既存のコードは変更していません（公開 API だけ使用）。

    PlayerSkillSlot
    using MS2026.Skills;

var slot = PlayerSkillSlot.Find(playerIndex);   // 砲台のスキル欄（配る係が付ける）
slot.SetSkill(skillAsset);                      // スキルの差し替え（使える状態は引き継ぐ）
slot.GrantCharge();                             // 溜める（スマッシュボール以外の条件で溜めたいとき）
PlayerSkillSlot.AnyStateChanged += s => { /* UI: s.State, s.IsReady ... */ };
    配る順番キャラ選択の結果＋対応表 → プレイヤーごと → 全員共通（PlayerSkillInstaller.ResolveSkill）。
    発動Ready の状態で LaserTurret.OnStateChanged(Firing) が来た瞬間。
    新しいスキル（例：黄色）
    [CreateAssetMenu(menuName = "MS2026/スキル/イエロー：…")]
public sealed class YellowSkill : CharacterSkill {
    [SkillLabel("跳ねる回数")] public int bounces = 3;
    public override CharacterSkillRunner CreateRunner(PlayerSkillSlot slot)
        => slot.gameObject.AddComponent<YellowSkillRunner>();
}
public sealed class YellowSkillRunner : CharacterSkillRunner {
    public override bool IsActive => _active;
    public override void Activate() { /* 撃ち始め */ }
    public override void Cancel()   { /* すぐ止める（NotifyFinished は呼ばない） */ }
    // 終わったら NotifyFinished();  ダメージは FortressNet.HasSimulationAuthority のときだけ
}
