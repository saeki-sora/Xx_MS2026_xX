    STAGESTUDIO

    ステージ背景スタジオ — 3Dの背景を置いて、敵の流れ方と見え方を整える

    シャンプーや歯ブラシを 置くだけ で、
    敵の群れがその間を
    さらさらと避けて流れる。

    机の上に小物を並べて、上から水をこぼすところを想像してください。水は小物の形に沿って回り込み、すき間を流れていきます。このツールは、Mayaで作った小物（背景オブジェクト）の「床に触れている形」を自動で測り、敵の群れにとっての「水が通れない場所」にします。手前の小物が砲台を隠したら自動で透け、裏に入った敵は影で見えます。

    誰が使う
    プランナー（配置・通り道）／デザイナー（見え方・光）
    開き方
    Tools›ステージ背景›ステージ背景スタジオを開く
    必要なもの
    MayaのFBX（無くても空のステージは作れる）
    今の状況
    2026-10-06 に完成、10-07 に「配置」ページ（ゲーム画面の中で直接さわる）を追加。動作確認は一部（下の注意を参照）
    01 — What you can do

    置くだけで、
    遊べる背景になる。

    見た目のモデルと、ゲームの「通り道」を別々に作る必要はありません。形から通り道を作り、見た目の反応も自動で付きます。

    ⇩

    FBXを落とすだけで取り込み

    中の物が1つずつ背景オブジェクトに。名前から役割（床・壁…）を推測し、Mayaの「上」をゲームの床に自動で合わせます。

    例：bathroom.fbx を落とす → シャンプー・歯ブラシ・コップ・床 が別々に並ぶ

    ✥

    ゲーム画面の中でつかんで動かす

    配置 ページに、P1〜P4・全体のゲームの画面がそのまま映ります。その画面の中で背景をクリックして選び、引っぱると床の上を動きます。ホイールで回す、Shift+ホイールで大きさ、Alt+ホイールで高さ。マス目や隣の物の端にぴたっとくっつきます。

    例：P1の画面でコップをつかんで、砲台にかぶらない所まで引っぱる

    ▣

    4人の画面を並べて確かめる

    4人並べる で P1〜P4 の画面を2×2に並べ、どの画面でもさわれます。右の欄では、欄の名前を左右にドラッグするだけで向き・大きさ・高さを細かく合わせられます（数字を打たなくてよい）。

    例：P1で動かしながら、P3の画面で隠れていないかを同時に見る

    ⤢

    背の高さによる「ずれ」が見える

    遠近のあるカメラでは、背の高い物ほど床の位置から外側へずれて映ります。選んだ視点から見て床のどこに重なって見えるかを色付きの影で、てっぺんのずれを矢印と数字で表示します。

    例：「P1では 1.6m ずれて見える」→ その分、砲台から離して置く

    ▭

    通れない範囲を自動で作る

    床から「壁とみなす高さ」までの形だけを使うので、浮いている部分の下は敵がくぐれます。値を動かすと輪郭がその場で変わります。

    例：横たわった歯ブラシの持ち手（浮いている）の下を敵が通る

    ◐

    手前の物は自動で透ける

    砲台やコアを隠している所だけ、丸く透けます。4人それぞれの視点で自動。手前に来る物ほど便利。

    例：左下のシャンプーがP1の砲台に重なっても、砲台が見える

    👥

    隠れた敵は影で見える

    背景の裏に入った敵の群れは、単色の影（シルエット）で透けて見えます。色と濃さは自由。

    🔥

    レーザーで光る・焦げる・壊れる

    当たった所が赤く光り、当て続けると焦げ跡が残ります。「壊せる壁」にすれば溶けるように消えて道が開きます。

    〰

    群れに押されて揺れる

    敵が押し寄せると、反対側へぷるっと傾きます。見た目だけなので通り道は変わりません。

    📏

    すき間のものさし

    背景どうしのすき間の幅をシーンに表示。敵が通れない（赤）・敵より狭い（黄）・通れる（緑）が一目でわかります。

    ✓

    自動の点検と「直す」ボタン

    道が塞がっていないか、砲台にかぶっていないか、輪郭が古くないか…を数秒ごとに点検。多くは押すだけで直ります。

    スタジオの
    「はじめに」を上から順に。

    名前は「はじめに」ページの ステージの名前 で変えられます。洗面所・台所…のように、いくつでも作れます。

    役割と通れない範囲を整える

    上の帯の 輪郭 をONにすると、シーンビューにオレンジの線で通れない範囲が出ます。壁とみなす高さ を下げると、浮いている部分の下がくぐれるようになります。値を動かすと線がその場で変わります。

    4

    見え方を確かめる

    配置 ページのゲーム画面（P1〜P4・全体）の中で、背景をつかんで動かします。ホイールで回す、Shift+ホイールで大きさ、Alt+ホイールで高さ。右の欄で細かく合わせ、見た目のずれや砲台までの距離も確かめます。見え方 ページでカメラの見え方のカードを押して切り替え、この目線でシーンを編集 の P1〜P4 でシーンビューをそのプレイヤーのゲームのカメラと同じ見え方にできます。隠れチェック に「P2の視点: シャンプーがP3の砲台を隠しています → 透けるので大丈夫」のように出ます。▶ Play して Q でレーザーを当てると光って焦げます。

    5

    点検して、ステージに保存

    点検 ページの赤（要対応）を0にします。多くは 直す ボタンで直ります。最後に上の帯の ステージに保存。シーンを保存するだけではステージに入りません（別のシーンで同じステージを出したときに反映されません）。

    これで「シャンプーと歯ブラシの間を、敵がさらさらと流れる」ステージのできあがり

    03 — Recipes

    「〜したい」から
    探す。

    ゲームの画面を見ながら背景を動かしたい・回したい・大きさを変えたい配置
    1. スタジオ左の 配置 を開く。上の帯の 視点 で 全体／P1〜P4 を選ぶ（4人並べる で4人分を2×2に）。
    2. 選ぶ：画面の中の背景をクリック（オレンジの縁取りが付く）。Shift＋クリックで追加・外す。何も無い所をクリックすると選択が外れます。
    3. 動かす：そのままドラッグ。つかんだ所がマウスに付いてきます。Esc でつかむ前に戻ります。
    4. 回す：ホイール（吸着オンなら15°ずつ）。大きさ：Shift＋ホイール（5%ずつ）。高さ：Alt＋ホイール（5cmずつ）。
    5. 細かく：右の欄の 横 X・縦 Y・向き・幅・奥行・高さ・床から の名前を左右にドラッグ。ボタン（↺90°・+10%・床に下ろす など）でも。
    6. どれも Ctrl＋Z で戻せます（ホイールを続けて回した分は1回にまとまります）。大きさ・高さを変えると、通れない範囲は自動で作り直されます。

    キー操作（画面をクリックしてから）：矢印で少しずらす（Shift で細かく）、Q/E で回す、-/+ で大きさ、PageUp/PageDown で高さ、F でシーンビューに映す。吸着は Ctrl を押している間だけ逆になります。シーンビューでも、背景をクリックすると ステージ配置 ツール（つかんで動かす・黄色い輪で回す・右下の四角で大きさ・↕ の札で高さ）で同じようにさわれます。

    物を床から浮かせたい／床に下ろしたい配置 › 床からの高さ

    配置 ページで選んで、Alt＋ホイール、または右の欄の 床から の名前を左右にドラッグ。▲5cm／▼5cm、まっすぐ床に戻すなら 床に下ろす。ゲーム画面の物の上に「○○・0.40m 浮き」と出ます。

    浮かせた高さが 壁とみなす高さ（初期0.6）より上なら、敵はその下をくぐれます（右の欄に「床から高いので、敵は下をくぐれます。」と出ます）。シーンビューでは物の横の ↕ の札を上下に引きます。

    4人それぞれの画面でどう見えるかを確かめながら置きたい配置 › 視点
    1. 配置 ページの 4人並べる。P1〜P4 の画面が2×2に並び、どの画面でも背景をつかめます。1つの画面で動かすと、ほかの画面もすぐ描き直されます。
    2. 大きく見たいときは 視点 で1人を選ぶ（ウィンドウを広げると画面も大きくなります）。
    3. Unity のシーンビューも同じ見え方にしたいときは、ページ下の シーンビューをこの目線にする。Game ビューの縦横比の枠が出ます。シーンビューを回す・ずらす・拡大縮小すると外れます。
    背の高い物が、置いた所からずれて見えるのを何とかしたい配置 › 見た目のずれ

    遠近のあるカメラ（今のP1など）では、背の高い物ほど画面の外側へずれて映ります。配置 ページのゲーム画面は実際の見え方そのものなので、見えている所を見ながら置けば大丈夫です。

    • 上の帯の 輪郭 をオンにすると、敵が通れない範囲（床の上の本当の位置）が重なり、見た目とのずれが分かります。
    • 右の欄の 見た目のずれ に「P1 1.6m」のように、各視点でてっぺんが何mずれて見えるかが出ます。
    • シーンビューにも出したいときは、ページ下の 見た目のずれをシーンビューに出す で視点を選ぶ（その視点の色の影と矢印）。
    砲台・コアにどれくらい近いか知りたい配置 › 距離

    配置 ページで背景を選ぶと、右の欄の 砲台・コア・湧き位置との距離 に近い順に出ます（例「P1の砲台 1.8m」）。上の帯の 距離 がオンなら、ゲーム画面にも点線と距離が出ます。近すぎ（1m未満）は赤、重なっていると「…に重なっています」。シーンビューにも同じ線が出ます。

    シャンプーと歯ブラシの間を敵に通らせたいオブジェクト・すき間
    1. 上の帯の すき間 をON。シーンビューに2つの間のものさしと幅の数字が出ます。
    2. 緑なら通れます。黄は「敵の体より狭い」（詰まる）。赤は「経路のマス目より狭いので、敵はそこを道だと思っていない」。
    3. 赤のときは、背景を少し離すか、どちらかの 外側への余白 を0にする、または 点検 の マス目を0.25にする（経路の計算が少し重くなります）。
    浮いている部分の下を敵にくぐらせたい通れない範囲

    その物の 壁とみなす高さ を、浮いている部分より低くします（右上の 物の高さ が目安）。例：持ち手が高さ0.4から浮いているなら 0.3。変えたらすぐ作り直す がONなら、輪郭がその場で変わります。

    水たまり・泡の上だけ敵を遅くしたい役割

    役割を ≈ 遅くなる地帯 に。敵の速さの倍率（0.5で半分）と 敵が避けたがる強さ（大きいほど遠回りしてでも避ける）を決めます。レーザーは素通りします。

    Mayaのシーンを丸ごと取り込みたい取り込み
    1. Mayaで小物ごとに名前を付けて（Shampoo, ToothBrush, Plate…）FBXで書き出し、エクスプローラーから Unity の Project ウィンドウへドラッグして入れる。置き場所は Assets/_Game/Stage/Models/ステージ名/（例 Models/Bathroom/bathroom.fbx）がおすすめ。テクスチャも同じフォルダに。Assets/_Game/DDrive/SourceAssets/Model には入れない（D-Drive の倉庫に自動登録されてしまうため）。
    2. 取り込みページの枠に落とす。全部が1つのグループに入っていても、自動で開いて中身を分けます。
    3. 向きが違えば 床の上での向き、大きさが違えば 大きさを合わせる。

    「MARK_」で始まる空のロケーターを置いておくと、取り込んだ後に 砲台・コアを目印に合わせる で位置を合わせられます。

    Mayaで決めた位置に、砲台とコアを置きたい取り込み・目印

    Mayaで MARK_Core、MARK_Turret1〜MARK_Turret4（MARK_P1〜も可）、MARK_Spawn… という名前の空の物を置いて書き出します。取り込むと結果のカードに 砲台・コアを目印に合わせる が出ます。湧き位置も合わせる をONにすると、敵の湧き位置（名前順）も合わせます。

    Mayaでモデルを直した／別のモデルに差し替えたいオブジェクト › モデル

    同じFBXを書き出し直したなら 取り込み直す。別のモデルにするなら 差し替えるモデル に入れて 差し替える。どちらも位置・役割・設定はそのままで、通れない範囲だけ作り直します。

    カメラの見え方を切り替えて確かめたい（真上／斜め）見え方

    見え方ページのカードを押すだけで切り替わり、ステージにも記録されます（次にステージを出すとその見え方になる）。この目線でシーンを編集 の P1〜P4 でシーンビューをその人のゲームのカメラと同じ見え方に（4人の画面で確かめるレシピ）。見え方のプリセット自体は要塞デザイナーの「カメラ」タブで作ります。

    手前の物の透け方を変えたい見た目の反応・反応の共通設定

    物ごとに 砲台・コアを隠したとき を選びます：Hole（隠している所だけ丸く透ける・おすすめ）／WholeFade（全体を薄く）／None（透けない）。丸の大きさ・ぼかしは見え方ページの 反応の共通設定（砲台のまわりの透ける丸の半径、コアのまわりの透ける丸の半径、丸のふちのぼかし）。

    裏に隠れた敵の影の色を変えたい・消したい反応の共通設定

    見え方ページの反応の共通設定の 影の色（アルファ＝濃さ）。全体で消すなら 隠れた敵を影で見せる をOFF、物ごとに消すなら 裏に隠れた敵を影で見せる をOFFにして 専用シェーダーに切り替え を押し直します。

    ステージの明るさ・影の向きを変えたい光

    光ページで太陽の 色・明るさ・照らす向き・高さ・影の濃さ、まわりの明るさ、霧を変えます。動かすとすぐ反映。同じページで このステージのBGM も選べます（D-Driveの番号札）。

    レーザーで壊して道が開く壁にしたい役割 › 壊せる壁

    役割を ◩ 壊せる壁 に。耐久・再生、演出（エフェクト・効果音）、耐久ゲージ・壊れた後（瓦礫を残すか）が出ます。壊れると溶けるように消えて通れるようになり、再生すると溶けた状態から現れます。▶ Play 中は 壊してみる / 直す で試せます。ネット対戦でも壊れ方は全員に同期されます。

    焦げ・光り・揺れの強さを変えたい見た目の反応・反応の共通設定

    物ごとの強さは 光り・焦げの強さ と 揺れの大きさ（重そうな物は小さく）。全体の速さ・色は反応の共通設定の「熱」「揺れ」。▶ Play 中は 熱を当ててみる・揺らしてみる ですぐ試せます。

    はじめに

    ⏱ 最初に開いたとき・次に何をするか迷ったとき
    • 5つの手順。終わると番号が ✓ に変わります。
    • このステージ：ステージの名前・メモ・一覧に出す絵。
    • Mayaで決めておくと楽になる名前（MARK_… と役割の自動推測の決まり）。

    取り込み

    ⏱ MayaのFBXを入れるとき
    • 点線の枠にFBXを落とす（または 取り込むモデル で選ぶ）。
    • 向きと大きさ：中の物を別々にする、Mayaの向きを床に合わせる、床の上での向き、大きさの倍率、基準にする物 ＋ その幅をこの大きさに ＋ 大きさを合わせる、全体の真ん中をゲームの中心に、専用シェーダーに切り替える。
    • 中身（取り込む物と役割）：行ごとに取り込むか・役割を直せます。目印は青い札。
    • 取り込んだ後のカード：砲台・コアを目印に合わせる（湧き位置も合わせる）。

    配置

    ⏱ 背景の位置・向き・大きさ・高さを、ゲームの画面を見ながら決めるとき
    • 上の帯：視点（全体／P1〜P4／4人並べる）、重ねる（輪郭・距離）、吸着（オン、マス目 0.1〜1m、角度 5〜90°、端 なし〜0.5m）。オンの札はオレンジ。
    • ゲーム画面：クリックで選ぶ（オレンジの縁取り）・ドラッグで動かす・ホイールで回す・Shift+ホイールで大きさ・Alt+ホイールで高さ。選んだ物の上に名前と浮き／沈みの量。左上に視点の札。画面の下に操作のまとめ。
    • 右の欄：位置（m）・向き（°）・大きさ（m）・床からの高さ（m）（名前を左右にドラッグ、ボタンでも）、見た目のずれ、砲台・コア・湧き位置との距離、シーンで見る、役割・反応を変える（オブジェクトページへ）。その下に 背景の一覧。
    • シーンビュー：シーンビューをこの目線にする／シーンビューの固定を外す、背景を選んだら配置ツールにする、見た目のずれをシーンビューに出す（なし／全体／P1〜P4、選んでいない物にも）。
    • ウィンドウが狭いと、右の欄はゲーム画面の下に回ります。広げると横に並び、画面も大きくなります。

    オブジェクト

    ⏱ 役割・通り道・反応を決めるとき
    • 左：一覧（名前で検索、役割の札で絞り込み、問題のある物に × ! の印）。ダブルクリックでシーンに映す。Ctrl で複数選ぶと まとめて変える。
    • 役割：5つのボタン＋役割ごとの設定（壊せる壁は耐久・演出・耐久ゲージ・瓦礫）。
    • 通れない範囲：頂点の数・面積・物の高さ・状態（最新／古い）、各設定、作り直す・根元を真ん中へ・形を手で直す・シーンで見る。
    • 見た目の反応：透け方・敵の影・熱・揺れ、Play中のテストボタン。
    • モデル：取り込み直す・差し替える・マテリアルの 専用シェーダーに切り替え / 元に戻す。

    見え方

    ⏱ 4人の画面で邪魔にならないか確かめるとき
    • カメラの見え方：プリセットのカード（押すと切り替え）、この目線でシーンを編集（全体／P1〜P4。シーンビューをゲームのカメラと同じ見え方に固定）、配置ページを開く。
    • 隠れチェック：視点ごとに、どの背景が砲台・コアを隠しているか（クリックでその物を選ぶ）。
    • 反応の共通設定：透け・敵の影・熱・揺れ・壊せる壁の強さと色。このステージ専用にする で他のステージと分けられます。

    光

    ⏱ ステージの雰囲気を決めるとき
    • 光を当てる（OFFでシーンの光のまま）、太陽（色・明るさ・照らす向き・高さ・影の濃さ）、まわりの明るさ（上から・横から・下から）、霧、このステージのBGM。
    !
    太陽は [Stage] Sun として自動で作られます。シーンに別の Directional Light があると明るすぎるので、そちらは消すかOFFに。

    点検

    ⏱ 保存する前・Playする前
    • 要対応（赤）・注意（黄）・お知らせ（青）の数。左のナビの数字も同じ。
    • 各項目に 直す ボタン（ある物だけ）と 選ぶ。
    • 主な点検：置き場所が無い／ステージがシーンに無い／部品が足りない／根元が傾いている／通れない範囲が無い・古い／専用シェーダーでない／砲台・コア・湧き位置にかぶっている／すき間が狭い／湧き位置からコアへ行けない／ステージに保存していない。

    シーンビュー

    ⏱ Unity のシーンビューで直接さわりたいとき
    • ステージ配置 ツール（スタジオを開いた状態で背景を選ぶと自動で切り替わる）：本体をつかんで動かす／黄色い輪で回す／右下の四角で大きさ／↕ の札で高さ。吸着は配置ページの設定と同じ。
    • 選んだ物から砲台・コア・湧き位置までの距離、配置ページで選んだ視点の 見た目のずれ（影と矢印）、シーンビューをこの目線にする 中は Game ビューの枠。
    • 切り替えはすべて 配置 ページ（上の帯と、ページ下の シーンビュー）で行います。

    06 — Troubleshooting

    困ったときは
    ここ。

    敵が背景をすり抜ける／避けない
    1. その物の役割が 壁 か（飾り・床は素通り）。
    2. 点検に「通れない範囲がありません」「古いままです」が出ていないか → 作り直す。
    3. 要塞デザイナーの「経路・障害物」タブの範囲（経路フィールド）の外に置いていないか。
    通れるはずのすき間を敵が通らない
    すき間のものさしが 赤 なら、経路のマス目（初期0.5）より狭いので道として扱われていません。すき間のレシピ を参照。
    透けない・焦げない・影が出ない
    その物のマテリアルが専用シェーダーか確認（点検の「専用シェーダーでないマテリアル」）。専用シェーダーに切り替え を押してください。床は透けない・影を作らないのが正しい動きです。
    取り込んだら小さすぎる／寝ている
    小さい：Mayaの1cmはUnityで0.01なので、大きさを合わせる を使います。寝ている：Mayaの向きを床に合わせる をON／OFFしてみてください。画面上の向きは 床の上での向き。
    シーンを保存したのに、別のシーンでステージを出すと変更が無い
    背景はステージ（Prefab）に保存して初めて入ります。上の帯が「未保存の変更あり」なら ステージに保存。
    「置き場所がありません」と出る／「取り込めません」と言われる

    2026-10-07 まで、Play を止めるたびにこの表示が出てしまう不具合がありました（ヒエラルキーに [Stage] があっても出る）。直してあります。

    1. ヒエラルキーに [Stage] があるか確認。あれば、スタジオのウィンドウを一度クリックすると読み直します（「置き場所を作る」を押しても、すでにあれば二重には作りません）。
    2. Game シーンを開いているか、Prefab の編集画面（青い帯の画面）になっていないか確認。
    3. それでも出る場合は、スタジオのウィンドウを閉じて開き直してください。
    背景をクリックしても、つかんで動かせない
    1. 配置 ページのゲーム画面なら、絵が出ているか（「描いています…」のままなら Unity のウィンドウを一度クリック）。手前に別の物があると、手前の物が選ばれます。隠れた物は右の 背景の一覧 から選んでください。
    2. シーンビューでは、ツールが ステージ配置 になっているか。スタジオを開いていると、背景を選んだときに自動で切り替わります（配置ページ下の 背景を選んだら配置ツールにする がオンのとき）。
    3. シーンビューで黄色い輪のそばの何も無い所を押すと、動かすのではなく回すになります。物の上をつかんでください。
    大きさや高さを変えたら、通れない範囲が変わった
    大きさ・高さを変えると、通れない範囲は自動で作り直されます（浮かせて 壁とみなす高さ より上に行った部分は通れるようになる）。手で直した 形は作り直さず、大きさの倍率だけ掛けます。
    「シーンビューをこの目線にする」がすぐ外れる
    シーンビューを回す・右ドラッグ・ホイールで拡大縮小すると、自由に見たいものとして固定を外します。背景をつかんで動かすだけなら外れません。
    ホイールを回したらページがスクロールしてしまう
    何も選んでいないときは、ホイールはページのスクロールになります。先にゲーム画面の背景をクリックして選んでから回してください。
    役割を「壊せる壁」から変えられない
    スマッシュボールが付いているときは変えられません。要塞デザイナーのスマッシュボールタブで外してから変えます。
    07 — Words

    分からない言葉は
    ここで引く。

    ステージ
    背景一式（洗面所・台所…）。中身のPrefab・カメラの見え方・光・反応の設定・BGMのセット。
    背景オブジェクト
    シャンプー・歯ブラシなど、ステージに置く物1つ。役割を持つ。
    通れない範囲（輪郭）
    真上から見た、敵が入れない形。モデルの形から自動で作る。
    壁とみなす高さ
    床からこの高さまでにある形だけを壁にする値。浮いた部分の下をくぐらせるのに使う。
    経路のマス目
    敵の通り道を計算するときの、床の細かさ（要塞デザイナーの経路フィールド）。これより狭いすき間は道にならない。
    専用シェーダー
    透け・焦げ・光り・溶け・敵の影に対応した、背景用の見た目の計算。色やテクスチャは元のまま。
    シルエット（敵の影）
    背景の裏に隠れた敵を、単色で透かして見せる表示。
    目印（MARK_）
    Mayaで置く空の物。名前でコア・砲台・湧き位置の場所を伝える。
    見た目のずれ（視差）
    遠近のあるカメラで、背の高い物が床に置いた位置より画面の外側へずれて映ること。画面の端にある物・背の高い物ほど大きい。
    吸着（スナップ）
    動かしたり回したりしたときに、マス目・決まった角度・他の物の端にぴたっとそろうこと。Ctrl を押している間は逆になる。
    Prefab
    Unityの「部品の型」。ステージの中身はPrefabに保存され、どのシーンでも同じものを出せる。
    08 — For programmers

    仕組みは
    既存の通路の上に。

    背景の輪郭は普通の PolygonCollider2D＋NavigationObstacle。群衆は既存の流れ場（フロー・フィールド）と壁の距離場で避けるので、群衆側の変更はありません。見た目の反応はすべて各PCで計算し、通信しません。

    MS2026.Stage
    StageRoot.Active.current;                 // 今のステージ（StageSet）
StageRoot.Active.ApplyEnvironment(true);  // 光・反応・カメラの見え方を当て直す
StageProp.All;                            // シーンの背景オブジェクト
prop.GetComponent<StagePropWobble>().Poke(Vector2.right, 6f);
prop.GetComponent<StagePropHeat>().ReceiveLaser(point, 0.3f, Time.deltaTime);
StageLookProfile.Current.ApplyGlobals();  // 透け・影・熱の色を反映
    詳細Docs/Tools/StageStudio_AI_Reference.md。
    配置ページ StageLayoutPage ＝ LayoutToolbar ＋ StagePreviewView（隠しカメラで描いた絵の上で、StagePropShape.Pick と StageMoveSession で直接さわる）＋ PropAdjustPanel。シーンビューの StagePlaceTool も同じ StageMoveSession を使う。大きさ・高さは根元ではなく中のモデルを変える（根元の大きさは1のまま）。
    シェーダーMS2026/Stage/Prop（URP Lit 互換）。群衆の影は別シェーダー MS2026/Fortress/SwarmSilhouette（ステンシル64）で、「隠れた敵を影で見せる」が ON のときだけ描くので、OFF や背景の無いシーンでは負荷は増えません。
