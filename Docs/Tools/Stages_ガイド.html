    STAGESELECT

    ステージ切り替え — 共通の Game に、ステージごとの中身を重ねる

    キャラを決めたら ルーレットでステージが決まり、
    そのステージの 障害物・背景・敵・砲台の位置 で遊ぶ。

    お店のくじ引きのようなものです。全員がキャラを決めると、画面いっぱいにステージのカードが横に流れ、だんだんゆっくりになって 1 枚で止まり「決定！」。そのステージの部屋（シーン）が、全員共通の土台（Game）の上に重なって始まります。土台には通信・カメラ・UI・コア・砲台があり、どのステージでも同じ物を使います。

    誰が使う
    レベルデザイナー（ステージを作る）／プランナー（ルーレット・ステージの選ばれ方）／プログラマー（仕組み）
    最初にやること
    Tools›ステージ›今の Game を共通と Stage1 に分ける（1回だけ）
    調整する場所
    Tools›ステージ›ステージの一覧を開く（Assets/Stages/Resources/StageCatalog.asset）
    今の状況
    コードは完成・コンパイル確認済み。Unity ではまだ「分ける」を押していない・動かしていない
    01 — What it does

    キャラ選択の後に
    ステージ抽選。

    流れは「タイトル → キャラ選択 → ルーレット → ゲーム」。ルーレットは握らなくても自動で回って止まるので、展示会場（キーボード無し）でも止まりません。

    ① 全員決定

    キャラ選択で全員が決める（今までどおり）。

    ② 抽選

    ホスト（P1）の PC がランダムにステージを選び、全員に配る。続けて同じステージにはならない（設定で変えられる）。

    ③ ルーレット

    全員の画面でカードが横に流れ、だんだんゆっくり、少し行き過ぎて戻って止まる → 光って「決定！」（約 3.6 秒＋見せる時間 1.8 秒）。

    ④ 読み込み

    歯磨き粉の幕で隠して、ステージ → 共通の Game の順に読み込む。コアと砲台がそのステージの位置へ移る。

    ⑤ 試合

    そのステージの障害物・背景・敵・クリアの撃破数で遊ぶ。終わったら、ステージも一緒に片付く。

    STAGE ROULETTE（イメージ）

    共通（Game）

    どのステージでも同じ物。

    • 通信・カメラ・UI・握力センサー
    • コア・砲台 4 台・スキルを配る係
    • BGM
    • ステージを読み込む係（[Stage] Bootstrap）

    ステージ（Stage1, Stage2…）

    ステージごとに違う物。

    • 背景（ステージ背景スタジオの [Stage]）
    • 障害物・壁・スマッシュボール・経路
    • 敵の湧き位置・敵を出す係・群衆
    • 試合の決まり（クリアの撃破数・コアの体力）
    • 配置の目印（コアと砲台の位置・カメラの視点）
    02 — First 5 minutes

    メニュー 1 回で
    分けて試す。

    1

    Game を分ける（1 回だけ）

    Tools›ステージ›今の Game を共通と Stage1 に分ける（1回だけ） を押して 分ける。今の Game の中身が Assets/Scenes/Stages/Stage1.unity に移り、仮の Stage2（障害物と湧き位置が左右反対、クリアの撃破数 1.5 倍）・ステージの一覧・ビルドのシーン一覧まで自動で作られます。終わると何をしたかの一覧が出ます。

    2

    Game を Play

    Game を開いて ▶ Play すると、Stage1 が自動で重なって始まります（今までと同じ見た目になるはず）。Stage2 を試すには、ステージの一覧の Default Stage Index を 1 にします（0 が一番上のステージ）。

    3

    ルーレットを見る

    ルーレットは本番の流れ（タイトル → キャラ選択 → ゲーム）でだけ出ます。ビルドした .exe をふつうに起動するか、Unity で Title から Play して、キャラ選択で全員決定してください。

    4

    確かめる

    Tools›ステージ›チェック で、ステージのシーンに足りない物・余計な物（通信の部品など）が無いかを確かめられます。

    分けた後の Game・Stage1 は Git で元に戻せます。

    03 — Recipes

    「〜したい」から
    探す。

    新しいステージを作りたいメニュー
    1. Project ウィンドウで、もとにするステージのシーン（例 Assets/Scenes/Stages/Stage1）を選ぶ。
    2. Tools›ステージ›新しいステージを作る（選んだステージを写す）。次の番号の StageN ができ、ステージの一覧とビルドのシーン一覧に入り、Game と一緒に開きます。
    3. 名前・カードの色は Assets/Stages/Data/Stage_N（Display Name・Subtitle・Theme Color・Thumbnail）。
    ステージの中身（障害物・背景・敵）を直したいメニュー

    ステージのシーンを選んで Tools›ステージ›選んだステージを Game と一緒に開く（編集用）。障害物・湧き位置・経路は [Stage] Content の下、背景は [Stage]（ステージ背景スタジオ）、クリアの撃破数・コアの体力は [Fortress] Match Rules にあります。要塞デザイナー・ステージ背景スタジオはそのまま使えます（両方のシーンが開いていれば OK）。直した物はステージのシーンに保存されます（Game は触らない）。

    このステージだけ砲台・コアの位置を変えたい配置の目印

    ステージのシーンの [Stage] Layout の子 Core・Turret_P1〜P4 を動かす／回します（Z の回転が砲台の向き）。ゲームの始めに、Game のコア・砲台がそこへ移ります。シーンビューでは、コアは水色の丸、砲台はプレイヤーの色の丸と向きの線で見えます。

    Game の砲台を動かして決めたいときは、Game と一緒に開いて砲台を動かし、[Stage] Layout のインスペクターの 今の砲台・コアの位置を目印に写す（その後 Game の変更は保存しない）。

    注意：プレイヤーごとの画面の向き（カメラの視点）は砲台の位置に合わせて作ってあります。位置を変えたら、要塞デザイナーのカメラでそのステージ用の視点を作り、Camera Preset に入れてください。

    ステージごとに難しさ（撃破数・コアの体力・敵）を変えたいステージのシーン

    [Fortress] Match Rules（Clear Kills・Core Max Health など）と、[Stage] Content › EnemySpawnDirector のウェーブ設定を、そのステージのシーンで変えます。

    ステージごとに BGM を変えたいステージ背景スタジオ

    BGM（[Fortress] Bgm）は共通の Game にあります。ステージごとに変えるときは、ステージ背景スタジオでそのステージ（StageSet）の BGM を入れ、Game の [Fortress] Bgm の BGM を空にします（両方鳴らないように）。

    ルーレットの長さ・文字・色を変えたいステージの一覧 › Roulette

    ステージの一覧（Tools›ステージ›ステージの一覧を開く）の Roulette：Spin Seconds（回る秒数 3.6）・Hold Seconds（止まってから見せる秒数 1.8）・Min Laps（最低何周 4）・Overshoot Cards（止まる直前に行き過ぎる大きさ 0.18、0 でぴたっと止まる）・Title（STAGE ROULETTE）・Caption（ステージ抽選中…）・Decided Text（決定！）・Accent・Flash Color・Card Frame（カードの枠の絵）・Stripes（後ろのしま。最初はキャラ選択のしまの絵）。

    ルーレットに効果音を付けたいステージの一覧 › Roulette

    On Start（回り始め）・On Tick（カードが真ん中を通るたび）・On Stop（止まったとき）に D-Drive の SE / VFX を選びます。今は空です。

    作りかけのステージをルーレットに出したくないステージの設定

    そのステージの設定（Assets/Stages/Data/Stage_N）の Include In Roulette を OFF。Game だけで Play するときの Default Stage Index や、bat の -fortress-stage では選べます。

    続けて同じステージになってもよい／ルーレットを出さないステージの一覧

    Avoid Repeat（初期値 ON：前回と同じステージは選ばない）を OFF にすると完全にランダム。Roulette › Enabled を OFF にすると、ランダムに選んだステージへルーレット無しですぐ進みます。ルーレットに出るステージが 1 つだけのときも出ません。

    特定のステージで試したい（Unity・bat）一覧・起動引数
    • Unity：ステージの一覧の Default Stage Index（0 が一番上）。または、そのステージを Game と一緒に開いて Play（開いているステージで始まる）。ステージのシーンだけを開いて Play しても、Game が自動で重なります。
    • テスト用の bat：起動引数に -fortress-stage Stage2（ステージの id・シーン名・1 からの番号のどれでも）。ホストと参加側に同じ値を付けてください。
    ステージのシーンが正しく作れているか確かめたいメニュー

    Tools›ステージ›チェック。Game に「ステージを読み込む係」があるか、各ステージに 配置の目印・群衆・経路・敵を出す係 が 1 つずつあるか、通信の部品（NetworkObject）や砲台・コアの本体が紛れていないか、ビルドのシーン一覧に入っているかを調べます。ビルドの一覧だけ直すなら Tools›ステージ›ビルドのシーン一覧を整える。

    見つかりませんでした。別の言葉で探してください。

    !
    今の仕様の注意。ステージのシーンには通信の部品（NetworkObject）を置かないでください。砲台・コアの本体も Game だけに置き、位置は「配置の目印」で決めます。ホストと参加側は同じビルドを使ってください（ステージの番号のやり取りが増えたため）。
    04 — Inspector

    見る場所は
    3 つ。

    ステージの一覧（StageCatalog）

    ステージの並び・ルーレット・Game だけのときのステージ

    • Common Scene Name（Game）・Stages（上から 1, 2, 3…）・Default Stage Index・Avoid Repeat・Roulette（上の逆引き）。
    • 項目にマウスを乗せると説明が出ます。

    ステージの設定（StageDefinition）

    名前・カードの見た目

    • Stage Id（あとから変えない）・Display Name・Subtitle・Scene Name・Thumbnail（空ならテーマ色の板に番号）・Theme Color・Include In Roulette。

    配置の目印（[Stage] Layout）

    このステージのコア・砲台の位置とカメラ

    • Core Anchor・Turret Anchors（P1〜P4）・Camera Preset・Content（ステージの中身の親。Game がそろうまで止めておく）・Load Common Scene When Alone。
    • ボタン 今の砲台・コアの位置を目印に写す。

    06 — Troubleshooting

    困ったときは
    ここ。

    Game を Play したのにステージが出ない（障害物・敵がいない）
    1. 「分ける」を押しましたか？（押す前の Game は今までどおり全部入り）
    2. ステージのシーンがビルドのシーン一覧に入っているか：Tools›ステージ›ビルドのシーン一覧を整える。
    3. Console に [Stage] で始まる案内が出ていないか。
    ルーレットが出ない
    ルーレットは本番の流れ（キャラ選択の後）でだけ出ます。Game だけで Play したときは出ません。また、ルーレットに出るステージが 2 つ以上必要です（Include In Roulette）。Roulette › Enabled も確かめてください。
    砲台・カメラの向きがおかしい
    ステージの [Stage] Layout の目印と Camera Preset を確かめてください。砲台の位置を変えたステージでは、それに合わせた視点が必要です。
    テスト用の bat で、参加側だけ様子がおかしい
    ホストと参加側に同じ -fortress-stage を付けているか確かめてください（違うと壊せる物の並びが合わず同期しません）。
    ネット対戦でも全員同じステージ？
    はい。ステージを選ぶのはホストだけで、番号を全員に配ります。ステージのシーンはホストが読み込むと、参加側の PC にも同じ順番で読み込まれます（途中参加でも同じ）。
    07 — Words

    分からない言葉は
    ここで引く。

    共通のシーン（Game）
    どのステージでも同じ物（通信・カメラ・UI・コア・砲台）が入ったシーン。
    ステージのシーン
    ステージごとの中身（背景・障害物・敵・試合の決まり・配置の目印）が入ったシーン。Game に重ねて読み込む。
    重ねて読み込む
    今のシーンを残したまま、別のシーンを足す読み込み方（Additive）。
    配置の目印
    そのステージでコア・砲台を置く位置と、カメラの視点を決める物（[Stage] Layout）。
    ステージを読み込む係
    Game に置く部品（[Stage] Bootstrap）。Game だけで Play したときにステージを読み込む。
    ホスト
    4 人対戦でまとめ役になる PC（P1）。ステージを選ぶのもホスト。
    08 — For programmers

    読み込む順番が
    いちばん大事。

    名前空間 MS2026.Stages、asmdef MS2026.Stages.Runtime / .Editor。ロビー側は GameSession.Stage.cs。壊せる物の番号は通信が始まったときに振るので、ステージ → Game の順に読み込む（Game が先に来たら、ステージの中身を止めておく）。

    本番（ロビー経由）
    CharacterSelectController (host) → GameSession.ProceedToGame()
  → TryBeginStageRoulette(): Roster.SetStage(random), phase = StageRoulette
      → 全員: StageRouletteView.Play(catalog, stageIndex)
  → (TotalSeconds 後) ProceedAfterRoulette(): phase = Loading, 幕
      → Character_Select を外す → NGO LoadScene(Stage) → NGO LoadScene(Game)
Game の [Stage] Bootstrap.Awake → StageLayout.TryApply()（コア・砲台・カメラ → 中身を動かす）
Game が外れたら → ホストが NGO UnloadScene(Stage)
    MS2026.Stages
    var catalog = StageCatalog.Load();          // Resources/StageCatalog
var layout  = StageLayout.Active;           // 今のステージの配置の目印
StageLayout.Applied += l => { /* l.definition.DisplayName など */ };
// テスト用の bat: -fortress-stage Stage2
