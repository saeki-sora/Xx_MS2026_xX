    PLAYREC

    録画しながらプレイ — 押すだけでプレイが始まり、止めると MP4 ができている

    再生ボタンの横の ● 録画プレイ を押すだけ。
    何分遊んでも 20MB 以内に自動でおさまるから、
    Discord にそのまま貼れる。

    旅行の写真を決まった容量のメモリーカードに収めるようなものです。短い旅ならきれいな画質で、長い旅なら少し画質を落として枚数を確保する。このツールは「録り終わってから長さを見て画質を決める」ので、途中で録画が切れることがありません。

    誰が使う
    全員（プレイの様子を共有したい人、バグ報告に動画を付けたい人）
    開き方
    Unity 上部のツールバー、再生ボタンの横の ● 録画プレイ。または Tools›録画しながらプレイ
    必要なもの
    何もいりません（Unity Recorder などのインストール不要）
    今の状況
    2026-10-16 追加。コンパイル確認済み、Unity 上での録画の確認はこれから（下の「はじめての 5 分」の最後を参照）
    01 — What you can do

    押す・遊ぶ・止める。
    それだけで動画。

    ⏺️

    ワンボタンで録画プレイ

    押すとプレイが始まり、同時にゲーム画面と音の録画が始まる。プレイを止めると録画も止まる。

    例：4 人対戦の 1 試合を丸ごと録って、チームのチャットに貼る

    📦

    必ず上限サイズ以内

    長さに合わせて解像度・なめらかさを自動で選ぶ。書き出した後に大きさを確かめ、超えていたら自動で縮め直す。

    例：30 秒なら 720p のきれいな動画、5 分なら 360p。どちらも Discord の無料プラン（20MB まで）にそのまま貼れる

    ✂️

    途中で切らない

    「20MB になったら録画終了」ではなく、録り終わってから画質を決めるので、最後まで全部入る。

    例：思ったより試合が長引いても、決着の瞬間まで残る

    🎬

    途中からも録れる

    普通にプレイしている最中でも、ボタンを押せばそこから録画できる。

    例：「あ、今のバグ出そう」と思ったら押す

    🛟

    Unity が落ちても救出

    録画中のデータは少しずつ保存しているので、次に Unity を開いたとき、残っていた分から動画にする。

    🚚

    ほかのプロジェクト・PC へすぐ

    フォルダを選ぶだけで別のプロジェクトへコピー。別の PC 用には zip を作って渡すだけ。

    Discord

    録ったら、そのまま Discord に貼れる

    Discord の無料プランで送れるのは 1 ファイル 20MB まで（2026 年 8 月に 10MB から引き上げ）。このツールの初期設定はちょうどこの 20MB に合わせてあり、しかも少し手前に収めるので、「アップロードしたら大きすぎて弾かれた」が起きません。圧縮サイトで縮め直す手間もいりません。

    Discord 無料の上限
    20MB
    このツールの動画
    約 18MB を目標に
    • MB の数え方が違っても大丈夫：20MB を「100 万バイト × 20 ＝ 2,000 万バイト」で数えています。1MB を 1,048,576 バイトで数える場合（約 2,097 万バイト）より小さいので、どちらの数え方でも上限を下回ります。
    • 余裕を持って作り、できたら測る：最初から上限の約 92% を目標に書き出し、できたファイルの大きさを実際に測って、超えていたら自動で縮め直します。
    • 長くても切れない：10 分録っても 1 時間録っても、画質を自動で下げて 20MB に収めます。決着の瞬間が切れて貼れない、ということがありません。
    • Nitro の人は：設定の 上限サイズ (MB) を Nitro Basic なら 50、Nitro なら 500 にすると、そのぶん高画質で録れます（やり方）。

    ※ Discord の上限は 2026-10 時点の公開情報にもとづきます。Discord は上限を変えることがあるので、変わったら 上限サイズ (MB) を合わせてください。

    02 — First 5 minutes

    まずは
    30 秒録ってみる。

    1

    ボタンを見つける

    Unity 上部のツールバー、▶ ‖ ▶|（再生・一時停止・コマ送り）の並びに ● 録画プレイ があります。

    見当たらないときは Tools›録画しながらプレイ›ツールバーにボタンを表示する を選んでください（Unity 6.3 以降は、新しく入れたツールバーのボタンが最初は隠れている仕組みのため。入れた直後に 1 回だけ自動で表示にしています）。メニューの Tools›録画しながらプレイ›録画プレイ（開始・停止） や Ctrl+Shift+Alt+R でも同じことができます。

    Unity ツールバー
    ● 録画プレイ▶‖▶|
    並び順は Unity の版や設定で少し変わります
    2

    押して、遊ぶ

    押すとプレイが始まり、ボタンが ■ 録画停止 0:12 のように録画時間の表示に変わります。ボタンにマウスを乗せると「今止めると何 p・何 fps になるか」が出ます。

    録画中
    ■ 録画停止 0:12▶‖▶|
    3

    いつも通りプレイを止める

    Unity の ▶ ボタンでプレイを止めると、録画も止まり、裏で動画への書き出しが始まります。右下に 録画を書き出し中 の進み具合が出ます。そのまま別の作業をしていて大丈夫です。

    4

    できた動画を見る

    書き出しの進み具合は、ボタンを右クリックすると一番上に出ます。書き終わると保存先フォルダ（プロジェクトの中の Recordings）が自動で開きます。Console に大きさ・解像度・長さが出ます。

    ファイル名は「プロジェクト名_日時.mp4」。そのままチャットに貼れます

    5

    最初の 1 回だけ確認してほしいこと

    このツールはまだ Unity 上で録画を試していません。最初の動画で次を見てください。

    • 上下さかさまになっていないか → なっていたら 設定の「上下反転の補正」
    • 色が暗すぎ・明るすぎになっていないか
    • 音と映像がずれていないか
    03 — Recipes

    「〜したい」から
    探す。

    プレイの途中から録りたいボタン

    普通にプレイしている間、ボタンは ● ここから録画 になっています。押した瞬間から録画が始まります。

    プレイは続けたまま、録画だけ止めたいボタン

    録画中のボタン ■ 録画停止 を押すと、録画だけ止まってプレイは続きます。動画への書き出しはプレイを止めてから始まります（プレイ中は書き出しを休んで、ゲームを重くしないため）。

    一時停止した時間は動画に入る？一時停止

    入りません。Unity の ‖（一時停止）中は録画の時計も止まり、ボタンは ‖ 録画一時停止 になります。

    さっき録った動画をすぐ見たい右クリック

    ボタンを右クリック → 最後の録画を再生。フォルダを開くなら 録画フォルダを開く。

    書き出しがあとどのくらいで終わるか知りたい右クリック

    ボタンを右クリックすると、一番上に 書き出し中 45%・残り約 0:20（720p 30fps） のように今の進み具合が出ます。待っている録画があれば 書き出し待ち ○ 本 も出ます。進み具合の画面を開く で Unity の進み具合の画面（バックグラウンドタスク）も開けます。残り時間はしばらく書き出してから出ます。サイズを超えて縮め直しているときは「（縮め直し 1 回目）」と出て、% は 0 からやり直しになります。

    失敗した録画を捨てたい書き出し中

    右下の 録画を書き出し中 の × を押す → 捨てる。書き出しを続ける を選べば続きから書き出します。書き出し済みの動画は保存先フォルダからふつうに消してください。

    Discord に貼りたいそのままで OK

    初期設定（上限サイズ (MB) 20）のままで、Discord の無料プランの上限（1 ファイル 20MB）に収まります。Recordings フォルダの mp4 を Discord のチャットにドラッグするだけ。右クリック → 録画フォルダを開く で場所がすぐ開きます。

    Nitro Basic（50MB）や Nitro（500MB）の人は Edit›Preferences›録画しながらプレイ の 上限サイズ (MB) をその数字にすると、長い録画でも高画質のまま送れます。ただし、受け取る側ではなく送る人のプランで決まるので、チームの誰が送っても大丈夫にしたいなら 20 のままがおすすめです。

    10MB 以内にしたい（送り先の上限が小さい）設定

    Edit›Preferences›録画しながらプレイ の 上限サイズ (MB) を 10 に。設定画面の下に「録画の長さと画質の目安」の表が出るので、何分ならどのくらいの画質か確かめられます。

    短い録画をもっときれいに／なめらかにしたい設定

    最大の解像度 を 1080、最大の fps を 60 に。ただし、そのぶん「長い録画で画質が下がり始めるまでの時間」が短くなります（同じ 20MB を細かい絵に使うため）。

    長く録っても画質を落としたくない考え方

    20MB という箱の大きさは変わらないので、長いほど 1 秒あたりに使える量は減ります。方法は 2 つ：上限サイズ (MB) を上げる、または見せたい場面だけ 途中から録る／録画だけ止める で短く切る。

    音はいらない設定

    音も録る を OFF。そのぶん映像に容量を回せます。なお ON のままでも、長い録画で音が容量を圧迫するときは自動でモノラル → 音なしに切り替わります（Console に「音あり(モノラル)」「音なし」と出ます）。

    動画が上下さかさま設定

    上下反転の補正 を 自動 から 反転する／反転しない のうち、今と逆になる方に変えてもう一度録ってください。

    保存先を変えたい設定

    保存先フォルダ の 選ぶ…。初期値の Recordings は Git に入らない場所なので、動画がリポジトリに混ざりません。ほかの場所にするときは Git に入らないか気をつけてください。

    自分の別のプロジェクトにも入れたい右クリック
    1. ボタンを右クリック → ほかのプロジェクトに入れる…。
    2. 入れたいプロジェクトのフォルダ（Assets がある場所）を選ぶ。
    3. そのプロジェクトを Unity で開くと、ボタンが出ます。

    もう入っているときは「上書きしますか？」と聞かれるので、最新版に入れ替えられます。

    ほかの PC・ほかの人に渡したい右クリック
    1. 右クリック → 配布用 zip を作る…（初期の保存先はデスクトップ）。
    2. zip を渡す。受け取った人は展開して、中の com.ms2026.playrecorder フォルダを自分のプロジェクトの Packages フォルダへドラッグするだけ。zip に 入れ方.txt も入っています。

    Unity 2021.3 以降なら動きます。Unity Recorder などのインストールは不要です。

    外したいフォルダを消す

    プロジェクトの Packages/com.ms2026.playrecorder フォルダを消すだけです。ゲーム本体には何も残りません。

    見つかりませんでした。別の言葉で探してください。

    04 — Screens

    ボタンの文字で
    今の状態が分かる。

    ツールバーのボタン

    いつも表示。文字が状態に合わせて変わります。

    • ● 録画プレイ：止まっているとき。押すとプレイ＋録画が始まる。
    • ● 録画プレイ（書き出し 45%）：前の録画を裏で書き出し中。押せば次の録画も始められる（書き出しはプレイ中は休み、後で再開）。
    • ● 録画準備中…：押した直後、プレイが始まるまで。
    • ● ここから録画：録画せずにプレイ中。押すと今から録画。
    • ■ 録画停止 1:23：録画中。押すと録画だけ止まる。
    • ‖ 録画一時停止 1:23：Unity の一時停止中（録画の時計も止まっている）。
    • 右クリック：一番上に 今の状態（押せない行。例「書き出し中 45%・残り約 0:20（720p 30fps）」「書き出し待ち 1 本」「録画中 1:23（今止めると 720p 30fps）」「書き出し中の録画はありません」）、その下に 進み具合の画面を開く ／ 録画フォルダを開く ／ 最後の録画を再生 ／ 設定… ／ ほかのプロジェクトに入れる… ／ 配布用 zip を作る…

    設定画面

    Edit›Preferences›録画しながらプレイ（右クリック → 設定… でも開く）。この PC の Unity 全体で共通の設定です。

    • 上：上限サイズ・画質の上限・音・保存先・上下反転。
    • 中：録画の長さと画質の目安（0:30〜20:00 で何 p・何 fps になるか）。設定を変えるとすぐ変わる。
    • 下：ほかのプロジェクトに入れる…、配布用 zip を作る…、既定値に戻す。

    06 — Troubleshooting

    困ったときは
    ここ。

    ボタンが見当たらない
    1. Tools›録画しながらプレイ›ツールバーにボタンを表示する を選ぶ（Unity 6.3 以降は、新しいツールバーのボタンが最初は隠れているため）。
    2. それでも無ければ Tools›録画しながらプレイ›録画プレイ（開始・停止） か Ctrl+Shift+Alt+R。
    3. Console に赤いエラーが出ていてスクリプトがコンパイルできていないと、ボタンもメニューも出ません。
    動画が真っ黒・止まった絵のまま
    録画は Game ビューに映っている絵を取ります。プレイ中に Scene ビューのタブを前に出していると Game ビューが描かれず、絵が止まることがあります。Game ビューを表示したままプレイしてください。
    書き出しが終わらない／進まない
    書き出しはプレイ中は休みます。エディタに戻ると続きから進みます。スクリプトを書き換えてコンパイルが走ると、その録画の書き出しは最初からやり直しになります（録画データは消えません）。
    Console に「上限を少し超えました」と出た
    5 回縮め直しても届かなかったときの表示です（動画は保存されています）。設定の 最大の解像度 を下げるか 音も録る を OFF にすると収まりやすくなります。
    Discord で「ファイルが大きすぎます」と出た
    1. 設定の 上限サイズ (MB) が 20 以下になっているか（Nitro 用に大きくしていないか）。
    2. Console の「保存しました」の行に出ている大きさが上限以下か。「上限を少し超えました」と出ていたら、最大の解像度 を下げるか 音も録る を OFF にしてもう一度。
    3. Discord が上限を変えた可能性もあります。そのときは 上限サイズ (MB) を新しい上限に合わせてください（10 にすれば旧上限の 10MB にも収まります）。
    Unity が録画中に落ちた
    次に同じプロジェクトを開くと、残っていた分から自動で動画にします。Console に「前回 Unity が録画中に終了したため、残っていた分から復元しました」と出ます。
    一時ファイルはどこ？ 容量は？
    プロジェクトの Library/PlayRecorder/Sessions/ に、録画 1 回ごとのフォルダができます。書き出しに成功すると自動で消えます。720p の間は 1 秒あたり数 MB 使いますが、長くなるほど取り込みの細かさも自動で下げるので増え方はゆるやかになります。失敗したもの（failed.txt 入り）は残るので、いらなければ手で消してください。
    07 — Words

    分からない言葉は
    ここで引く。

    解像度（720p など）
    動画の縦の細かさ。720p は縦 720 点。数字が大きいほどくっきりして、ファイルも大きくなる。
    fps
    1 秒あたりのコマ数。30fps なら 1 秒に 30 枚。多いほど動きがなめらか。
    ビットレート
    動画 1 秒あたりに使うデータ量。上限サイズ ÷ 長さ で決まる。
    書き出し（エンコード）
    一時保存した絵と音を、MP4 という 1 本の動画ファイルにまとめる作業。
    MP4
    いちばん一般的な動画の形式。チャットやスマホでそのまま再生できる。
    Packages フォルダ
    Unity プロジェクトの、Assets と同じ場所にあるフォルダ。ここにツールのフォルダを入れると Unity が読み込む。
    08 — For programmers

    Unity 内蔵の
    MediaEncoder だけ。

    エディタ専用の自己完結パッケージ（名前空間 MS2026.PlayRecorder.Editor、すべて internal、依存なし、"unity": "2021.3"）。ゲームのビルドには入りません。GameObject に付ける 2 つの部品（画面と音の取り込み係）だけは、エディタ専用アセンブリだと付けられないため Hooks/（defineConstraints: UNITY_EDITOR でエディタのときだけコンパイル）に分けています。

    capture pipeline
    WaitForEndOfFrame
  → ScreenCapture.CaptureScreenshotIntoRenderTexture(full)
  → GpuScale.Blit(full → small, 半分ずつ縮小 + 上下反転)   // small = RecordingPlan.CaptureRung(経過秒)
  → AsyncGPUReadback.Request(small, RGBA32)
  → FrameStoreWriter（別スレッド）: ImageConversion.EncodeArrayToJPG(q88)
       → Library/PlayRecorder/Sessions/<日時>/frames.bin + frames.idx
AudioListener の GameObject に PlayRecorderAudioTap（OnAudioFilterRead、読むだけ）
  → audio.raw（float、無音ですき間埋め）
    時計エディタ一時停止の時間を除いた実時間。
    再生開始ドメインリロードをまたぐため SessionState に「次のプレイで録画」印。
    RecordingPlan
    videoBps = (limit*0.92 - 64KB - audioBytesPerSec*秒) * 8 / 秒
段 = 1080p60, 1080p30, 720p30, 540p30, 480p30, 360p30, 360p24, 288p20, 240p15, 180p12, 144p10
     （設定の最大解像度/fps と元画面で切りそろえ）
選ぶ段 = bpp(= videoBps / (幅*高さ*fps)) ≥ 0.07 の中で一番上。bps は 0.2 bpp で頭打ち
音   = ステレオ(予算の25%以下) → モノラル(40%以下) → なし   ※AAC の実サイズは 6 秒試し書きで実測
書き出し後: サイズ > 上限 → 実測の超過率で bps を縮め、必要なら段も下げて再エンコード（最大 5 回）
