    音・エフェクト・演出を
    「番号札（ID）」で預かる倉庫。
    中身はいつでも 入れ替えられる。

    たとえるなら「クローク（荷物預かり）」。プログラマーは「この場面で SEID.TurretFire の札の物を出して」とだけ書きます。札の中身（どんな音か・音量・エフェクトの見た目）はデザイナーやプランナーが専用の画面で作り、後から何度差し替えてもコードを直す必要がありません。

    誰が使う
    デザイナー・プランナー（中身を作る）／プログラマー（札を使う 1 行を書く）
    入口
    Tools›D-Drive›Asset Browser（全部ここから）
    置き場所
    Assets/_Game/DDrive/（素材の投入口は SourceAssets/）
    今の登録数
    効果音 1 個だけ（「和太鼓でドン」＝ SEID.Se。砲台がレーザーを撃った瞬間に鳴る）
    01 — The idea

    3 人の分業で
    作業がぶつからない。

    🎫

    番号札（ID）

    素材を作ると自動で付く名前。ファイル名から作られます。

    SEID.TurretFire
    🗄️

    倉庫の中身（Data）

    デザイナー・プランナーが専用の画面で作る。音そのもの、音量、出す位置…。

    SE_Turret_Fire.asset
    ⌨️

    呼び出し（コード）

    プログラマーは札を渡して「鳴らして」と書くだけ。

    Audio.PlaySe(…)
    !
    中身がまだ無くても、ゲームは止まりません。札だけあって中身が空だと、無音やピンクの仮の球（Placeholder）で代わりに動きます。「音が鳴らない」「ピンク色の球が出る」は、たいてい中身の登録漏れです（→ 困ったとき）。
    02 — What goes in

    倉庫に入れられる
    18 種類。

    太字が、このゲームでまず使いそうなもの。それぞれに専用の編集画面があります。

    🔊

    サウンド

    効果音（SE）・BGM。音量・ピッチ・聞こえる距離・連打防止。環境音を場所に置くことも。

    ✨

    ビジュアル

    エフェクト（VFX）・出す位置（Anchor）・配置セット（並べて一斉に出す）・マテリアル・テクスチャ。

    🎬

    演出

    演出（Presentation）＝SE・エフェクト・揺れ・ヒットストップを 1 本にまとめた物。画面の揺れ・パッドの振動・カットシーン。

    🧍

    キャラ・物

    モデル・3D アニメ・2D アニメ・Prefab（弾やギミックなど、ゲーム中に出す物）。

    🖥️

    UI

    UI 画面（Canvas）・UI の動き（59 種のプリセット）・ボタン／スライダーの見た目。

    🔢

    調整値

    Web の発注ツールで管理する数値をゲームに取り込む（使う場合のみ）。

    03 — First 5 minutes

    効果音を 1 つ
    登録して鳴らす。

    1

    音のファイルを「投入口」に置く

    音のファイル（.wav / .mp3 / .ogg）を Assets/_Game/DDrive/SourceAssets/Se/ の下の、分類用のフォルダに入れます。例：SourceAssets/Se/Turret/Fire.wav

    数秒待つと、倉庫の中身（SE_Turret_Fire.asset）と番号札（SEID.TurretFire）が自動で作られます。

    !
    ファイル名は英語で。日本語だけの名前（例：和太鼓でドン.mp3）だと札の名前が作れず、全部「Se」になってぶつかります。日本語名は後で「Display Name」に付けられます。
    Assets/_Game/DDrive/ ├─ SourceAssets/ # ← ここに素材を置く │ ├─ Se/ │ │ └─ Turret/ │ │ └─ Fire.wav # 置いた │ ├─ Bgm/ Vfx/ Model/ … ├─ GameData/ # 自動で作られる中身 │ └─ Audio/SE/Turret/ │ └─ SE_Turret_Fire.asset └─ Generated/ # 番号札の一覧（触らない）
    2

    Asset Browser で試聴して、名前と音量を整える

    Tools›D-Drive›Asset Browser を開き、一覧から選んで下の ▶ 再生。ゲームを動かさずに鳴ります。Inspector で Display Name を「砲台の発射音」のような日本語に、Volume（0〜1）で音量を調整。

    Asset Browser に音のファイルを直接ドラッグ＆ドロップしても登録できます（表示名と英語の識別子を入力）。

    3

    Validation で確認する

    Tools›D-Drive›Validation›Run All。赤（Error）が無ければ OK。よく出る黄色（Warning）は「Mixer が未割当」。修正 ボタンが出ている物は押すだけで直ります（Ctrl+Z で戻せる）。

    4

    プログラマーに札の名前を伝える

    「砲台の発射音は SEID.TurretFire です」と伝えれば、プログラマーがその札を鳴らす 1 行を書きます。すでに鳴らす場所が決まっている札なら、中身を差し替えるだけでコード修正は不要です。

    これで登録の流れは全部です。エフェクトや演出も「作る → 調整 → Validation」の同じ流れです

    04 — Recipes

    「〜したい」から
    探す。

    今の効果音（和太鼓）を別の音に差し替えたいAsset Browser

    Asset Browser で「和太鼓でドン」を選び、Inspector の Clips の音を新しい音のファイルに差し替えます。札（SEID.Se）は変わらないので、砲台の発射音がそのまま新しい音になります。音を切り詰めたいときは ▶ 〜 Editor で開く（Audio Editor）で波形を見ながらトリミング。

    毎回少しずつ違う音にしたいSE の設定
    • Clips に複数の音を入れ、Select Mode を Random（毎回ランダム）か RoundRobin（順番に）。
    • Pitch Range を例えば 0.95〜1.05 にすると、鳴るたびに少し高さが変わります。
    連打で音が重なりすぎる／逆に鳴らないことがあるSE の設定
    • Max Concurrent：同じ音が同時に鳴れる数（既定 8）。超えると一番古い音が止まる。
    • Cooldown Sec：この秒数以内の連続再生は無視（既定 0.03 秒）。「鳴らないことがある」なら小さく。
    近づくと聞こえる環境音を置きたいSeEmitter
    1. その音の Loop を ON、Spatial を Anchor、Min / Max Distance で聞こえる範囲を決める。
    2. Hierarchy で右クリック D-Drive›SeEmitter を置き、Se Id 欄で音を選ぶ。プログラム不要で、その物がある間鳴り続けます。
    エフェクトを登録したいVFX

    エフェクトの Prefab を SourceAssets/Vfx/分類/英語名.prefab に置くか、Asset Browser の 新規 で VFX を作って Prefab を割り当てます。VFX Editor ではシーンで再生しながら位置・色を調整できます。Life Mode（一回で終わる／ループ／秒数指定）にも注意。

    スマッシュボールを割ったときなどの「画面の揺れ」を作りたいShake
    1. Asset Browser の 新規 で揺れ（Shake）を作る。
    2. Tools›D-Drive›Editors›Shake / Haptics で波形を見ながら揺れ幅・周波数を調整し、実際に揺らして確認。
    3. 要塞デザイナーの「カメラ › 演出（揺れ・寄り）」で揺らし方を D-Driveの揺れアセット にして、作った揺れを選ぶ。
    「斬撃」のように、音・エフェクト・揺れをまとめた演出を作りたいPresentation Editor
    1. Tools›D-Drive›Presentation Editor を開き、＋ 新規作成。
    2. Asset Browser から SE・VFX・揺れなどをタイムラインへドラッグ＆ドロップ。種類ごとのレーンに並びます。
    3. 各トラックの Trigger を「開始から ○ 秒後（At Time）」か「コードから合図が来たら（On Signal）」に。
    4. 「モデル選択」→「配置」→ ▶ 再生 で、全部まとめて確認。On Signal は再生中に Signal レーン のボタンで試せます。

    下の「演出を体験」で動きをイメージできます。

    オンライン対戦で、相手の画面にも演出を出したい演出の設定

    演出の Flags › Net を Cosmetic に（既定の Local だと自分の画面だけ）。揺れ・振動・ヒットストップを関係者だけにしたいときは、そのトラックの Scope を Participants Only に。

    ゲームで音が鳴らない／ピンクの球が出るValidation

    まず Validation›Run All。「カタログ未登録」「Addressables 未登録」「Placeholder」が出ていたら 修正。Project 上でコピーしたり、別の場所から持ってきたデータでよく起きます。

    どこからも使われていない素材を片付けたい未使用アセット

    Tools›D-Drive›未使用アセット（Asset Browser の 未使用... ボタンも同じ）。削除は Asset Browser の 削除... から行うと、使っている場所を確認しながら安全に消せます。Project ウィンドウで直接消さないでください。

    名前を日本語で分かりやすくしたいDisplay Name

    Inspector の Display Name は日本語で自由に付けられます（検索にも使われる）。ファイル名や札の名前はツールが決めるので、手で変えないでください。

    D-Drive 公式の詳しいマニュアルを読みたいマニュアル

    Tools›D-Drive›マニュアルを開く。再生ボタンの右の ？ マニュアル ボタンでも開けます（見当たらないときはツールバーの空きを右クリック →「D-Drive/Manual」にチェック）。マニュアル内の Assets/GameData などは、このプロジェクトでは Assets/_Game/DDrive/GameData に読み替えてください。

    見つかりませんでした。別の言葉で探してください。

    05 — Try a presentation

    演出（Presentation）は
    こう動く。

    「剣攻撃」の演出の例です。▶ 再生 を押し、途中で ⚡ 当たった！ を押してみてください。点線のトラックは「合図待ち」で、合図が来た瞬間に鳴ります。

    PRESENTID.SwordSlash — 全体 1.20 秒
    ▶ を押すと「開始から ○ 秒後」のトラックが順に鳴ります。

    実線 ＝ At Time（開始から ○ 秒後）

    振りかぶりのアニメ・剣の軌跡エフェクト・風切り音など、必ず決まったタイミングで出るもの。

    点線 ＝ On Signal（合図が来たら）

    「当たった」はゲームが判定するので、コードから合図（hit）が来たときだけ、ヒットストップ・打撃音・揺れ・振動を出す。

    !
    合図待ちのトラックだけで作った演出は、Total Duration（全体の長さ）を入れないと 0 秒ですぐ終わってしまいます。
    06 — Screens

    覚える画面は
    4 つ。

    Asset Browser

    ⏱ 素材を探す・作る・試聴する（すべての入口）
    • 検索欄：日本語の表示名・カテゴリ・タグ・説明文でも探せる。
    • 種別メニュー：All／Se／Bgm／Vfx…で絞り込み。
    • 新規：新しい素材を作る（名前・置き場所・登録を全部自動で）。
    • 未使用...：どこからも使われていない素材。削除...：安全に削除。
    • プレビューバー（一番下）：音の ▶ 再生・■ 停止・ループ・速度。
    • 行をダブルクリックで専用エディタが開く。

    専用エディタ

    ⏱ 中身を作り込むとき

    素材を選ぶと Inspector の一番上に ▶ 〜 Editor で開く ボタンが出ます。迷ったらこれ。全部 Tools›D-Drive›Editors にもあります。

    • Audio：波形を見ながらトリミング・試聴・3D の聞こえ方。
    • VFX：シーンで再生しながら位置・色を調整。
    • Shake / Haptics：揺れ・振動の波形を見て、実際に揺らす。
    • Anchor / Anchor Group：エフェクトや音を「どこに」出すか。
    • ほかに Model・Prefab・Animation・Material・Canvas・UI Tween・Skin。

    Presentation Editor

    ⏱ 演出を組むとき（Tools›D-Drive›Presentation Editor）
    • タイムライン：素材をドラッグ＆ドロップすると種類別のレーンに並ぶ。左右にドラッグで時間調整。
    • トラック一覧：Trigger・時間・合図名・対象（本人／相手）・出す位置・Stop On Cancel。
    • 統合プレビュー：モデルを配置して ▶。アニメ・音・エフェクト・揺れ・振動が同時に再生。速度 0.1x〜2x、ループ。
    • Signal レーン：再生中に合図を手動で送る。

    Validation（自動チェック）

    ⏱ 作業の区切り・「出てこない」とき
    • 赤 Error：そのままだと出てこない・動かない → 必ず直す。
    • 黄 Warning：動くが意図とずれやすい → 読んで判断。
    • 青 Info：お知らせ。
    • 修正 ボタンで自動修正（Ctrl+Z で戻せる）。
    • 各専用エディタの下の「検証」欄では、その素材 1 件分だけを確認できる。
    07 — Numbers

    効果音（SE）の
    主な設定。

    一番よく触る効果音の設定です（Inspector の英語表記のまま載せています）。

    🔊 SE GameData/Audio/SE/*.asset
    項目何が変わる上げると下げると初期値
    Volume基準の音量（0〜1）大きい小さい1
    Pitch Range鳴るたびの音の高さの幅（最小〜最大）高く・ばらつく低く1〜1
    Clips ／ Select Mode鳴らす音（複数可）と選び方Random（毎回ランダム）／RoundRobin（順番）／First（常に先頭）Random
    Start Offset Sec音の途中から鳴らす位置（秒）頭を飛ばす最初から0
    Loop鳴りっぱなしにするか環境音は ONOFF
    Spatial聞こえ方None＝どこでも同じ／Anchor＝物について動く／AtPosition＝決まった場所からNone
    Min ／ Max Distance減衰しない距離／聞こえなくなる距離遠くまで聞こえる近くだけ1 ／ 30
    Max Concurrent同じ音の同時再生数重なって厚くなる古い音が止まりやすい8
    Cooldown Sec連打で無視する間隔（秒）連打が鳴りにくい全部鳴る0.03
    Mixer出力先の音のグループ未設定だと Validation で黄色の警告未設定
    08 — Troubleshooting

    困ったときは
    ここ。

    ゲームで音が鳴らない／ピンクの球が出る
    1. Validation›Run All で「未登録」「Placeholder」が出ていたら 修正。
    2. 中身（Clips や Prefab）が空になっていないか。
    3. Volume が 0 になっていないか。
    4. 連打なら Cooldown Sec / Max Concurrent。
    5. ゲーム開始直後だけ鳴らないなら、プログラマーに「起動完了を待ってから鳴らす」対応を依頼。
    SourceAssets に置いたのに何も作られない
    SourceAssets のすぐ下が種別フォルダ（Se・Bgm・Vfx など。大文字小文字も一致）である必要があります。SourceAssets/Fire.wav（直置き）や SourceAssets/新規/Se/Fire.wav（間に別フォルダ）は認識されません。Console に案内が出ます。
    札の名前（SEID.○○）がプログラマーの画面に出てこない
    Tools›D-Drive›Generate›Regenerate Asset IDs で一覧を作り直します。札の名前は「ファイル名から種別の頭文字を除いたもの」です（SE_Turret_Fire → SEID.TurretFire）。
    演出がすぐ終わる／Cancel しても止まらない
    合図待ちだけの演出は Total Duration を入れる。止まらないのは Interruptible が OFF だから（最後まで見せる演出向けの設定）。
    Development Build で、左下の「[DDrive 手動接続]」が出ない／左上の通信状態の下に別の表示がある
    このプロジェクトでは、左下の D-Drive の手動接続画面はわざと隠しています（そこから接続するとプレイヤー番号が送られず、接続を断られるため）。接続は右上の「D-Drive/NGO 接続」画面を使ってください。左上の D-Drive の通信状態表示はそのまま残し、ゲーム側の計測表示（群衆の HUD など）はその下に並びます。
    ファイルを移動・名前変更してしまった
    番号札の中身の番号は変わりませんが、札の名前（SEID.○○）が変わってプログラムがエラーになることがあります。元に戻すか、プログラマーに連絡してください。
    09 — Words

    分からない言葉は
    ここで引く。

    ID 番号札
    素材を呼び出すための名前（SEID.TurretFire など）。自動で作られる。
    Data 中身
    倉庫に入っている素材の設定ファイル（.asset）。
    SourceAssets 投入口
    元の素材ファイルを置くフォルダ。置くだけで Data が作られる。
    Asset Browser
    全素材の一覧・検索・作成・試聴ができる入口のウィンドウ。
    Placeholder
    中身が無いときの代役（無音・ピンクの球）。ゲームを止めないため。
    カタログ／Addressables
    倉庫の台帳と、ゲーム中に素材を読み込む仕組み。登録漏れは Validation が教えてくれる。
    Validation
    設定ミスや登録漏れを自動で見つけるチェック。
    演出 Presentation
    音・エフェクト・揺れ・振動などを時間軸に並べた 1 本のまとまり。
    トラック
    演出の中の 1 行。「いつ（Trigger）」「何を（Kind）」を決める。
    Signal 合図
    「当たった」などをゲームから演出に伝える名前付きの合図。
    Anchor 出す位置
    エフェクトや音を「どこに出すか」（右手・足元など）のデータ。
    ヒットストップ
    当たった瞬間に一瞬時間を止める演出。
    10 — For programmers

    呼び方は全部
    同じ形。

    「ID を渡して静的ファサードを呼ぶ」だけ。未登録・未起動でも例外にならず Placeholder で続行。Fortress のコードは DDrive.Runtime / DDrive.Foundation / DDrive.Generated を参照済み。

    DDrive.Runtime.Audio
    using DDrive.Generated;
using DDrive.Runtime.Audio;

Audio.PlaySe(SEID.Se);                       // 2D
Audio.PlaySe(SEID.Se, transform.position);   // その場所で 3D
var h = Audio.PlaySe(SEID.Se, transform);    // 追従
Audio.Stop(h, 0.2f);                         // 0.2 秒でフェードアウト
Audio.PlayBgm(BGMID.Title);                  // 再生中なら自動クロスフェード
    このプロジェクトLaserTurretAudio が Firing 突入時に Audio.PlaySe(SEID.Se)。
    ID 名ファイル名から種別接頭辞を除いた PascalCase。カテゴリも含む。
    Vfx / CameraFx / Haptics
    using DDrive.Runtime.Vfx;
using DDrive.Runtime.CameraShake;

var v = Vfx.Spawn(VFXID.HitSpark, hitPoint, Quaternion.identity);
v.SetParam("MainColor", Color.red);
v.Stop();                                   // 自然に消える / Kill() で即時
if (CameraFx.IsBound) CameraFx.Shake(SHAKEID.Hit, 0.8f);
    このプロジェクトCameraReactionPlayer が D-Drive の揺れ（未起動なら簡易揺れ）を使う。
    DDrive.Runtime.Presentation
    using DDrive.Runtime.Presentation;

var ctx = new PlayContext { Self = transform, Target = enemy, OnSignal = key => { } };
var h = Presentation.Play(PRESENTID.SwordSlash, in ctx);
h.Signal("hit");      // OnSignal("hit") のトラックが発火
h.Cancel();           // Interruptible=false なら無視
    注意時刻 0 のトラックは Play() 内で同期発火 → 後から Subscribe しても拾えない。ctx.OnSignal を使う。
    クラス名生成クラスは PRESENTID（PRESID ではない）。
    DDriveRuntimeBootstrap
    using Cysharp.Threading.Tasks;
using DDrive.Runtime.Loop;

async UniTaskVoid Start()
{
    await DDriveRuntimeBootstrap.Instance.WhenReady;   // カタログ登録待ち
    Audio.PlayBgm(BGMID.Title);
}
    時間Time.timeScale=0 では D-Drive は止まらない（PauseService を使う）。HitStop も timeScale を変えない。

    11 — Rules & update

    壊さないための
    約束。

    DO

    • 作成は Asset Browser か SourceAssets から
    • コードからは静的ファサード経由（Audio / Vfx / Presentation…）
    • 作業の区切りで Validation › Run All
    • ゲームのコードは自分の asmdef に置く

    DON'T

    • Generated/ の生成コードを手で編集
    • Data を実行時に書き換え
    • D-Drive 管理の物を Instantiate / Resources.Load / AudioSource.Play で直接扱う
