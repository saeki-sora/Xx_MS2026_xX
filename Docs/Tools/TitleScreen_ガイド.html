    TITLESCREEN

    タイトル画面 — ゲームの顔を、画像の差し替えと数値だけで作る

    上向きの歯磨き粉をつまむと、ふくらんで噴き出す。
    画面が歯磨き粉で塗り替わり、
    ロゴとキャラが落ちてきてボタンでゲームへ。

    舞台は 100 年後の電脳世界。バグやウイルスが「ばいきん」のように増え、歯磨き粉を武器にしたクリーニングスタッフが磨いて回る――その世界の入口です。見た目はパステルの水色・ピンク、色ずれ、電脳ノイズ（グリッチ）、2 進数、キラキラでそろえています。
    舞台の幕開けのようなものです。暗転から明るくなり、真ん中の大きな歯磨き粉がつままれてふくらみ、キャップから噴き出した歯磨き粉が画面全体にどろーっと垂れて塗り替わると、ロゴ → キャラ 2 人 → 「スタート」の順に役者が飛び込んできます。役者（画像）はいつでも入れ替えられ、出てくるタイミングや動き方は台本（Inspector の数値）で決めます。

    誰が使う
    デザイナー（画像の差し替え）／プランナー（タイミング・動きの調整）
    開き方
    Assets/Scenes/Title.unity を開く。最初の 1 回だけ Tools›タイトル›タイトルシーンを組み立てる
    必要なもの
    差し替える画像（PNG）。無くても仮の画像で動く
    今の状況
    画像はすべて仮（キャラは仮のキューブ）。スタートは A キー（握力センサーは今後）。演出の流れは 2026-10-07 の指示どおり
    01 — What you can do

    つまんで、噴き出して、
    塗り替わる。

    再生すると、下の順番で進みます。途中で A キーを押すと演出を飛ばし、もう一度押すとスタートします。

    OPENING → DROP → START
    ① つまむ
    ぷくーっ
    上向きの歯磨き粉の真ん中がきゅっとつままれたように細くなり、まわりがふくらんでいく。カメラが寄りながらブルブル（だんだん強く）。
    ② 噴き出す
    スポーン！ブシュッ
    抑えきれずにキャップが回りながら吹き飛び、口から歯磨き粉が上へ噴き出す。泡が飛び、画面が揺れ、カメラが引く。
    ③ 塗り替わる
    どろーっ
    上から画面全体に歯磨き粉がどろーっと垂れてきて覆い、そのまま下へ流れ落ちると、紫でどんよりした背景がきれいな明るい背景に塗り替わっている。
    ④ 落ちてくる → スタート
    ドン・ドン・ドン
    ロゴが真ん中上、キャラが左下・右下に落ちてくる。最後に「握ってスタート！（Aキー）」。
    🪥

    歯磨き粉（オープニング）

    上向きでポンと出てきて、真ん中がつままれたように細くなる（指などは出さない）。つまんだ所は細く、まわりはふくらんで縦にも少し伸び、震える。力は「ゆっくり → 最後にぐっと」強くなる。噴き出す瞬間にキャップが回転しながら吹き飛び、噴き出した後はしぼむ。

    絵を差し替えても、ふくらみはそのまま効く（再生中に絵を細かい横じまに切って動かしている）

    🎥

    カメラ・幕

    ふくらむ間はだんだん寄りながらブルブル。噴き出した瞬間に揺れて、少し行き過ぎるくらいの勢いで引いて戻る。そのあと上から画面全体に歯磨き粉がどろーっと垂れてきて覆い、下へ流れ落ちる。垂れる先端はでこぼこ（細い縦の列ごとに少しずつ遅れて落ちる）。

    🅰️

    タイトルロゴ

    上から落ちてきて真ん中上に「ドン」。白く光り、画面が揺れ、むにっとつぶれて戻る。待機中は数秒おきに「キラッ」、ときどき「ザザッ」と電脳ノイズ。

    🧊

    キャラ（仮のキューブ）

    回転しながら左下・右下に順番に落ちてきて「ドン」。着地のたびに画面が揺れ、白く光ってむにっとつぶれる。その後ふわふわ上下。

    あとでキャラのモデルや絵に差し替える

    👆

    〇〇でスタート！

    真ん中下に弾むように現れて、ゆっくり点滅。押すとノイズが走り、速く点滅して消える。

    🫧

    背景・泡・ばいきん

    最初は紫でどんよりした背景（汚れた洗面台・ばいきんの影・ノイズ）が、ゆっくり引きながら現れる。歯磨き粉で塗り替わると、同じ場所のきれいな明るい背景になり、下から泡が湧き始める。ばいきん（バグ）は最初から回りながら漂う。

    02 — First 5 minutes

    組み立てて、
    再生して、差し替える。

    Tools›タイトル›タイトルシーンを組み立てる。Title シーンが開き、仮の画像で一式が並んで保存されます。Hierarchy に [Title] ができていれば OK。

    新しい画像は Project で選んで Texture Type を Sprite (2D and UI) にしておきます（Assets/Title/Sprites に置くのがおすすめ）。

    4

    動きを調整する

    Logo などの親オブジェクトの Title Element Motion の数値を変えて再生。登場／待機中のゆらぎ／スタート時（退場） の 3 つに分かれています。

    歯磨き粉のふくらみ方・噴き出し方・幕は [Title] › Opening の Title Opening で変えます（出てくる／つまんでふくらむ／噴き出す／塗り替わる）。

    位置はシーン上で動かしたところが「最終位置」。登場の動きはそこからの相対で決まります

    まとめて調整して、何度でも見直す

    [Title] を選ぶと、Inspector の上に 流れの一覧（ここで全部まとめて調整できます） が出ます。歯磨き粉・背景・ロゴ・キャラ左右・スタート文字・カメラの、タイミング・位置・大きさ・揺れなどをここだけで変えられます（名前の青い文字を押すとその物を選べます）。

    ▶ Play 中は ▶ 最初から再生 で、止めずに何度でも頭から見直せます。再生中に変えた値は、止めると元に戻ります。残したいときは止める前に 再生中に変えた値を残す を押し、止めた後にシーンを保存（Ctrl+S）。

    位置と大きさは再生を止めてから変えます（再生中は動きの演出が上書きするため）

    03 — Recipes

    「〜したい」から
    探す。

    ロゴ・背景・歯磨き粉・スタート文字の画像を替えたいSprite

    各オブジェクトの子 Sprite の Sprite Renderer › Sprite を差し替えます（歯磨き粉は Opening › Toothpaste › Sprite、キャップは Toothpaste › Cap › Sprite（チューブとキャップは別々の絵）、噴き出す歯磨き粉は PasteStream。塗り替わりの歯磨き粉だけは UI なので FadeCanvas › PasteCurtain の Raw Image › Texture）。または Assets/Title/Sprites の同じ名前の PNG を上書きしても替わります。

    仮のキューブを本物のキャラに替えたいModel
    1. [Title] › CharacterLeft（または CharacterRight）の子 Model を消す。
    2. 代わりのモデル（または絵）を同じ場所の子として置き、名前を Model にする。位置は (0, 0, 0) が着地点。

    名前を Model にしておくと、組み立て直しても消えずに引き継がれます。落ち方・揺れは親の Title Element Motion がそのまま効きます。

    塗り替わる前（どんよりした背景）の絵を替えたいSpriteBefore

    [Title] › Background › SpriteBefore の Sprite を差し替えます（塗り替わった後のきれいな背景は、同じ Background の子 Sprite）。歯磨き粉が画面を覆いきった瞬間に、SpriteBefore が消えて後ろのきれいな背景が見える仕組みです。編集中は SpriteBefore が手前に重なっているので、後ろを見たいときは SpriteBefore を一時的に非表示にしてください。

    塗り替わる前／後で出し分けたい物を増やしたいときは、Opening の Title Opening › Before Objects（前だけ）／After Objects（後だけ）に入れます。今は泡（Bubbles）が「後だけ」です。

    差し替えた画像の大きさを変えたいTitle Sprite Fit

    子 Sprite の Title Sprite Fit › Size（画面の高さが約 10.8）。横幅で決めたいときは Mode を 幅を指定。画像そのままの大きさにしたいときは 合わせない（画像の大きさのまま）。

    ロゴの現れ方・光り方・ノイズの見た目を変えたいShaderFX

    Assets/Title/Effects/TitleFX_Logo を選び、ディゾルブ の Edge Color（浮かび上がるときの縁の色）、グリッチ の Block Size（ノイズの粗さ）・Rgb Split（色ずれの幅）、被弾フラッシュ の Color（光る色）を変えます。グリッチの Amount は 0 のままにしてください（強さは Title Element Motion が動かします）。キャラは TitleFX_Character（輪郭の光は リムライト）。スタート文字はロゴと同じ設定を使っています。

    出てくる順番・タイミングを変えたい登場

    Enter Delay（始まってから何秒後に出るか）と Enter Duration（何秒かけて出るか）。例：ロゴを先に出したいなら Logo の Enter Delay を 0.3 に。

    キャラを横から出したい／もっと高い所から落としたいMove From

    CharacterLeft / CharacterRight の Move From。今は真上 (0, 10, 0)。横から滑り込ませるなら (-8, 0, 0) など。最終位置から見た「出発点のずれ」です。落ちながらの回転は Rotate From（0,0,0 で回らない）。

    着地の「ドン」をもっと重く／軽くしたい着地

    Shake On Land（画面の揺れ）、Squash On Land（むにっとつぶれる量、0 で無し）、Flash On Land（白く光る量）。落ちる速さは Enter Duration（短いほど速い）。

    歯磨き粉のふくらみ方・つまみ方を変えたいTitle Opening

    [Title] › Opening の Title Opening › つまんでふくらむ：Swell Duration（ふくらんでいく秒数、既定 2）、Swell Amount（太くなる割合、0.4）、Pinch Amount（つまんだ所の細さ、0.5）、Pinch Height（つまむ高さ。0 = 下端、1 = 上端、0.45）、Pinch Width（つまむ幅）、Swell Stretch（縦に伸びる量）、Tube Tremble（震え）。

    指などは置いていません。置きたくなったら Opening の子に置いて Pinchers に入れると、つまむ間に真ん中へ寄っていきます（寄る距離は Pincher Travel）。

    ふくらむ間のカメラの寄り・ブルブル、噴き出した揺れを変えたいTitle Opening

    Zoom In（寄る量）と Rumble（ブルブル、0.12）。キャップの飛び方は Cap Launch Speed（飛ぶ速さ、16）、Cap Launch Spread（左右のぶれ）、Cap Spin（回転）、Cap Gravity（重力。0 で落ちてこない）。噴き出した後は Eject Shake（揺れ）と Pull Back Duration（引いて戻るまでの秒数）。噴き出す勢いは Eject Duration（伸びきるまでの秒数、短いほど速い）。

    どろーっと垂れる歯磨き粉（塗り替わり）の速さ・垂れ方を変えたい塗り替わる

    Title Opening › 塗り替わる：Curtain Delay（噴き出してから垂れてくるまで、0.25）、Curtain Drop Duration（覆いきるまで、1.3。長いほどどろーっと遅い）、Curtain Ease（垂れ方の緩急）、Curtain Unevenness（先端のでこぼこ。0 で横一直線、0.45）、Curtain Columns（縦の列の数、28）、Curtain Hold（覆ったままの時間、0.25）、Reveal Style（下へ抜ける／ふっと消える）、Reveal Duration（消えきるまで、0.9）。

    絵は [Title] › FadeCanvas › PasteCurtain の Raw Image › Texture。列ごとに上下にずれて落ちるので、しまは縦向きの絵にすると継ぎ目が目立ちません（下のふちの垂れも絵の一部）。

    幕が抜けてからロゴが落ちてくるまでの間を変えたいHand Off Delay

    Title Opening の Hand Off Delay（幕が消え始めてから合図を出すまで、既定 0.15 秒）。個別には各配置物の Enter Delay（合図から何秒後に落ち始めるか。ロゴ 0／キャラ左 0.45／キャラ右 0.7／スタート文字 1.5）。

    着地のバウンドを強く／弱くしたいEnter Ease

    Enter Ease を選びます：少し行き過ぎて戻る（今の既定）、弾む（ボールのように跳ねる）、最後にゆっくり（行き過ぎない）など。

    スタート文字の点滅を速く／薄くしたい待機中のゆらぎ

    PressStart の Blink Speed（1 秒あたりの回数、既定 0.8）と Blink Min Alpha（一番薄いとき、既定 0.35。1 で点滅なし）。

    ロゴの「キラッ」を止めたい／増やしたいGlint

    Logo の Glint Interval（何秒ごと、既定 3.5。0 で止める）と Glint Strength。

    泡やばいきんを増やしたい／減らしたいBubbles / Germs

    [Title] › Bubbles（泡）または Germs（ばいきん）の Particle System の Emission › Rate over Time（1 秒に出る数。既定 泡 45／ばいきん 1.2）。色は一番上の Start Color、大きさは Start Size。ばいきんの絵は Assets/Title/Sprites/Title_Germ.png を上書きすると替わります。

    電脳ノイズ（ザザッ）を増やしたい／止めたいGlitch

    Title Element Motion の Glitch In（登場中のノイズ）、Glitch Interval（待機中に何秒おきか、0 で止める）と Glitch Strength、Glitch On Exit（スタートの瞬間）。子に、グリッチの入った Effect Target が付いているもの（Logo・CharacterLeft/Right・PressStart）だけで効きます。

    スタートの後、暗転するまでを長く／短くしたいTitle Screen Controller

    [Title] の Title Screen Controller › Start Hold Seconds（暗転し始めるまで、既定 0.55）と Fade Out Seconds（暗転にかける秒数、既定 0.5）。

    スタートのキーを変えたいStart Key

    Title Screen Controller › Start Key。今は仮で A キーです。握力センサーでのスタートは今後つなぎます。

    スタートやロゴ着地で効果音を鳴らしたいエフェクト・効果音

    噴き出す音は Title Opening の On Eject（つまみ始めは On Pinch、幕が覆いきった瞬間は On Covered）、着地の「ドン」は各配置物の Title Element Motion › On Land、スタートは Title Screen Controller の On Start に、D-Drive の SE・VFX を選びます。

    !
    今の仕様の注意：D-Drive の起動役がゲームのシーンにしか無いため、タイトルでは選んでも鳴りません（エラーも出ません）。タイトルでも鳴らすには起動役をタイトルのシーンへ移す作業が必要です（プログラマーに相談）。
    値を変えるたびに再生し直すのが面倒最初から再生

    ▶ Play したまま、[Title]（または各配置物・Opening・Main Camera）の Inspector 上部の ▶ 最初から再生。暗転から頭出しされます。

    再生中に調整した値を残したい値を残す
    1. 再生中に値を調整する。
    2. 止める前に 再生中に変えた値を残す を押す（「✓ 値を写し取り済み」と出る）。
    3. 再生を止めると値がシーンに書き戻されるので、シーンを保存。

    位置と大きさは対象外です（再生を止めてから変えてください）。

    数値をめちゃくちゃにしたので最初に戻したい組み立て直し

    Tools›タイトル›タイトルシーンを組み立てる をもう一度 → 初期値で作り直す。差し替えた画像とキャラの Model はそのまま、位置と動きの数値が初期値に戻ります。数値を引き継いで作り直す を選ぶと、調整した値はそのまま残ります。

    見つかりませんでした。別の言葉で探してください。

    04 — Hierarchy

    シーンの
    中身。

    [Title]（Title Screen Controller）

    全体の進行役。スタートのキー、行き先のシーン、暗転・フラッシュ・カメラの寄り、効果音。

    • Opening — オープニングの進行（Title Opening）。子に歯磨き粉 Toothpaste（その子にキャップ Cap）、噴き出す歯磨き粉 PasteStream、飛び散る泡 BurstSplash。
    • Background / Logo / PressStart — それぞれ親が「動き」（Title Element Motion）、子の Sprite が「画像と大きさ」（Sprite Renderer ＋ Title Sprite Fit）。
    • CharacterLeft / CharacterRight — 親が「動き」、子の Model が見た目（今は仮のキューブ）。
    • Background › SpriteBefore — 塗り替わる前の、紫でどんよりした背景。Bubbles — 下から湧く泡・キラキラ（塗り替わった後だけ）。Germs — 漂うばいきん。
    • FadeCanvas › PasteCurtain — 画面にどろーっと垂れて塗りつぶす歯磨き粉（再生中に縦の列に分かれる）。Fade — 暗転・フラッシュ用の板（どちらも編集中は消えています）。
    • Main Camera — Title Camera Motion（揺れ・ブルブル・寄り）が付いています。

    Exit Style消え方何もしない／フェードアウト／点滅して消える／膨らみながら消える何もしない

    Pinchers / Pincher Travelつまむ間に真ん中へ寄せる物（今は空）／寄る距離指などを足したいときだけ使う空 / 0.35
    Zoom In / Rumbleふくらむ間にカメラが寄る量／ブルブルの強さぐっと寄る・激しい0 で無し0.15 / 0.12
    Slice Countふくらみを作る横じまの数なめらか段々が見える48
    Cap Launch Speed / Spread / Spin / Gravityキャップが飛ぶ速さ／左右のぶれ／回転（度/秒）／重力勢いよく飛ぶふわっと外れる16 / 3 / 900 / 20
    Eject Duration噴き出した歯磨き粉が伸びきる秒数ゆっくり伸びる勢いよく0.4
    Eject Shake噴き出した瞬間の揺れ（幕が覆いきったときはこの半分）大きく揺れる0 で無し0.4
    Pull Back Duration / Deflate Durationカメラが引いて戻る秒数／チューブがしぼむ秒数ゆっくりすばやく0.5 / 0.35
    Curtain Delay噴き出してから歯磨き粉が垂れてくるまで間が空くすぐ垂れる0.25
    Curtain Drop Durationどろーっと垂れて覆いきるまで重く遅いさらっと速い1.3
    Curtain Ease垂れ方の緩急「ゆっくり始まりゆっくり終わる」がどろーっとした感じゆっくり始まりゆっくり終わる
    Curtain Unevenness / Curtain Columns先端のでこぼこ（0〜0.9）／縦の列の数でこぼこ・なめらか横一直線・段々0.45 / 28
    Curtain Hold覆ったままの時間長く覆うすぐ消える0.25
    Reveal Style / Reveal Duration消え方（下へ抜ける／ふっと消える）／消えきるまで下へ抜ける / 0.9
    Before Objects / After Objects塗り替わる前だけ見せる物／後だけ見せる物覆いきった瞬間に入れ替わるどんよりした背景 / 泡
    Hand Off Delay消え始めてから、ロゴたちが登場し始めるまで間が空くすぐ落ちてくる0.15

    06 — Troubleshooting

    困ったときは
    ここ。

    再生を止めたら、調整した値が元に戻った
    Unity では再生中の変更は止めると戻ります。止める前に 再生中に変えた値を残す を押してください（逆引き「再生中に調整した値を残したい」）。
    再生してもロゴやキャラが表示されない／歯磨き粉が出ない
    シーンが古い作りのままです。Tools›タイトル›タイトルシーンを組み立てる → 作り直す を実行してください。Hierarchy の [Title] の下に Opening・CharacterLeft・CharacterRight があれば新しい作りです。
    A を押してもゲームのシーンに進まない
    1. 演出の途中なら、1 回目は「演出を飛ばす」です。もう 1 回押してください。
    2. Console に「シーン「Game」を読み込めません」が出ていたら、File › Build Profiles のシーン一覧に Game が入っているか確認。
    3. Game ビューをクリックしてから押してください（Unity の別の画面が選ばれているとキーが届きません）。
    キューブが真っ黒・ピンク色になる
    キューブには光が必要です。シーンの Directional Light を消していないか確認。ピンク色ならマテリアル（Title_CubeLeft / Title_CubeRight）のシェーダーが見つかっていないので、プログラマーに相談してください。
    差し替えた画像が真っ白・四角になる
    画像の Texture Type が Sprite (2D and UI) になっているか確認してください。
    ロゴが浮かび上がらない・光らない・ノイズが出ない
    Logo › Sprite に Effect Target が付いていて、Profile が TitleFX_Logo、Sprite Renderer の Material が Title_SpriteFX か確認。
    効果音が鳴らない
    今の仕様ではタイトルでは鳴りません（逆引き「効果音を鳴らしたい」参照）。
    07 — Words

    分からない言葉は
    ここで引く。

    暗転／明転
    画面が黒くなること／黒から明るくなること。
    ディゾルブ
    絵がノイズ状に少しずつ現れる・消える見た目。ShaderFX の機能。
    グリッチ
    画面がザザッと乱れて、絵がずれたり色が分かれたりするデジタルなノイズ。ShaderFX の機能。
    Effect Target
    ShaderFX の見た目エフェクトを付けるための部品。
    ワールドの単位
    シーン内の長さ。タイトルのカメラでは画面の高さが約 10.8。
    08 — For programmers

    別の入力から
    スタートさせる。

    名前空間 MS2026.Title（Assets/Title/Scripts/Runtime）。

    TitleScreenController
    using MS2026.Title;

// 握力などのしきい値を超えたら呼ぶ（演出中なら演出を飛ばす、待機中ならスタート）
FindAnyObjectByType<TitleScreenController>().RequestStart();

// カメラの演出（今のカメラの動きに上乗せされる）
var cam = Camera.main.GetComponent<TitleCameraMotion>();
cam.Shake(0.2f);          // ワールド単位の最大のずれ
cam.ZoomTo(0.1f, 0.5f);   // 0.5 秒で 10% 寄って保つ（0 で戻す）
cam.SetRumble(0.1f);      // 止めるまで続くブルブル（0 で止める）
