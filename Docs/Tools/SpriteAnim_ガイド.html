    SPRITEANIM

    MS2026 SpriteAnim — スプライトシート 1 枚から、歩く・攻撃する・切り替える

    デザイナーから届いた スプライトシート 1 枚 を、
    切って・並べて・名前を付けるだけで
    アニメになる。

    パラパラ漫画を作る道具です。シートを格子状に切ってコマにし、「Walk」「Attack」のように名前を付けたパラパラ漫画を何本も 1 冊（Animation Set）にまとめます。ゲームでは「Walk を再生して」と名前で呼ぶだけ。Unity 標準の Animator のような複雑な配線は要りません。

    誰が使う
    デザイナー（アニメ作成・確認）／プログラマー（再生の呼び出し）
    開き方
    MS2026›スプライトアニメ›スプライトアニメスタジオ（画面上部メニューの「MS2026」）
    必要なもの
    スプライトシート（まだ無ければテスト用シートを自動生成できる）
    今の使用状況
    パッケージは導入済み。ゲーム本編ではまだ未使用
    01 — What you can do

    スタジオの
    ①〜⑤ を上から順に。

    スプライトアニメスタジオは、上から ① → ⑤ の順に進めればアニメが完成する作りになっています。

    ✂️

    ① スライス

    シートを「横○列 × 縦○行」で切ってコマにする。素材が無くてもテスト用シートを作れる。

    📚

    ② アニメーションセット

    キャラ 1 体分のアニメ（Walk・Attack・Idle…）をまとめる 1 冊のファイル。

    ▶️

    ③ プレビュー

    その場で再生・一時停止・コマ送り・速度変更。前後のコマを透かすオニオンスキンも。

    🔀

    ④ 遷移テスト

    「歩き→攻撃」に切り替わるときの重なり（クロスフェード）の見た目と秒数を確認。

    🧰

    ⑤ ツール

    連番のスプライト（walk_0, walk_1…）からアニメを一括作成。アニメ名のコード定数も自動生成。

    🎮

    ゲームで再生

    Sprite Animator 部品を付けてセットを入れるだけ。最初のアニメは自動で再生される。

    02 — First 5 minutes

    素材が無くても、
    5 分で 1 本作れる。

    1

    スタジオを開いて、シートを切る

    MS2026›スプライトアニメ›スプライトアニメスタジオ。① スプライトシートを読み込んでスライス の Sprite Sheet 欄に画像をドラッグし、Columns（横の数）と Rows（縦の数）を入れて スライス実行。

    素材がまだ無ければ テスト用シートを生成 (実素材が無くても動作確認できます)。色分け＋通し番号付きのシートができ、自動でスライスまでされます。

    ③ プレビューで確認

    再生／一時停止、|< >| でコマ送り、スクラブ、再生速度、オニオンスキン。ゲームを動かさずに確認できます。

    5

    キャラに付けて動かす

    SpriteRenderer（または UI の Image）が付いた GameObject に Add Component›MS2026›Sprite Anim›Sprite Animator を付け、Animation Set に②のセット、Default Animation に Walk を選ぶ。▶ Play で歩き出します。

    Play 中は Inspector にテスト再生ボタンが出るので、他のアニメへの切り替えも試せます

    03 — Recipes

    「〜したい」から
    探す。

    バラバラの画像（walk_0, walk_1…）からまとめて作りたい⑤ ツール

    Project ウィンドウで画像を全部選んだ状態で ⑤ ツール の 選択中のスプライトから自動でアニメーションを作成。名前の「_数字」の前の部分ごと（walk / run …）にアニメが自動で作られ、数字順に並びます。

    シートの絵と絵の間にすき間がある① スライス

    Padding X / Y（コマとコマの間の幅）と Margin X / Y（画像の外周の余白）をピクセルで入れてからスライス実行。Pixels Per Unit はゲーム内での大きさの基準です。

    1 回だけ再生して止めたい／往復させたいLoop Mode

    アニメの Loop Mode を選びます（下の「数値の意味」に図解あり）：Once（最後で止まる）、Loop（繰り返す）、PingPong（行って戻る）、ClampForever（最後のコマで止まり続ける）。

    特定のコマだけ長く見せたい（溜めポーズ）Frames

    Frames の各行の時間（秒）を個別に書き換えます。FPS 一括適用の後で、溜めたいコマだけ長くするのが楽です。

    歩き→攻撃の切り替わりを滑らかにしたい④ 遷移テスト
    1. ④ 遷移（クロスフェード）テスト で From（例 Walk）と To（例 Attack）を選ぶ。
    2. Cross Fade (sec) を動かして テスト実行。ちょうどいい秒数を探す。
    3. 決まった秒数をセットの Default Cross Fade (sec) に入れる（全切り替えの既定値）。特定の組み合わせだけ変えたいときは、セットの Inspector の Transition Rules（from / to / 秒。* で「何でも」）。
    同じ敵が何体も並ぶとき、足並みがそろって不自然Sprite Animator

    Sprite Animator の Randomize Start Frame を ON。体ごとに開始コマがばらけます。

    ポーズ中もメニューのアニメは動かしたいSprite Animator

    Sprite Animator の Use Unscaled Time を ON にすると、ゲームの時間を止めても動き続けます。

    足音や攻撃判定を「このコマで」出したいフレームイベント

    Frames の該当コマの行の右端の欄（イベント名。行は「スプライト・秒数・イベント名」の順）に Footstep などを書きます。そのコマに来ると Sprite Animator の On Frame Event が名前付きで呼ばれるので、Inspector で音を鳴らす処理などをつなぎます（プログラマーはコードから受け取れます）。

    アニメ名のタイプミスを防ぎたい⑤ ツール

    アニメーション名の定数クラスを生成 (C#) で、セットのアニメ名をまとめたコードファイルが作られます（例：PlayerAnims.Walk）。プログラマーに渡すとタイプミスが起きません。

    見つかりませんでした。別の言葉で探してください。

    i
    このゲームの群衆の敵は別の仕組みです。数千体の敵のアニメは要塞デザイナーの「群衆 › 敵の種類」でスプライトシートを指定して動かしています（SpriteAnim ではありません）。SpriteAnim はボス・UI・演出用キャラなど、個別に置くものに向いています。
    04 — Numbers

    ループの種類と
    主な設定。

    Once

    1 2 3 4 ■

    最後まで再生して止まる（完了イベントが出る）。攻撃・被弾など 1 回きりの動き。

    Loop

    1 2 3 4 1 2 3 4 …

    先頭に戻って繰り返す。歩き・待機。新規作成時の既定。

    PingPong

    1 2 3 4 3 2 1 2 …

    行って戻るを繰り返す。呼吸・揺れ。

    ClampForever

    1 2 3 4 4 4 4 …

    最後のコマで止まり続ける（再生中のまま）。倒れた後の姿勢など。

    Sprite Animator（キャラに付ける部品）
    項目意味メモ初期値

    Default Animation最初に再生するアニメドロップダウンで選べる—
    Play On Enable有効になった瞬間に再生するかON
    Use Unscaled Timeゲーム時間の停止を無視ポーズ中の UI 用OFF
    Randomize Start Frame開始コマをランダムに群れの同期崩しOFF
    Speed再生速度の倍率（0〜5）アニメ側の Speed とかけ算1
    アニメーション／セット
    項目意味メモ初期値

    05 — Troubleshooting

    困ったときは
    ここ。

    Play してもアニメしない
    1. Sprite Animator の Animation Set と Default Animation が入っているか。
    2. 同じ GameObject に SpriteRenderer か Image があるか。
    3. Console に「Animation Set が設定されていません」「アニメーション '…' が見つかりません」が出ていないか（名前の打ち間違い）。
    加算で光る特殊なマテリアルのスプライトで、切り替え時に見た目が変わる
    クロスフェードは「もう 1 枚重ねて透明度で混ぜる」方式なので、特殊な合成のマテリアルでは切り替えの一瞬だけ見え方が変わることがあります。気になる場合はその切り替えだけ Cross Fade を 0 に。
    Transition Rules の編集画面がない
    専用 GUI はまだありません。セットのファイルを選び、Inspector の配列（Transition Rules）を直接編集してください。
    06 — Words

    分からない言葉は
    ここで引く。

    スプライトシート
    アニメのコマを 1 枚の画像に格子状に並べたもの。
    スライス
    シートを格子で切り分けて、1 コマずつのスプライトにすること。
    アニメーションセット
    キャラ 1 体分のアニメをまとめたファイル。
    クロスフェード
    前のアニメを薄くしながら次のアニメを濃くして、なめらかに切り替えること。
    オニオンスキン
    前後のコマを半透明で重ねて見せる表示。動きのつながりを確認できる。
    フレームイベント
    特定のコマに来たときに出す名前付きの合図。足音・攻撃判定などに使う。
    FPS
    1 秒あたりのコマ数。12 なら 1 コマ約 0.083 秒。
    07 — For programmers

    呼ぶのは
    名前だけ。

    名前空間 MS2026.SpriteAnim。依存は com.unity.ugui のみの自己完結パッケージ。

    SpriteAnimator
    using MS2026.SpriteAnim;

var anim = GetComponent<SpriteAnimator>();
anim.Play("Walk");                 // 同じアニメ再生中なら何もしない（毎フレーム呼んで安全）
anim.Play("Attack", 0.1f);         // 0.1 秒クロスフェード（-1 でセット既定/遷移ルール）
anim.PlayOneShot("Hit", "Idle");   // Hit を 1 回 → 終わったら Idle
anim.Stop(); anim.Pause(); anim.Resume();
bool has = anim.HasAnimation("Run");
    見つからない名前警告ログを出して何もしない（例外にしない）。
    実行順[DefaultExecutionOrder(-1)]。
    events
    anim.AnimationStarted   += name => { };
anim.AnimationCompleted += name => { };   // Once の最後
anim.AnimationLooped    += name => { };
anim.FrameEvent         += evt  => { if (evt == "Footstep") { /* ... */ } };
// Inspector 用 UnityEvent: onAnimationStarted / onAnimationCompleted /
//                          onAnimationLooped / onFrameEvent
