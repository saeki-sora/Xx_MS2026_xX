    01 — Tools

    入っている
    ツール。

    要

    要塞デザイナーFORTRESS DESIGNER · 自作

    砲台・レーザーの熱・敵ウェーブ・障害物・スマッシュボール・群衆・4 人のカメラを、コードなしで調整して Play で確認する調整卓。

    Tools › 要塞プランナー向け
    ガイドを開く →
    握

    握力入力ブリッジGRIP INPUT BRIDGE · 自作

    握力センサーの値を「その人の 0〜100%」に通訳してゲームに渡す入力の土台。キーボード代用・キャリブレーション・記録再生。

    Tools › 握力入力ブリッジ本番運営にも
    ガイドを開く →
    FX

    ShaderFXSHADER FX · 自作パッケージ

    光る縁・溶けて消える・被弾フラッシュ・ホログラムなど 16 種類の見た目エフェクトを、設定ファイルに積むだけで付ける。

    Create › ShaderFXデザイナー向け
    ガイドを開く →
    SA

    SpriteAnimSPRITE ANIM · 自作パッケージ

    スプライトシート 1 枚を切って並べるだけで 2D アニメに。名前で再生・なめらかな切り替え。

    MS2026 › スプライトアニメデザイナー向け
    ガイドを開く →
    D

    D-DriveD-DRIVE · 外部パッケージ v1.2.1

    効果音・エフェクト・演出・画面の揺れを「番号札（ID）」で管理する倉庫。中身はいつでも差し替えられる。

    Tools › D-Drive全員
    ガイドを開く →
