    00 — First time

    はじめて
    開く人へ。

    プロジェクトを初めて開いてから、最初の操作を試すまでの手順です。デザイナー・プランナーの方は、ここを上から順に進めてください。

    1

    Unity を用意する

    Unity Hub で Unity 6000.3.13f1 を入れます。違う版で開くと、プロジェクト全体の変換が走ってしまうので避けてください。

    2

    Git を入れておく

    D-Drive などのパッケージの一部は、インターネット上の Git の置き場から自動で取り込みます。そのため PC に Git が入っている必要があります。開いたときに Console に赤字でパッケージのエラーが出たら、Git が入っているか（または置き場を見る権限があるか）を担当プログラマーに相談してください。

    3

    試すときは自分用のブランチで

    要塞デザイナーで変えた数値（ウェーブ・敵・カメラ・レーザーなど）は設定ファイルに直接保存され、Play を止めても元に戻りません。GitHub Desktop などで自分用のブランチを作ってから開くと、ほかの人に影響せず、気に入らなければ変更を取り消すだけで元に戻せます。良い値ができたら、担当プログラマーに取り込みを頼んでください。

    4

    プロジェクトを開く

    Unity Hub の Add › Add project from disk でこのプロジェクトのフォルダを選び、開きます。初回は読み込みに長く（数分〜数十分）かかります。終わるまで待ってください。

    5

    最初に開くシーン

    Project ウィンドウで Assets›Scenes›Game.unity をダブルクリックします。本番で使うシーンで、コア・4 基の砲台・敵の湧き位置・ウェーブが入っています（SampleScene は使いません）。

    6

    この資料の開き方

    この一覧（Docs/Tools/index.html）や各ガイドは、エクスプローラーでダブルクリックしてブラウザで開きます。Docs フォルダの中に置いたまま開いてください（HTML ファイルだけを別の場所にコピーすると、見た目が崩れます）。

    i
    ▶ Play すると、画面の右上に「D-Drive/NGO 接続 (Phase 0 検証用)」の枠、左上に数字の並んだ計測表示が出ます。どちらもネット対戦の確認用なので、1 人で試すときは触らなくて大丈夫です（接続しなくても、そのまま遊べます）。

    🎥 デザイナー：カメラ・見た目の調整

    1. はじめての 5 分（Play して Q でレーザーを撃ち、数値を変える感覚をつかむ）
    2. 4 人それぞれの画面の見え方を決める（最初に 1 回「カメラリグをセットアップ」）
    3. Play 中に他の人の画面で見る（F1〜F5）
    4. 斜め見下ろしにしてキャラを立たせる
    5. 割った・攻撃されたときに画面を揺らす
    6. 敵の絵（スプライト）を差し替える
    7. レーザーや壊れる箱にエフェクト・音を入れる
    8. もっと見た目を作り込むなら：ShaderFX（光る・溶ける）／SpriteAnim（コマアニメ）

    👾 プランナー：ウェーブ・レベルデザイン

    1. はじめての 5 分（Play して QWOP で 4 人分を撃つ）
    2. 敵の数・出るタイミングを変える（敵ウェーブタブ。Play で自動再生、テストタブで開始／停止）
    3. 敵が湧く場所を増やす・円形に並べる
    4. 壁を置いて敵に回り道をさせる（到達チェックで確認）
    5. レーザーで壊せる箱を置く／スマッシュボールを作る
    6. 新しい敵の種類を作る／群れの流れ方を変える
    7. 数値の意味（上げると／下げるとどうなるかの一覧）

    要塞デザイナーFORTRESS DESIGNER · 自作

    砲台・レーザーの熱・敵ウェーブ・障害物・スマッシュボール・群衆・4 人のカメラを、コードなしで調整して Play で確認する調整卓。

    Tools › 要塞プランナー・デザイナー向け
    ガイドを開く →
    S

    ステージ背景スタジオSTAGE STUDIO · 自作

    Maya の 3D 背景を取り込むだけで、敵の群れがその間をさらさらと避けて流れるステージに。手前の物は自動で透け、隠れた敵は影で見える。

    Tools › ステージ背景プランナー・デザイナー向け
    ガイドを開く →
    U

    UIスタジオUI STUDIO · 自作

    ロビー・HUD などの画面を雛形から作り、レイヤーで重ね、動き・画面切り替え・ゲームの値とのつなぎをコードなしで整える。

    Tools › UIスタジオデザイナー・プランナー向け
    ガイドを開く →
    握

    握力入力ブリッジGRIP INPUT BRIDGE · 自作

    握力センサーの値を「その人の 0〜100%」に通訳してゲームに渡す入力の土台。キーボード代用・キャリブレーション・記録再生。

    Tools › 握力入力ブリッジ本番運営にも
    ガイドを開く →

    ShaderFXSHADER FX · 自作パッケージ
