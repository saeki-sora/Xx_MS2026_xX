    CHARASELECT

    キャラクター選択 — 短く握って選び、長く握って決める

    ロビーでホストが「ゲーム開始！」を押すと、全員がキャラ選択の画面へ。
    画面は4つに分かれていて、左上 1P・左下 2P・右上 3P・右下 4P。
    短く握るとカーソル移動、長く握ると決定。

    ゲームセンターの対戦台のキャラ選びのようなものです。自分の区画には、今カーソルがあるキャラの立ち絵・名前・能力の棒グラフ・スキルの説明が出ます。画面の下には 1P〜4P の丸が並び、上の区画と同じく、それぞれが今選んでいるキャラ（今は仮のキューブ。キャラごとに色が違う）を映します。決めると区画に「READY!」のはんこが押され、丸の縁がその人の色になります。
    ルールは「早い者勝ち」（誰かが決めたキャラは他の人は選べない）が基本で、スイッチひとつで「同じキャラを何人でも選べる」にもできます。

    誰が使う
    デザイナー（立ち絵・アイコン・背景の差し替え）／プランナー（キャラ名・能力・スキルの文章、ルール）
    開き方
    Assets/Scenes/Character_Select.unity。最初の 1 回（と作り替えたとき）は Tools›キャラ選択›シーンを組み立てる
    必要なもの
    無くても動く（仮のキャラは赤・青・緑・黄のキューブで、名前は全部「キャラ名（仮）」。仮の文章も入っている）。差し替えるときは立ち絵・顔のアイコン・背景（会社のオフィス）の PNG
    今の状況
    絵・文章はすべて仮（キャラはキューブの色で見分ける）。操作は仮の A キー（握力センサーでも動く）。選んだキャラはまだゲーム本編では使っていない。この画面構成は Unity での確認がこれから

    4つの区画

    左上 1P・左下 2P・右上 3P・右下 4P。区画にはその人の色がうっすらかかり、キャラ名の札と説明の板もその人の色。左に立ち絵（今は仮のキューブ。ふわふわ動く。キャラを変えると横からすべり込む）。参加していない人の区画は薄くなる。

    📝

    名前・能力・スキル

    キャラ名、能力の棒グラフ（いくつでも）、スキル名、スキルの説明は、キャラのファイルに文章を打ち込むだけ。今は仮の文章が入っている。

    棒グラフはキャラを変えるとするっと伸び縮みする

    ⭕

    下の丸（1P〜4P）

    左から 1P・2P・3P・4P。上の区画と同じく、その人が今選んでいるキャラ（仮はキャラの色のキューブ）を映す。長く握っている間は縁に沿ってゲージが伸び、決まると縁がその人の色になって「1P」の札にチェックが付く。参加していない人の丸は薄くなる。

    「1P」の札は 1P・2P が丸の上、3P・4P が丸の下

    👆

    短く握る／長く握る

    0.6 秒より前に離すと「カーソル移動」、0.6 秒握り続けると（離さなくても）「決定」。決めた後にもう一度長く握ると取り消せる。

    今は仮で A キー。握力センサー（キーボードの握力の代わりの Q なども）でも同じように動く

    🔒

    早い者勝ち（切り替えできる）

    誰かが決めたキャラは、ほかの人は選べない。そのキャラにいた人は自動で次の空いているキャラへ動く。選べないキャラで決めようとすると、区画がぶるっと揺れる。

    「同じキャラを選べる」をONにすると、何人でも同じキャラにできる

    🪥

    歯磨き粉の幕で切り替わる

    ロビーからキャラ選択に入るときと、「GO!」のあとゲームへ進むときは、歯磨き粉の幕が上から垂れてきて画面を覆い、次の画面が読み込めたら抜けていく。2026-10-22 からは、描いてもらった連番の絵（60枚）を使っています。キャラ選択では、流れ落ち始めると区画が滑り込んでくる。

    このシーンだけで再生したときも、最初に幕が流れ落ちるところから始まる（見た目を試せる）

    🪥

    歯磨き粉で塗り替えて切り替え

    キャラを変えると、しま模様の歯磨き粉の線が、左の真ん中から書き始めて「／」の向きに傾いたジグザグで右へ進み、最後は右上へ抜けるように、キャラの上から外まで引く（区画の外には出ない）。引き終わったところで新しいキャラに替わり、歯磨き粉は泡になってはじけて消え、最後にキラーンと光る。

    READY! のはんこと GO! には歯が付き、決めた瞬間には泡・キラキラと一緒に歯も弾ける

    🫧

    電脳世界と歯磨き粉の演出

    背景は電脳オフィス（仮）。区画にはプレイヤーの色のドット柄と流れる斜めのしま。画面には歯磨き粉の泡が昇り、2進数（0と1）がうっすら降り、キラキラがまたたく。

    キャラを変えるとキャラ名に「ザザッ」と色ずれ、決めると「READY!」のはんこが叩きつけられ、白く光って泡とキラキラが弾ける。全員決まると画面が光って「GO!」

    🌐

    4人対戦（LAN）・1台で試す

    4台の PC それぞれで、自分のキャラだけを操作する。ホストの PC が判定して全員に配るので、全員の画面は同じになる。このシーンだけで ▶ 再生すると、1台で 1P〜4P を A S D F で試せる。

    シーンを組み立てる（最初の 1 回・作り替えたとき）

    03 — Recipes

    「〜したい」から
    探す。

    絵の差し替えや数値の調整を1か所でしたい見た目と数値の調整

    Tools›キャラ選択›見た目と数値の調整 を開きます。

    • キャラ：キャラごとに名前・色・立ち絵・下の丸の顔・スキル名・スキルの説明・能力を書き換える。＋ キャラを増やす で複製して増やせる。
    • 画像の差し替え：背景・仮のキャラ・ドット柄・札・板・歯・泡などが絵つきで並ぶ。画像を選んで差し替える で PNG / JPG を選ぶと、その絵に替わる（使っている所は全部）。仮の絵に戻す で元に戻せる。
    • 数値：ルール・キャラの切り替え（塗り方）・READY!・下の丸・登場・漂う泡・ロビーからの幕の数値。4つの区画や4つの丸の分は、まとめて同じ値になる（キャラ選択のシーンを開いておく）。変えたら シーンを保存。

    シーンを組み立て直すときは 数値を引き継いで作り直す を選ぶと、ここで変えた数値が残ります。

    キャラ名・スキル内容を書き換えたいキャラのファイル

    キャラのファイル（Assets/CharacterSelect/Data/Characters/）の Display Name（区画の札・アイコンの名前）、Skill Name（スキル名。空なら出さない）、Skill Description（スキルの説明。改行もできる）。説明は 3 行くらいまでが枠に収まります。

    能力の棒グラフを変えたい・増やしたいStats

    キャラのファイルの Stats。＋ で増やし、Label（名前。空なら棒だけ）と Value（長さ 0〜1）を入れます。上から順に並びます。3〜4 本が板に収まる目安です。キャラごとに本数が違ってもかまいません。

    仮のキューブを本物の立ち絵にしたいSprite
    1. 絵（PNG）を Project に入れ、Texture Type を Sprite (2D and UI) にする。
    2. キャラのファイルの Sprite にドラッグ。
    3. Sprite Tint を白に戻す（仮のキューブはここで色を付けているため）。

    区画の左の枠（300×340）に縦横の比率を保って入り、下の丸の中にも同じ絵が出ます。大きさは Sprite Scale（足元を中心に拡大）、位置は Sprite Offset（ピクセル）で調整。

    仮のキューブの色を変えたいSprite Tint

    キャラのファイルの Sprite Tint（立ち絵にかける色）を変えます。区画の立ち絵と下の丸の両方のキューブの色が変わります。キャラを増やしたときも、複製して Sprite Tint を別の色にすれば見分けられます。

    下の丸に顔だけの絵を出したいIcon

    キャラのファイルの Icon に顔の絵を入れます（色はかけず絵のまま出ます）。空のときは立ち絵（Sprite、Sprite Tint の色つき）が丸の中に出ます。それも無いときは、キャラの色（Theme Color）の丸に名前の 1 文字目。

    背景を会社のオフィスの絵にしたいCS_Background_Cyber

    Assets/CharacterSelect/Art/CS_Background_Cyber.png（今は仮の電脳オフィスの絵）を同じ名前の絵（1920×1080 がおすすめ）で上書きします。または [CharacterSelect UI] › Background の Image に別の絵を入れます。区画にはプレイヤーの色がうっすらかかります（濃さは各区画の Player Panel › Area Tint Alpha）。

    キャラを増やしたい・減らしたい・並びを変えたいキャラの一覧
    1. Project で既存のキャラのファイルを選んで Ctrl+D（複製）し、名前・Id・文章・絵を変える（新しく作るなら右クリック Create›MS2026›キャラ選択›キャラクター）。
    2. Tools›キャラ選択›キャラの一覧を選ぶ の Characters に足す。上から順が、短く握ったときに切り替わる順番です。空の欄は作らないでください。

    仮のキューブのまま増やすときは、Sprite Tint を別の色にして見分けられるようにします。早い者勝ちのルールでは、キャラは 4 体以上にしておくと全員が別のキャラを選べます。

    札・板・丸の絵を替えたいArt

    Assets/CharacterSelect/Art/ の同じ名前の PNG を上書きすると替わります：CS_NameTag（キャラ名の斜めの札。高さ 64 のまま）、CS_Panel（説明の板・スキルの枠）、CS_Bar（棒グラフ・ゲージ）、CS_Pill（「1P」の札・はんこ）、CS_Ring / CS_Circle（下の丸の縁と中）、CS_Check（決定の印）、CS_CharaCube（仮のキャラ）、CS_Tooth（歯）、CS_Halftone（区画のドット柄）、CS_Stripes（流れるしま）、CS_Frame（区画の白い枠）、CS_Bubble / CS_Sparkle（泡・キラキラ）。白で描いてあり、画面の側でプレイヤーの色・キャラの色を付けています。

    同じキャラを何人でも選べるようにしたいAllow Same Character

    [CharacterSelect] › Character Select Controller › Allow Same Character を ON。右下の文字が「同じキャラ：えらべる」に変わります。再生中に OFF に戻すと、同じキャラを決めていた人は番号の小さい人だけ残り、ほかの人は「えらび中」に戻ります。

    長押しの長さを変えたいLong Press Seconds

    Long Press Seconds（既定 0.6 秒）。これより前に離すと「カーソル移動」、ここまで握ると「決定」。長くすると誤って決めにくくなり、短くすると素早く決められます。

    決めた後は取り消せないようにしたいLong Press Cancels

    Long Press Cancels を OFF にします（既定 ON = 決めた後にもう一度長く握ると取り消し）。

    制限時間を付けたいTime Limit Seconds

    Time Limit Seconds に秒数（0 = 制限なし）。画面の上の真ん中に「のこり ○」が出て、0 になると、まだ決めていない人は今のキャラ（使われていれば空いているキャラ）に自動で決まります。

    「GO!」からゲームへ進むまでを長く／短くしたいFinished Hold Seconds

    Finished Hold Seconds（既定 1.5 秒）。

    仮のキーを変えたいKey

    ネット対戦（ロビーから来たとき）は Key（既定 A）。このシーンだけで試すときの 1P〜4P は Offline Keys（A・S・D・F）と Offline Players（参加する人数、既定 4）。握力センサーを使わないなら Use Grip Sensor を OFF。画面左下の操作の説明は、再生するとキーに合わせて自動で書き換わります。

    区画・文字・アイコンの配置や大きさを変えたい[CharacterSelect UI]

    シーンの [CharacterSelect UI] の中を直接動かします。区画は Panels › Panel 1P〜4P（中に立ち絵 Portrait、説明の板 InfoPanel、キャラ名の札 NameTag など）。区画の場所を入れ替えてもかまいません（どの区画が何 P かは Character Select View › Panels の順番）。棒グラフ 1 本の見た目は InfoPanel › Stats › StatTemplate（非表示の見本）を直すと全部に反映されます。下の丸は Circles › Circle 1P〜4P（どれが何 P かは Character Select View › Circles の順番）。

    !
    注意：「シーンを組み立てる」をもう一度実行すると、シーンの中で直した配置・文字は作り直されて消えます。キャラのファイル（文章・絵）・PNG の上書きは消えません。
    立ち絵のふわふわ・すべり込みを変えたいPlayer Panel

    各区画の Player Panel の Bob Pixels（上下の幅、8）、Bob Speed（速さ、0.5）、Slide In Pixels（キャラを変えたときに横からすべり込む距離、60）。参加していない区画の薄さは Inactive Alpha。

    キャラを変えるときの歯磨き粉の塗り方・速さ・消え方を変えたいCharacter Swap Fx

    各区画の Portrait の Character Swap Fx：Clip To Character（オンでキャラの形の中にだけ塗る。ふつうはオフ＝道すじのとおりに外まで引く）、Fill Gaps（オンで線を自動で太くして、すき間なく塗りつぶす。前のキャラが完全に隠れる。Legs 9 くらいと合わせる）、Lean（ジグザグの傾き、35 度。大きいほど「／」に寝る。0 で縦に往復、マイナスで「＼」）、Legs（線の本数、11。多いほど細かいジグザグ。最後が右上へ抜けるよう、偶数なら1本増える）、Size（ジグザグ全体の大きさ、0.55。1 で立ち絵の枠くらい、小さいほどキャラのまわりにまとまる）、Paint Seconds（塗り終わるまで、0.45）、Hold Seconds（塗ったまま、0.06）、Reveal Style（泡になって消える／同じ道をたどって拭き取る）、Reveal Seconds（消えるまで、0.3）、Jitter（毎回少し形を変える量）、Overshoot（枠の外まで塗る量）、Foam Interval（泡）、Shine Seconds / Shine Size（キラーン）。線の太さとしまの見え方は Body › PasteLayer › PasteFrame › Paste › Stroke の Paste Stroke（Width 38。Fill Gaps がオンのときは、すき間が残らない太さより細くはならない。Texture は最初はタイトルと同じ歯磨き粉の絵、Texture U が狭いほどしまが太い）。歯の絵は Art/CS_Tooth.png を上書きすると替わります。止めたいときは Player Panel › Swap を空にすると、すぐ切り替わります。

    キャラ選択に入るとき・GO! のあとの歯磨き粉の幕を変えたい歯磨き粉の幕の設定

    Tools›キャラ選択›歯磨き粉の幕の設定を選ぶ（Assets/CharacterSelect/Resources/CharacterSelectCurtain）。
    連番の絵（今はこれを使っています。2026-10-22）：Frames に入っている連番（Assets/_Game/UI/Transitions/Frames/Transition1/ の tora00〜tora59）を画面いっぱいに順番に出します。Frame Rate（1秒の枚数、30）、Covered Frame（画面を覆いきるコマ、24。ここで次の画面の読み込みを始める）、Reveal Frame（抜け始めるコマ、32。読み込みが長いときは、この1つ前のコマで止めて待つ）。絵描きさんが書き出し直したら、連番をプロジェクトにコピーしてから Tools›キャラ選択›歯磨き粉の幕に連番を入れる でフォルダを選ぶと、入れ替わります。Frames を空にすると、下の「列を垂らす幕」に戻ります。
    列を垂らす幕（連番が空のとき）：Texture（幕の絵。最初はタイトルのオープニングと同じ Title_PasteCurtain）、Columns（縦の列の数）、Unevenness（垂れる先端のでこぼこ）、Drop Seconds（覆いきるまで）、Hold Seconds（覆ったままの最短時間。連番のときもこれは使う）、Reveal Seconds（流れ落ちるまで）、On Cover / On Reveal（効果音）。このシーンだけで再生したときに幕を出したくなければ Play On Standalone を OFF。「GO!」のあとはロビーのいつもの幕にしたいときは Use For Game Start を OFF。

    設定は再生を始めたときに読み込むので、変えたら再生し直してください。

    演出（泡・2進数・色ずれ・光・はんこ）を強く／弱く／止めたい演出の部品
    • 漂う泡・2進数・キラキラ：[CharacterSelect UI] › Ambient の Bubble Count・Digit Count・Sparkle Count（0 で出さない）、大きさ・速さ・色。止めるなら Ambient を非表示。
    • キャラ名の色ずれ：各区画の NameTag › Name の Character Select Glitch › Amplitude（ずれの幅）・Duration（長さ）。Idle Interval に秒数を入れると、ときどき勝手にザザッとなる。
    • 決定のはんこ：各区画の Player Panel › Stamp Slam Seconds・Stamp Slam Scale。
    • 弾ける泡とキラキラ：各区画・各丸の Burst、真ん中の CenterBurst の Size・Speed・Gravity（マイナスで上へ浮く）・Life。
    • 流れるしま：各区画の Stripes の Speed（0 で止まる）と色の濃さ。ドット柄の濃さは Player Panel › Pattern Alpha。
    • 登場の動き：Character Select View › Entrance Seconds・Entrance Stagger・Entrance Distance（0 で動かない）。
    選ぶ・決める・全員決定で効果音を出したい音・演出

    Character Select Controller の On Move（カーソル移動）、On Confirm（決定）、On Cancel、On Rejected（選べないキャラで決めようとした）、On All Decided に D-Drive の SE を選びます。ネット対戦では各 PC が自分で鳴らします。この画面は UI なので、VFX（エフェクト）は場所が合いません（効果音向け）。

    04 — Hierarchy

    シーンの
    中身。

    [CharacterSelect]

    進行役（Character Select Controller：ルール・操作・音）と見た目の係（Character Select View：区画とアイコンを動かす）。

    [CharacterSelect UI] › Panels › Panel 1P〜4P

    プレイヤーの区画（左上 1P・左下 2P・右上 3P・右下 4P）。部品は Player Panel。

    • AreaTint — 区画にうっすらかかるプレイヤーの色。
    • Body › Portrait — 立ち絵（Image）。立ち絵が無いキャラは Fallback（色の丸）と Letter（頭文字）。
    • Body › InfoPanel — 説明の板。Stats（棒グラフ。StatTemplate が見本）、SkillBox（SkillName・SkillText）、HoldGauge（長く握る間に伸びる）、State（えらび中／READY!など）。
    • Body › NameTag — キャラ名の斜めの札。PlayerLabelBack — 「1P」の札。PlayerName — ネット対戦のときのプレイヤーの名前。LocalMark — 「あなた」（ネット対戦のときだけ）。DecidedStamp — 「READY!」のはんこ。

    [CharacterSelect UI] › Circles › Circle 1P〜4P

    下の丸（左から 1P・2P・3P・4P）。上の区画と同じく、その人が選んでいるキャラを映す。部品は Player Circle。

    • HoldGauge（長く握る間に縁に沿って伸びる）・Ring（縁。えらび中は紺、決定するとその人の色）・Back・Face（キャラ。仮は色つきのキューブ）・Letter。
    • Label 1P〜4P — 「1P」の札（1P・2P は丸の上、3P・4P は下）。決定するとチェック（Decided）が付く。

    演出の部品

    どれも消しても画面は動きます（演出が無くなるだけ）。

    • Ambient — 画面全体を漂う泡・2進数・キラキラ（Character Select Ambient）。
    • 各区画の Pattern（ドット柄）・Stripes（流れるしま）・Frame（白い枠）・Flash（決定で白く光る）・Burst（決定で弾ける泡とキラキラ）。キャラ名の Character Select Glitch（色ずれ）。
    • ScreenFlash・CenterBurst — 全員決定のときの光と弾け。FadeOut — 1台で試すとき、ゲームへ進む前に覆う板。

    その他

    Background（背景）、Dividers（区画の仕切りの線）、Bottom（下の部分。中に BottomBar・Circles・Help・Rule。登場のときにせり上がる）、Timer（制限時間）、DecidedBanner（GO!）。Main Camera は画面を塗るだけ。

    06 — Troubleshooting

    困ったときは
    ここ。

    前の作り（キャラが台の上に並ぶ画面・下にキャラのアイコンが並ぶ画面）のまま／「Missing Script」が出る
    画面を作り替えたので、Tools›キャラ選択›シーンを組み立てる → 作り直す を実行してください。前の作りの部品は消えています。
    ロビーで「キャラクター選択に進めませんでした」と出る
    ビルドの設定にキャラ選択のシーンが入っていません。Tools›キャラ選択›シーンを組み立てる を実行すると足されます（または File›Build Profiles の Scene List に Character_Select を足す）。
    再生しても何も出ない／キャラが出ない
    シーンを組み立てていないか、キャラの一覧が空です。Console に「キャラの一覧（roster）が空です」と出ていたら、Character Select Controller › Roster に一覧のファイルが入っているか確認します。
    ネット対戦では、どのキーで操作する？
    全員 A（と握力センサー）です。各 PC は、ロビーで選んだ自分の番号の区画だけを操作できます（ほかの人の区画は、その人の PC から届いた操作で動く）。キーは Character Select Controller › Key で変えられます。1 台で試すとき（このシーンだけで再生）だけは、1 つのキーボードで 4 人分を動かすため 1P〜4P が A S D F に分かれます。
    Q キーで READY になってしまう
    Q（W・O・P）は握力センサーのキーボードでの代わりです。キャラ選択では Character Select Controller › Ignore Keyboard Grip（最初から ON）で無視するので、Q では READY になりません。本物の握力センサーと仮のキー（A）は使えます。
    ロビーの「握り続けて準備OK」は別の仕組みで、Q を押し続けると準備OKが切り替わります（ロビーのシーンの [Lobby] Session › 握って準備OK で OFF にできます）。
    同じキャラを2人で長押しすると、遅れた人が別のキャラで一瞬で READY になる
    2026-10-12 に直しました。先に READY になった人がいると、もう1人のカーソルは次の空いているキャラへ自動で動きます。このとき長押しは取り消され（その人の区画と下の丸がぶるっと揺れる）、一度離して握り直すまで数えません。同じキャラを2人で選べる設定（Allow Same Character）のときは、カーソルが動かないので2人とも READY になれます。
    連打すると READY になってしまう
    2026-10-12 に直しました（キーの「押した・離した」を1回ずつ数えるようにし、握力センサーは握り直しも「離した」と数える）。それでもセンサーで起きるときは、Character Select Controller の Grip Release Dip（握り直しとみなすゆるみ、0.25）を小さく、Long Press Seconds を長くしてください。
    キーを押しても動かない
    1. Game ビューをクリックしてから押してください。
    2. 最初から押しっぱなしだったキー・握りは、一度離すまで数えません。
    3. 「GO!」の後と、Esc の一時メニューが開いている間は操作できません。
    4. ネット対戦では自分の分（ロビーで選んだ番号）だけが動きます。
    決めようとすると区画がぶるっと揺れて決まらない
    そのキャラは他の人が先に決めています（早い者勝ち）。短く握って別のキャラへ。全員で同じキャラを選べるようにするなら Allow Same Character を ON。
    スキルの説明が枠からはみ出す
    説明は 3 行くらいまでが目安です。文章を短くするか、区画の InfoPanel › SkillBox と SkillText を大きくします。
    立ち絵が小さい・大きい・ずれる
    キャラのファイルの Sprite Scale（大きさ）と Sprite Offset（ピクセル）で調整します。絵の下や横に透明な余白が多いと小さく見えるので、余白を切った絵にすると合わせやすくなります。
    ロビーに戻りたい
    Esc で一時メニュー → ホストは 全員でロビーに戻る、参加している人は 試合から抜ける。
    選んだキャラがゲームに出てこない
    今はまだゲーム本編に選んだキャラを使う仕組みがありません（選んだ結果を残すところまで）。プログラマーに相談してください（下の「コードから使う」）。
    07 — Words

    分からない言葉は
    ここで引く。

    キャラのファイル
    キャラ 1 体分の設定（名前・能力・スキル・立ち絵・顔のアイコン）。1 キャラ = 1 ファイル（Character Definition）。
    キャラの一覧
    選べるキャラを並べたファイル（Character Roster）。並び順 = 短く握ったときに切り替わる順。
    区画
    画面を 4 つに分けた 1 つ。各プレイヤーの選んでいるキャラが出る（Player Panel）。
    下の丸
    画面の下の 1P〜4P の丸（Player Circle）。区画と同じく、各プレイヤーの選んでいるキャラ・決定を映す。
    ホスト
    ネット対戦で部屋を作った PC。キャラ選択の判定（決められるか・全員決まったか）もこの PC が行う。
    Sprite（スプライト）
    Unity で 2D の絵として使える画像。PNG を入れて Texture Type を Sprite (2D and UI) にする。
    早い者勝ち
    誰かが決めたキャラは他の人が選べないルール（Allow Same Character が OFF）。
