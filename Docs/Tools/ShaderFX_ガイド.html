    SHADERFX

    MS2026 ShaderFX — 光る・溶ける・凍る・燃える を「後付け」する

    「光る縁」「溶けて消える」「被弾で白く光る」を、
    設定ファイルに積むだけで付けられる。

    たとえるなら「写真アプリのフィルター」。1 つの設定ファイル（Effect Profile）にフィルターを好きなだけ重ねておき、それをキャラや物に貼ると見た目が変わります。同じ設定を何千体に貼っても重くならないように作られています。

    誰が使う
    デザイナー・プランナー（見た目づくり）、プログラマー（被弾など出来事との連動）
    作り方
    Project で右クリック Create›ShaderFX›Effect Profile
    一覧
    Tools›シェーダーFX›プロファイルブラウザ
    今の使用状況
    パッケージは導入済み。ゲーム本編ではまだ未使用（デモが Assets/ShaderFX_Demo/ にあります）
    01 — How it works

    登場人物は
    3 つだけ。

    PROFILE → TARGET → DIRECTOR
    設定ファイル
    Effect Profile
    効果を積み重ねたレシピ。「+ Add Effect」で足していく。
    貼るシール
    Effect Target
    キャラや物に付ける部品。どの Profile を使うかを持つだけ。
    裏方（自動）
    Effect Director
    シーンに自動で現れて、全員にまとめて効果をかける。触らなくていい。
    !
    効果が見えるには、その物のマテリアルのシェーダーが ShaderFX/Uber（3D）か ShaderFX/Uber Sprite（2D スプライト）である必要があります。ここだけは最初に一度設定してください。
    02 — Catalog

    使えるエフェクト
    16 種類。

    上の 10 種は「その物だけ」にかかる オブジェクト系、下の 6 種は「画面全体」にかかる 画面系。見本は雰囲気を伝えるイメージです。

    リムライト 2D/3D

    輪郭（縁）を光らせる。アニメ調キャラの定番。

    ディゾルブ 2D/3D

    模様状に溶けて消える。消える進み具合を 0→1 で動かす。

    被弾フラッシュ 2D/3D

    一瞬だけ色を差し替えて光らせる。白で定番の被弾表現。

    発光（エミッション） 2D/3D

    自分で光る。点滅の速さも設定可能。

    発火（ファイア） 2D/3D

    揺らめく炎のグロー。色を変えれば毒炎・魔法の炎。

    氷結（フロスト） 2D/3D

    青みがかった凍った質感＋きらめき。

    ホログラム 2D/3D

    縁の発光＋走査線＋ちらつき。SF の敵に。

    グリッチ 2D/3D

    ブロック状のずれ＋色ズレ。故障・ハッキング表現。模様のある絵でないと見えにくい。

    UV スクロール 2D/3D

    筋状の光が流れる。溶岩・魔法陣・エネルギーライン。

    トゥーン影 3D のみ

    陰影を段階的にくっきり。2D スプライトでは変化なし。

    白黒化 画面

    画面全体をモノクロに。回想シーンなど。

    ポスタリゼーション 画面

    色数を減らして劇画・レトロ調に。

    ドット絵化 画面

    モザイク状に。「敵だけドット絵」も可能（要プログラマー）。

    アウトライン 画面・3D

    コミック風の輪郭線。2D スプライトには付かない。

    衝撃波 画面

    画面上の 1 点から輪状に歪みが広がる。ボス登場など。

    画面フラッシュ 画面

    画面全体を一色に。被弾で赤、回復で白。

    03 — First 5 minutes

    キャラの縁を
    光らせてみる。

    1

    Effect Profile を作る

    Project ウィンドウで右クリック → Create›ShaderFX›Effect Profile。名前は「Profile_敵_通常」のように用途が分かる名前に。

    2

    「+ Add Effect」で効果を足す

    作った Profile を選ぶと Inspector に + Add Effect ボタンがあります。オブジェクト系›リムライト を選び、色・強さ などを調整。

    迷ったら プリセット›オブジェクト系›アニメ調キャラ標準 を選ぶと、完成形の組み合わせがまとめて入ります。

    Inspector — Profile_敵_通常 (Effect Profile)
    + Add Effect ▾
      リムライト色 #4DE6FF · 強さ 1.5×
    Color
    Power
    3
    Intensity
    1.5

    効果は折りたたみ式。✓ で ON/OFF、× で削除

    3

    見せたい物のマテリアルを ShaderFX 用にする

    その物のマテリアル（無ければ新しく作る）の Shader を、3D なら ShaderFX/Uber、2D スプライトなら ShaderFX/Uber Sprite に変える。

    4

    Effect Target を付けて Profile を入れる

    その物に Add Component›ShaderFX›Effect Target を付け、Profile 欄に 1 で作ったファイルを入れます。Play しなくても、その場で Scene に反映されます。

    縁が光ったら成功。Profile の数値を変えると、それを使っている全員が一斉に変わります

    04 — Recipes

    「〜したい」から
    探す。

    完成形の組み合わせから始めたいプリセット

    + Add Effect の プリセット から選ぶと、組み合わせがまとめて入ります。オブジェクト系 13 種（アニメ調キャラ標準・聖なる守護者・ホログラム敵・サイバーステルス・氷結・呪われたアンデッド・発火・炎の魔物・パワーアップ状態・トゥーン標準・ディゾルブ消滅・被弾フラッシュ・グリッチ故障）、画面系 8 種（回想シーン・レトロゲーム風・ドット絵フィルター・コミック風輪郭線・被弾赤フラッシュ・回復白フラッシュ・衝撃波・気絶暗転）。入れた後も自由に調整できます。

    同じ見た目をたくさんの物に使い回したいProfile

    同じ Profile を全員の Effect Target に入れるだけ。何百体に入れても、Profile の種類が増えない限り重くなりません。見た目を変えたいときは Profile を 1 か所直せば全員変わります。

    プロジェクト内の Profile を一覧で見たいブラウザ

    Tools›シェーダーFX›プロファイルブラウザ。Search で絞り込み、Ping で場所を表示、Select で選択。

    このエリアに入った物だけ凍らせたいEffect Volume
    1. 空の GameObject に Collider（2D なら Collider2D）を付け、範囲を決める。
    2. Add Component›ShaderFX›Effect Volume（Is Trigger は自動で ON）。
    3. Overlay Profile に「氷結」の Profile を入れる。

    入った Effect Target に氷結が重なり、出ると元に戻ります。物理の仕様上、どちらかに Rigidbody が必要です。

    敵が攻撃を受けた瞬間に白く光らせたい要プログラマー

    Profile に 被弾フラッシュ（強さ 0）を入れておき、被弾の瞬間にコードで PlayHitFlash(1, 0, 0.2) を呼んでもらいます（0.2 秒で 1→0）。演出の作り込み（色・時間）は Profile 側で調整できます。

    倒したときに溶けて消えるようにしたいTimeline / 要プログラマー

    Profile に ディゾルブ（消える進み具合 0）を入れておき、倒れたときに PlayDissolve(0, 1, 0.5) を呼びます。カットシーンなら Timeline の ShaderFXParameterTrack で、コード無しで動かせます。

    画面全体を白黒・レトロ調にしたい画面系

    Profile に画面系の効果（白黒化・ポスタリゼーション・ドット絵化など）を入れ、シーン内のどれか 1 つの Effect Target にその Profile を入れれば、画面全体にかかります。画面系は「シーンで 1 つの設定」なので、複数あると最後に処理されたものが勝ちます。

    2D スプライトに使いたい2D

    手順は 3D と同じで、マテリアルのシェーダーを ShaderFX/Uber Sprite にするだけ。トゥーン影は効かず、アウトラインの輪郭検出にも入りません。影も落としません。

    見つかりませんでした。別の言葉で探してください。

    !
    このゲームでの注意
    ・群衆（数千体の敵）には使えません。群衆の敵は 1 体ずつの GameObject を持たない特別な描き方をしているため、Effect Target を付けられません。使えるのはコア・砲台・破壊可能物・個別に置いた敵などです。
    ・要塞デザイナーの 「絵を立たせる（ビルボード）」と同じ絵に使うと、その絵は立たなくなります（ShaderFX のマテリアルが優先されるため）。

    06 — Troubleshooting

    困ったときは
    ここ。

    Profile を入れたのに見た目が変わらない
    1. マテリアルのシェーダーが ShaderFX/Uber / ShaderFX/Uber Sprite になっているか。
    2. Effect Target に「Effect Profile が未設定です」「Renderer が見つかりません」と出ていないか（Renderer を持つ物に付ける）。
    3. 効果の ✓（enabled）が ON か。ディゾルブ・被弾フラッシュは 強さ 0 だと見えないのが正常。
    4. グリッチは単色の物だとずらす模様が無く見えません。
    保存したら見た目が戻った／マテリアルが壊れた気がする
    エディタでのプレビューは一時的なマテリアルを使っていて、保存の瞬間だけ元に戻してから書き込む安全装置があります。保存後は自動で再適用されるので、ファイルは壊れていません。
    画面系の効果が 2 つ同時にかからない
    画面系の設定はシーンで 1 つです。複数の Effect Target が別々の画面系 Profile を持つと、最後に処理されたものが勝ちます。1 つの Profile にまとめてください。
    07 — Words

    分からない言葉は
    ここで引く。

    シェーダー
    物の表面をどう描くかの計算。ShaderFX の効果はシェーダーの中で動く。
    マテリアル
    シェーダー＋色や画像の設定。物に貼る「塗装」。
    Effect Profile
    効果を積み重ねた設定ファイル（レシピ）。
    Effect Target
    物に付ける部品。「この物にはこのレシピ」を指定する。
    オーバーレイ
    本来のレシピを残したまま、一時的に別の効果を上に重ねること。外せば元通り。
    オブジェクト系／画面系
    その物だけにかかる効果／カメラの絵全体にかかる効果。
    Tween
    値を時間をかけて変化させること（例：0.5 秒で 0→1）。
    08 — For programmers

    出来事との
    連動はコードで。

    名前空間 MS2026.ShaderFX。EffectDirector はシーンに自動生成されます（Edit Mode でも非表示で生成）。

    EffectTarget
    using MS2026.ShaderFX;

var fx = GetComponent<EffectTarget>();
fx.PlayHitFlash(1f, 0f, 0.2f, ShaderFXEase.OutQuad);     // 被弾
fx.PlayDissolve(0f, 1f, 0.5f, ShaderFXEase.OutQuad,
                () => Destroy(gameObject));             // 消滅
fx.SetInstanceDissolveAmount(0.3f);   // この 1 体だけ（GPU Instancing でまとめ描き）
fx.ClearInstanceOverrides();
    前提対象モジュール（HitFlash 等）が Profile 側で有効になっていること。API は値を書くだけで ON/OFF はしない。
    性能_DissolveAmount/_HitFlashAmount 以外の任意プロパティはインスタンシング対象外。
    EffectDirector
    var d = EffectDirector.Instance;
d.ApplyToGroup(EffectGroup.Enemy, hitFlashProfile);   // Group で一括
d.RemoveFromGroup(EffectGroup.Enemy);
d.ApplyToTag("Enemy", dissolveProfile);               // EffectTarget 無しの物にも
d.NotifySpawned(spawned);                             // Instantiate 直後
d.PushOverlay(target, "HitFlash", profile, priority: 10);
d.PopOverlay(target, "HitFlash");
    EffectGroupRuntime/EffectGroup.cs（Player/Enemy/Stage/Pickup/UI3D）。プロジェクトに合わせて書き換えてよい。
    EffectModule
    [Serializable]
[EffectModuleInfo("My Effect", "オブジェクト系")]
public sealed class MyEffectModule : EffectModule
{
    public override string Keyword => "_FX_MYEFFECT";
    public override void ApplyTo(Material m) { /* m.SetFloat(...) */ }
    public override int ComputeParameterHash() => HashCode.Combine(/* params */);
    public override string GetSummary() => "一行サマリー";
}
    必須キーワード分岐を ShaderFXUber.shader と ShaderFXUberSprite.shader の両方に追加。片方だけだと黙って効かない。
