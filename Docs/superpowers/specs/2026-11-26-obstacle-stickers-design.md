# 障害物シール 設計

- 日付: 2026-11-26（ユーザーと相談して決定）
- 見え方の見本: `Docs/superpowers/specs/2026-11-26-obstacle-stickers-look-demo.html`（ブラウザで開くと動く。A 紙・B ホログラム・C ぷっくりの3通り）
- 計画書: `Docs/superpowers/plans/2026-11-26-obstacle-stickers.md`

## 1. 何のために作るか

ステージの障害物（壁・壊せる壁）にシールをたくさん貼って、**ポップでにぎやかに見せる**。
シールはふだんキラキラしていて、**スキルの攻撃が当たると光り、当て続けると焼けこげる**。戦いの跡が残っていく。

## 2. 決まったこと（ユーザー決定）

| 項目 | 決定 |
|---|---|
| 目的 | ステージの障害物をポップでにぎやかに見せる |
| 貼り方 | 自動でばらまく。気に入らない所だけ手で直す（動かす・回す・大きさ・消す・足す） |
| 絵柄 | デザイナーが描いた PNG |
| 作り方 | シール1枚ずつを「小さな板」にして、障害物の表面に沿わせて貼る（Unity のデカール・テクスチャ焼き込みは使わない） |
| 動き | ふだんキラキラ → スキルが当たると光る → 当て続けると焼けこげる |
| 反応する攻撃 | **スキルだけ**。ふだんの砲台のレーザーでは何も起きない |
| 見え方 | A 紙シール・B ホログラム・C ぷっくりシールを**全部作る** |
| 見え方を選ぶ単位 | **絵柄ごと**（PNG の種類ごとに A/B/C を決める） |

## 3. Claude が決めて、ユーザーが「それで大丈夫」と言ったこと

- **反応するスキル**
  - 赤の極太レーザー: 壁に当たっている所のシールが光り、当て続けると焦げる（続けて当たる＝Sustained）。
  - 黄色のリコシェアロー: 壁ではね返った点のシールが一瞬強く光り、少し焦げる（一回だけ＝Pulse）。
  - 緑（葉が回る）・青（うがい薬のボトルを投げて床に渦）: 壁に当たらないので何もしない。あとから足せるよう、スキル → シールの知らせ口は共通にする。
  - 注: 相談中に「青はまだできていない」と言ったが、実際は main に青（`Assets/BlueSkill/`）がある。床に渦を出すスキルで壁には当たらないため、結論（何もしない）は同じ。
- **焦げ**は試合が終わるまで残り、次の試合で元に戻る。焦げの状態はメモリにだけ持ち、保存しない（試合ごとにシーンを読み直すので自然に戻る）。
- **壊せる壁**が壊れたら、シールもいっしょに消える（壁と同じ溶け方）。再生した壁のシールは新品に戻る。はがれて飛ぶ演出は今回入れない。
- **道具の場所**: ステージ背景スタジオの「背景オブジェクト」の詳細に「シール」の欄を足す。最初に見せるのは **量・使う絵柄・ばらまき直す** の3つだけ。1枚ずつ直すのはシーンビューで行う。
- **絵柄の登録**: PNG を入れると絵柄の一覧に並び、絵柄ごとに見え方（A/B/C）・大きさのめやす・白いふちの有無を選べる。
- **ホログラムが多すぎるとき**: 上限で止めない。スタジオに「ホログラムの割合」の目安を出して知らせるだけ。
- **通信しない**。光る・焦げるは各 PC が自分の画面で計算する（CLAUDE.md の演出の決まりと同じ）。
- **対象は壁・壊せる壁だけ**。床・飾り・遅くなる地帯・歯のコアには貼らない。

## 4. 見え方（見本ページと同じ）

全スタイル共通: 白いふち（PNG の形から自動で作る。絵柄ごとに外せる）。色は4色まで・少し落ち着いた色・プレイヤー色（赤青黄緑）そのままは使わない・菌に見える丸いぶつぶつ形は避ける（これはデザイナーへの描き方のお願い。コードでは縛らない）。

| | A 紙シール | B ホログラム | C ぷっくり |
|---|---|---|---|
| ふだん | マットな紙。ときどき1枚だけ光の帯がすっと横切る（同時に光るのは少数） | 虹色がゆっくり流れ、小さな星がまたたく | ゼリーの立体シール。ふちが丸く盛り上がり、つやの点がときどききらっと光る。下に小さな影 |
| 当たる | ふちからオレンジに熱を帯びる | 白っぽく強く光る | 中から明かりがともったように光る |
| 焦げる | 茶色くすすけ、白いふちが黄ばんでから黒くなる。焦げた所の角がぎざぎざに欠ける | 虹色が抜けて灰色になり、黒いぷつぷつが出る | 少ししぼんで黒くなる。熱いうちは赤いひびが走る |
| 効く理由（`Docs/Reference/Beautiful_2D_Analysis.md`） | P1・P8（光る数を絞る）、P5 | ポップさ最大。P1 に注意 | P4（影で乗っている感じ）、P5 |

焦げ・光りの量は 1 枚ごとに 0〜1 で持つ。光りは冷めるが焦げは残る。

## 5. 仕組みの形（作り方の要点）

- **スキル → シールの知らせ口**: `MS2026.Fortress` に静的な `SkillSurfaceHits`（当たった点を流すだけ）を置く。赤のスキル（RedSkill のアセンブリ）と黄色の矢（Fortress）がそこへ報告し、シール（Stage のアセンブリ）が聞く。Stage と RedSkill はお互いを参照しないので、両方が参照している Fortress に置く。
- **シールの実体**: 障害物の `Visual`（揺れの支点）の下に子「Stickers」を作り、`StageStickerLayer`（配置データ・状態）と MeshFilter/MeshRenderer を付ける。全シールを1つのメッシュにまとめる（1枚 = 5×5 頂点の格子を表面に沿わせた板）。配置データ（格子の頂点位置・法線）はシーン/Prefab に保存し、メッシュはエディタで作って**アセットとして保存**する（ステージの Prefab に書き戻しても参照が切れないように）。Play 中はそのアセットの複製に光り・焦げを書く。モデルのメッシュは実行時に読まない。
- **重なり**: シールは少し重なってよい。list の順番が重ね順で、後ろほど少しずつ浮かせてちらつきを防ぐ。手で直したシールは一番上に来る。
- **当たりの距離**: スキルの当たる点は壁の足元の輪郭（2D）なので、シールの中心ではなく、シールの板の一番近い点までの距離（XY）で測る。届く半径は `StageLookProfile` で調整できる。
- **障害物の反応にそろう**: シールの Renderer は `Visual` の下にあるので、`StagePropRenderer` が透け穴・全体の薄さ・暗さ・溶けの値を自動で渡す。シールのシェーダーは `StagePropEffects.hlsl` の `StageClip` を使い、障害物と同じに穴があき・溶ける。ただし障害物の熱（ふだんのレーザーの光り・焦げ）は**使わない**。
- **光り・焦げの量**は頂点データ（UV1）で 1 枚ずつシェーダーへ渡す（MaterialPropertyBlock は `StagePropRenderer` が使っているので取り合わない）。
- **絵柄**は `StickerLibrary`（ScriptableObject）にまとめる。PNG は 256×256 の `Texture2DArray` に詰め、アルファに「形からの距離（SDF）」を入れる。白いふち・ぷっくりの盛り上がり・影・焦げのぎざぎざは、この距離から作る。
- **調整の値**（光る速さ・冷める速さ・焦げる速さ・色・当たりの半径など）は `StageLookProfile` に `stickers` として足し、ステージ背景スタジオの「見え方」で触れる。

## 6. やらないこと

- 床・飾り・歯のコアへの貼り付け、はがれて飛ぶ演出、ふだんのレーザーでの反応、通信、シールのアニメ（パラパラ）、Unity のデカール機能の有効化。
- ツールの資料（`Docs/Tools/`）の更新（CLAUDE.md の決まり）。

## 7. 作る人に任せること

- シェーダーの細かい式（色の混ぜ方・ノイズの種類）は、見本ページの見え方に近ければよい。
- 調整の値の初期値は計画書に書いたものから始め、Unity で見て変えてよい（変えたら報告する）。
