# 3Dトゥーン調整ウィンドウの作り直し（C 細長パネル型）

2026-11-20。見本ページ: https://claude.ai/artifact/19mzaC6GEj5CiVXXfe8F3R

## ねらい
- デザイナーさんが自分で触って、ステージの3Dの物のアニメ調の見え方（`MS2026/3DObject/Toon`）を決められるようにする。
- 今の窓（`Tools/3Dオブジェクト トゥーン/調整ウィンドウ`）は、開くと約60項目が全部見える。並びもシェーダーの区切りのままで、変えた所が分からず、検索もない。

## やること・やらないこと
- やる: 窓を C 案（シーンビューの横に置ける細長い1列）に作り直す。同じメニュー・同じ題名のまま置き換える。
- やらない: シェーダー・実行時の差し替え（`ObjectToonApplier`）・設定ファイル（`ObjectToonProfile`）の形は変えない。今ある材質と値はそのまま使える。
- やらない（ユーザー決定）: A/B の保存・見え方の候補・よく触る項目の入れ替えは入れない。
- 失敗の条件: デザイナーさんがシーンを見ながら触ったときに、「どこを触ればいいか」で手が止まること。

## 案の比較（ユーザーは C を選んだ）
- A 並べ直し: 今の窓のタブを3つに並べ直す。早く作れるが、詳しい設定を開くと31項目が縦に並ぶ。
- B スタジオ型: 左にページ一覧、下に説明の帯。1ページの項目は少ないが、窓が広くなり、ページの行き来が要る。
- **C 細長パネル型（採用）**: 幅300くらいの1列。シーンビューを広いまま横に置ける。行き来がない。

## 画面（上から）
1. **上の帯**: 題名と「エディタでもトゥーンで見る」（開いたらオン）。再生中は「実行中。変えた値は止めた後も残る」と出す。
2. **いま調整している物**: ふだんは「全部の物（共通の設定）」。物ごとの調整に入ると「コップだけを調整中」に変わり、［全部に戻る］が出る。
3. **検索**: 打つと、名前か見出しに合う項目だけ残る（折りたたみは自動で開く）。
4. **変えた所: N ［すべて戻す］**
5. **知らせ**: トゥーンになっていない物があれば「トゥーンになっていない物 6 ［追加］」と出す。
6. **よく触る8つ**（いつも見えている）: 影の色・影の広さ・境目のくっきり・影の面の明るさ・線の太さ・線の色・彩度・全体の明るさ。
7. **折りたたみ（最初は閉じる）**: 影／輪郭線／色と光／ハイライト・ふちの光。物ごとの調整中だけ「この物だけの項目」（基本の色・自己発光・両面・床用・鏡と映り込み）も出す。見出しに、その中で変えた所の数を出す。
8. **物ごと（閉じておく）**: シーンで選んでいる物のカードと、材質の一覧。
9. **準備（閉じておく・作る人向け）**: ゲーム中にトゥーンにするか・対象のシーン・材質探し・2Dの絵（オンオフと2D用の共通の値）。
10. **下の帯**: マウスを乗せた項目の説明を2〜3行で出す（ステージ背景スタジオと同じ仕組み）。

## 項目の行
- 名前（短く）・スライダー／色／スイッチ・数値・↺。
- 変えた所は名前を青くして印を付け、↺ を出す。基準は次のとおり。
  - 共通の設定を調整中: シェーダーの初期値。
  - 物ごとに調整中: 共通の設定の値。↺ で共通の値に戻る。
- 親スイッチ（線を出す・ハイライトを出す・ふちの光を出す・点の光を受ける）が切れていると、子の項目は薄くなる。
- 値を変えたらすぐシーンとゲームに出す。共通の設定を変えたときは、「共通に合わせる」がオンの材質すべてに配る（今と同じ）。Undo で戻せる。

## 物ごと（ユーザー決定: デザイナーさんも物を選んで調整する）
- シーンで物をクリックすると、「物ごと」の一番上にその物のカードが出る。カードには材質と、今の状態（共通・この材質だけ・この物だけ・トゥーンになっていない）を出す。
- ボタンは3つ。
  - ［この材質の物を調整］: 材質ごとの表の「共通に合わせる」を切り、その材質を上の項目で調整する。
  - ［この物だけ調整］: 今の objectOverrides の仕組みで、その物専用の材質を作って調整する。
  - ［鏡にする］
- 一覧には、トゥーンのオンオフ・状態・［選ぶ］（シーンで選ぶ）・［調整］を並べる。トゥーンになっていない材質は黄色にして［追加］を付ける。

## 作り（Claude が決めた所）
- UI Toolkit で作り、見た目は StudioKit の部品と uss を使う。StudioShell は左のページ一覧が付くので使わず、上の帯・中身・下の説明の帯をこの窓で組む。StudioKit 側は変えない。
- 窓は薄くし、部品ごとにファイルを分ける（`Scripts/Editor/Window/`）。
  - 状態: 設定ファイル・調整中の材質・変更の通知。
  - 項目の表: 名前・見出し・よく触るか・親スイッチ・説明。
  - 項目の行。
  - 見た目の欄・物ごとの欄・準備の欄。
- 「トゥーンになっていない物」は、窓を開いたとき・シーンを保存したとき・追加したときだけ調べる（毎フレームは調べない）。
- 材質の画面（ObjectToonShaderGUI）は今のまま残す。
- 確かめ方: Unity の csproj を dotnet msbuild でコンパイルする。動きは Unity でユーザーに確かめてもらう（UnityMCP が今つながっていないため）。
