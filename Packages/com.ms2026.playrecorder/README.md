# 録画しながらプレイ（Play Recorder）

Unity エディタ上部のツールバー（再生ボタンの横）に **「● 録画プレイ」** ボタンを追加します。
押すとプレイが始まり、ゲーム画面と音を録画。プレイを止めると **上限サイズ（初期値 20MB）以内の MP4** に自動で書き出します。

- **Discord にそのまま貼れる**：Discord の無料プランは 1 ファイル 20MB まで（2026 年 8 月に 10MB から引き上げ）。初期設定はこれに合わせた 20MB で、しかも 20MB を 20,000,000 バイトで数えて約 92% を目標に作るので、MB の数え方がどちらでも上限を下回ります。Nitro の人は上限サイズを 50 / 500 にすれば高画質に。
- **途中で切らない**：録画の長さが分かってから「上限 ÷ 長さ」でビットレートを決め、それに見合う解像度・fps を自動で選びます（短いほど高画質。目安：1 分まで 720p30、3 分で 360p30、10 分で 240p15）。書き出し後に実際の大きさを確かめ、超えていたら自動で縮め直します。
- **追加のインストール不要**：Unity 内蔵の動画エンコーダ（`UnityEditor.Media.MediaEncoder`）を使うので、Unity Recorder などは要りません。
- Unity 2021.3 以降（Windows / Mac は MP4、Linux は WebM）。Unity 6.3 以降は公式のツールバー拡張、それより前はツールバーへの差し込みで表示します。

## 入れ方（どれか 1 つ）

1. **フォルダをコピー**：この `com.ms2026.playrecorder` フォルダを、入れたいプロジェクトの `Packages` フォルダ（`Assets` と同じ場所にある）へコピーするだけ。
2. **すでに入っているプロジェクトから配る**：ボタンを右クリック（またはメニュー `Tools › 録画しながらプレイ`）→ **ほかのプロジェクトに入れる…** → 相手のプロジェクトのフォルダを選ぶだけ。
3. **ほかの PC へ**：同じメニューの **配布用 zip を作る…** で zip を作って渡す（中に `入れ方.txt` 同梱）。

やめるときは `Packages/com.ms2026.playrecorder` フォルダを消すだけです。

## 使い方

| 操作 | 結果 |
|---|---|
| **● 録画プレイ** を押す（エディタ停止中） | プレイ開始＋録画開始 |
| **● ここから録画** を押す（プレイ中） | 今から録画開始 |
| **■ 録画停止 0:42** を押す | 録画だけ止める（プレイは続く） |
| Unity の再生ボタンでプレイを止める | 録画も止まり、裏で MP4 に書き出し → 保存先フォルダが開く |
| ボタンを右クリック | 一番上に今の状態（書き出し中 45%・残り約 0:20／書き出し待ち ○ 本／録画中 …）。その下に 進み具合の画面を開く／録画フォルダを開く／最後の録画を再生／設定…／ほかのプロジェクトに入れる…／配布用 zip を作る… |
| `Ctrl+Shift+Alt+R` | ボタンと同じ（開始・停止） |

- 保存先：プロジェクトの `Recordings/`（Unity 標準の .gitignore で Git に入らない場所）。ファイル名は `プロジェクト名_日時.mp4`。
- 書き出しは Unity の右下の進行表示（バックグラウンドタスク）に出ます。プレイ中は休み、エディタに戻ると再開。× で「捨てる」も選べます。
- Unity が録画中に落ちても、次に開いたとき残っていた分から書き出します。
- ボタンが見当たらないとき：メニュー `Tools › 録画しながらプレイ › ツールバーにボタンを表示する`。Unity 6.3 以降は新しいツールバー部品が「非表示」で登録されるため、入れた直後に 1 回だけ自動で表示にしています（その後自分で隠した場合はそのまま）。

## 設定（Edit › Preferences › 録画しながらプレイ）

| 項目 | 初期値 | 説明 |
|---|---|---|
| 上限サイズ (MB) | 20 | 1MB = 1,000,000 バイトで数える |
| 最大の解像度 | 720p | 480 / 720 / 1080 |
| 最大の fps | 30 | 30 / 60 |
| 音も録る | ON | 長い録画で音が上限を圧迫するときは自動でモノラル → 音なし |
| 保存先フォルダ | Recordings | プロジェクトからの相対パスかフルパス |
| 書き出したらフォルダを開く | ON | |
| 上下反転の補正 | 自動 | 録画が上下さかさまになったときだけ変える |

設定は EditorPrefs（その PC の Unity 全体で共通）に保存されます。設定画面には「録画の長さと画質の目安」の表も出ます。

## しくみ（開発者向け）

録画中：`WaitForEndOfFrame` で `ScreenCapture.CaptureScreenshotIntoRenderTexture` → GPU で縮小 → `AsyncGPUReadback` → 別スレッドで JPEG 化して `Library/PlayRecorder/Sessions/<日時>/` に保存。音は `AudioListener` の GameObject に付けた `OnAudioFilterRead` で生のまま保存。取り込み画質も「今止めたらこの段」以上は取らないので、一時ファイルが増えすぎません。
停止後：長さから画質を決め、JPEG を読み直して `MediaEncoder`（H.264 / AAC）で書き出し。大きさを確かめて超えていれば最大 5 回縮め直します。
