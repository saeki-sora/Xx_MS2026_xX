# MS2026 SpriteAnim

デザイナーからスプライトシート1枚をもらうだけで、**再生・停止・再生中の別アニメーションへの遷移**を死ぬほど簡単かつ正確に扱えるようにする、2D スプライトアニメーションのための実験用パッケージです。

Unity 標準の Animator / AnimationClip は使わず、独自の軽量な再生システム（`SpriteAnimator`）で完結しています。理由は、キャラごとに Animator Controller を組む手間や、遷移条件のステートマシンをGUIで作る手間を無くし、「コードから `Play("Walk")` を呼ぶだけ」で完結する体験にするためです。

## 使い方（最短ルート）

1. メニュー `MS2026 > Sprite Anim > Sprite Anim Studio` を開く。
2. デザイナーから受け取ったスプライトシートを **Sprite Sheet** 欄にドラッグし、列数・行数を入力して **スライス実行**。
   - 素材がまだ届いていない場合は **テスト用シートを生成** を押せば、色分け＋通し番号ドット付きのダミーシートがその場で作られ、自動でスライスまで実行されます。
3. **新規セットを作成** で `SpriteAnimationSet` アセットを作る（1キャラ・1エフェクト群につき1つが目安）。
4. アニメーションリストの `+` で `Walk` `Attack` などのアニメーションを追加し、スライスしたスプライトを選択してから「フレーム追加」ボタンで登録。FPSを入力して「全フレームに一括適用」すれば個別に時間を打つ必要はありません。
5. ③プレビューでその場で再生確認。オニオンスキンやコマ送りも可能。
6. ④遷移テストで、2つのアニメーション間のクロスフェードの見た目・時間を実機を再生せずに確認。
7. GameObject に `SpriteRenderer`（または UI の `Image`）と `SpriteAnimator` コンポーネントを追加し、Animation Set を割り当てる。

```csharp
// SpriteRenderer / UI Image どちらが付いていても同じAPIで動く
var animator = GetComponent<SpriteAnimator>();

animator.Play("Walk");                 // 再生。既に再生中なら何もしない（毎フレーム呼んでも安全）
animator.Play("Attack", 0.1f);         // 0.1秒かけてクロスフェードしながら切替
animator.PlayOneShot("Hit", "Idle");   // Hitを1回再生→終わったら自動でIdleへ戻る
animator.Stop();
```

アニメーション名を文字列で書くのが不安なら、⑤ツールの「アニメーション名の定数クラスを生成」でマジックストリングを排除できます（`PlayerAnims.Walk` のように使える）。

## 詰め込んだ便利機能

**デザイナー向け**
- 実素材なしで動作確認できる「テスト用シート生成」（色分け＋フレーム番号ドット表示）
- ドラッグ&ドロップでのグリッドスライス（列/行、パディング、マージンを指定可能）
- フレームのドラッグ並べ替え、FPS一括適用
- プレビュー内 再生/一時停止/コマ送り/スクラブ/再生速度変更/オニオンスキン
- 実機再生なしでクロスフェード遷移の見た目と秒数を確認できる遷移テスター
- Project ウィンドウで選択した複数スプライトを名前の連番（`walk_0, walk_1...`）から自動グルーピングしてアニメーション一括生成

**プログラマー向け**
- `SpriteRenderer` / UI `Image` を同じコンポーネント・同じAPIで扱える抽象化
- `Play()` は同じアニメーションなら再生を巻き戻さない（毎フレーム呼び出しても安全）
- `PlayOneShot(name, returnTo)` でワンショット→復帰を1行で実装可能
- フレーム単位のイベント（`onFrameEvent` / `FrameEvent`）で足音・攻撃判定などにフック可能
- `OnAnimationStarted/Completed/Looped` の C# event と UnityEvent 両対応（コードからもInspectorからも配線可能）
- ループ方式は `Once` / `Loop` / `PingPong` / `ClampForever` の4種
- `randomizeStartFrame` で同一アニメーションを再生する複数キャラの同期崩し
- `useUnscaledTime` でポーズ中でも再生できるUIアニメーション対応
- from→to ごとにクロスフェード秒数を上書きできる `TransitionRule`（ワイルドカード `*` 対応）
- アニメーション名の定数クラス自動生成でマジックストリングを排除
- Inspector 上でアニメーション名をドロップダウン選択（タイポ防止）、Play Mode 中はテスト再生ボタンつき

## 本番プロジェクトへの移行方法

このパッケージは `com.ms2026.shaderfx` と同じ形の、完全に自己完結した Local UPM パッケージです。依存は `com.unity.ugui` のみ。

1. `Packages/com.ms2026.spriteanim` フォルダを丸ごと本番プロジェクトの `Packages/` にコピーする。
2. 本番プロジェクトの `Packages/manifest.json` の `dependencies` に以下を追加する。

```json
"com.ms2026.spriteanim": "0.1.0"
```

3. 以上で完了。プロジェクト固有のコードには一切依存していないため、コード変更は不要です。

## 既知の制約・今後の拡張余地

- クロスフェードは「新レイヤーを複製してアルファブレンド」で実現しているため、`Material` を使った特殊な合成（加算発光など）をしているスプライトでは見た目が変わる場合があります。
- `TransitionRule` はデータ構造として用意済みですが、専用の編集GUIはまだ無く、`SpriteAnimationSet` のデフォルトInspector（配列表示）から編集してください。
- JSON書き出し・スプライト命名規則のカスタマイズなど、拡張したい場合は `Editor/` 以下の各クラスが独立しているため差し替えが容易です。
